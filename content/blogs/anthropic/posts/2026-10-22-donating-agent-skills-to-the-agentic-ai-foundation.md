## 要約

Anthropic は、AI エージェントに専門知識とワークフローを与えるオープン標準 Agent Skills を、Linux Foundation 傘下の Agentic AI Foundation（AAIF）に寄贈した。AAIF は Anthropic が昨年 Block・OpenAI と共同で設立し、Model Context Protocol（MCP）も寄贈した団体。2025 年 12 月に標準を公開して以来、ChatGPT・Cursor・GitHub Copilot・VS Code など 70 以上のエージェントプラットフォームが Agent Skills を取り入れている。

## 新機能・主な変更

> [!info] Agent Skills とは
> スキルは、エージェントに特定のタスクや領域を教える `SKILL.md` ファイルと、必要なスクリプト・参考資料を収めたフォルダ。Claude Code の開発中に、一般的な知識作業には強いが実際の業務に必要な手順の知識が足りないことから生まれた。2025 年 10 月の公開から数週間で開発者が GitHub に数千のスキルを公開し、Codex・Cursor・OpenCode 向けのローダーも作られた。これまでに 100 万のスキルが公開され、約 2 億 8,000 万回インストールされている。

> [!info] 寄贈の内容
> Agent Skills の名前とロゴ、GitHub の organization、`agentskills.io` ドメインを寄贈する。AAIF に加わらなくても標準を使ったり貢献したりできる。標準は Anthropic・Google・OpenAI などのエンジニアが個人として保守し、David Soria Parra と Mahesh Murag がリードメンテナーを務める。

> [!info] 今後
> 最初のロードマップとして、バージョン付きのリリース、正式な提案プロセス、スキルを書く人・インストールする人向けのセキュリティガイダンスを提案している。MCP と同様にコミュニティの意見と透明な意思決定を優先し、仕様変更の提案へのフィードバックはプロジェクトの Discord で受け付ける。仕様は `agentskills.io` で読める。

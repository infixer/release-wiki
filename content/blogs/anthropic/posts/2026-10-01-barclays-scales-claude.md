## 要約

英国のユニバーサルバンク Barclays が Anthropic との戦略的協業を拡大し、Claude をグローバルな業務全体に組み込む。ソフトウェア開発の加速、レガシーシステムの刷新、業務効率の改善が目的で、Claude Code の利用は 2026 年末までに開発者の 50%、2027 年にはソフトウェアエンジニアの過半数に広がる見込み。すでに行員向けの知識アシスタントやメール処理で Claude が使われている。

## 新機能・主な変更

> [!tip] Claude Code を開発者に展開
> Barclays は Claude をソフトウェア開発の加速・レガシーシステムの刷新・業務効率化に使う。Claude Code の利用は 2026 年末までに開発者の 50%、2027 年にはソフトウェアエンジニアの過半数に達する見込み。Group Co-COO の Craig Bright 氏は、レガシープラットフォームの刷新やソフトウェア品質の向上に Claude を使い、AI をエージェント的な能力として開発・テスト・セキュリティ・運用に組み込んでいく方向だと述べている。

> [!tip] Colleague Knowledge Assistant
> Barclays UK の行員が、2,000 万人超の英国リテール顧客の対応で情報や回答をすばやく見つけるためのアシスタント。2025 年から稼働しており、検索拡張生成（RAG）の構成で Claude を使う。16,000 人以上の行員が利用し、検索件数は 100 万件を超えた。

> [!tip] Global Markets でのメール処理
> Global Markets 部門では、顧客からの問い合わせメールを Claude のモデルで分類・情報付与し、最適な処理ルートを決めている。1 日に約 12 万通のメールを処理し、手作業を減らしている。

> [!info] 責任ある展開
> Barclays は AI のユースケースに対して、ガバナンス・セキュリティ管理・人による監督を適用している。Anthropic の Chief Commercial Officer、Paul Smith 氏は、英国における重要なマイルストーンだとコメントしている。

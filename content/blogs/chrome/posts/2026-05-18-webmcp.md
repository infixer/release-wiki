## 要約

AI エージェントがウェブページの機能を安全かつ確実に呼び出せるようにするための、提案中のウェブ標準「WebMCP」。ページ側が `checkout` や `filter_results` のような「ツール」を明示的に宣言することで、エージェントによる DOM スクレイピングに頼らない操作を可能にする。Chrome 149 からオリジントライアルを実施予定。

## 新機能・主な変更

> [!tip] WebMCP の仕組み
> ウェブサイトが JSON スキーマ付きの「ツール」を定義・公開し、エージェントはそれを呼び出す形でページを操作する。命令型 API（JavaScript でツールを定義）と宣言型 API（HTML フォームへのアノテーション）の 2 種類が用意される。
>
> - **試す方法**: `chrome://flags/#enable-webmcp-testing` を有効化してローカル検証、または Chrome 149 からのオリジントライアルに登録
> - **セキュリティ**: オリジン分離されたドキュメントでのみ動作（`document.domain` 設定時は無効）。`tools` Permissions Policy の既定は同一オリジンのみで、`allow="tools"` によりクロスオリジン iframe にも許可できる
> - **制限事項**: ヘッドレスブラウジング向けではなく、人間がループに入るローカルワークフロー向けに設計されている。複雑な UI では JavaScript の追加・改修が必要になる場合がある
> - **検証ツール**: Model Context Tool Inspector 拡張機能で、登録されたツールの確認・手動呼び出し・自然言語での動作検証ができる

## 要約

Firefox 154.0.1 は修正版リリース。直近のパスワード保存の変更が原因で発生していた、保存済みパスワードへのアクセス低下や意図しないマスターパスワードの入力要求を修正した。ほかにも住所の自動入力、Windows のスタートメニューショートカット、ローカルネットワーク機器への接続、イントラネットサイトを開いた際のクラッシュ、タブタイトルの表示に関する不具合を修正している。

## 新機能・主な変更

- 直近のパスワード保存の変更が原因で発生していた、保存済みパスワードへのアクセス低下や意図しないマスターパスワードの入力要求を修正（Bug 2064411, Bug 2065593, Bug 2063993）
- 一部サイトで住所の自動入力が失敗する問題を修正（Bug 2065145, Bug 2063599）
- Firefox が起動するたびに Windows のスタートメニューに新しいショートカットを追加してしまう問題を修正（Bug 2064652）
- 一部の HTTP 経由で読み込まれるサイトで、ローカルネットワーク機器への接続が権限プロンプトなしに失敗する問題を修正（Bug 2059274）
- ローカルネットワーク共有上のファイルにリンクするよう設定されたイントラネットサイトを開いた際のクラッシュを修正（Bug 2064648）
- Windows でシステムフォントが MS UI Gothic の場合に、タブタイトルの先頭が欠けて表示される問題を修正（Bug 2056856）

> [!warning] 既知の問題
> - 縦置きタブを有効にしている場合、Firefox 再起動後にサイドバーの状態が保持されないことがある。再起動後にサイドバーのツールバーボタンをクリックすると縦置きタブを再度有効化できる。この問題は Firefox 155.0.1 で修正済み。
> - フルスクリーン時にツールバーを非表示にする設定（Windows・Linux のデフォルト）では、画面左端にカーソルを移動しても縦置きタブのサイドバーが表示されない。カーソルを画面上端に移動するとツールバーとサイドバーが揃って表示される。ツールバーを右クリックして「ツールバーを非表示にする」のチェックを外す方法もある。現在修正に取り組み中。（Bug 2064638）

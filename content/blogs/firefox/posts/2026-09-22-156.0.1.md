## 要約

Firefox 156.0.1 は修正版リリース。NVDA スクリーンリーダーでのアドレスバー操作、リンク内要素の `:active` スタイル、CSS アンカー位置指定を使うページでの応答なし、macOS 27 でのウィンドウ最大化復元、Windows でのシステムハンドルのリークといった不具合を修正した。

## 新機能・主な変更

- NVDA スクリーンリーダーで、マウスポインターをアドレスバーのボタン上に移動してもボタンが読み上げられない問題を修正（Bug 2069276）
- リンク内の要素をクリックしている間、CSS の `:active` スタイルが表示されない問題を修正（Bug 2067272）
- CSS のアンカー位置指定（anchor positioning）を使うページで Firefox が応答しなくなる問題を修正（Bug 2070171）
- macOS 27 で、タイトルバーのダブルクリックで復元したウィンドウがすぐに最大化状態に戻ってしまう問題を修正（Bug 2066632）
- Windows でコンテンツプロセスの起動・終了のたびにシステムハンドルがリークする問題を修正（Bug 2069644）

## 破壊的変更・移行手順

なし

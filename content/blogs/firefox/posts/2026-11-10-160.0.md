## 要約

Firefox 160.0 は 2026-11-10 に Release チャネルで提供が始まった。ピクチャーインピクチャーに再生速度の設定が加わり、タブやページの一部を常に手前に表示する Mini Window（初期版）が登場した。`mailto:` などのリンクの処理を繰り返し求めるサイトを「Never allow」でブロックできるようになり、MKV（FLAC・MP3・PCM 音声）を再生でき、macOS の WebGL は Metal で描画する。開発者向けには Web Speech API の `SpeechRecognition`（端末上で 40 言語）と、`::-webkit-input-placeholder` に対応した。

## 新機能・主な変更

> [!tip] ピクチャーインピクチャーの再生速度
> ピクチャーインピクチャーのプレーヤーで、再生速度を 0.25x〜2.0x の範囲で設定できる。設定はプレーヤーのウィンドウが中サイズ以上のときだけ表示される。

> [!tip] Mini Window
> タブやページの選択した部分を、ブラウズ中も常に手前に表示されるウィンドウに移せる。初期版の機能で、Mozilla Connect でフィードバックを募っている。

> [!tip] リンクの処理を求めるサイトをブロック
> メール（`mailto:`）などのリンクの処理を繰り返し求めるサイトを、新しい「Never allow」ボタンでブロックできる。ブロックしたサイトは設定で管理できる。

> [!tip] その他の変更
> - 履歴の項目をサイドバーからタブストリップへドラッグして新しいタブで開ける
> - コピーしたテキストが Web アドレスではなく検索語のとき、アドレスバーのコンテキストメニューに「Paste and Go」ではなく「Paste and Search」を表示
> - PDF として保存したページの数式（MathML）が、スクリーンリーダーなどの支援技術から読めるように
> - FLAC・MP3・PCM 音声の Matroska（MKV）ファイルを再生できる
> - macOS の WebGL コンテンツを Apple の Metal グラフィックス API で描画（一部のサイトで性能が上がる場合がある）
> - Smart Window の Organize Tabs がフランス語に対応（関連する開いているタブのグループを提案し、フランス語で名前を付ける。段階的に展開）
> - アドレスバーでドメイン名とそれ以外の部分のコントラストを上げ、どのサイトを開いているか分かりやすく

> [!tip] 開発者向け: Web プラットフォームの新機能
> - Web Speech API の `SpeechRecognition` インターフェイスに対応。端末上で 40 言語のリアルタイムの音声認識ができる
> - 旧来の `::-webkit-input-placeholder` 疑似要素を `::placeholder` の別名としてサポート（プレースホルダーのテキストを装飾しているサイトとの互換性を高める）

- アドレスバー・検索バーをクリックした直後に素早く入力すると、最初の 1 文字が失われることがある問題を修正
- NTLM・Kerberos（Negotiate）認証を使うイントラネットのサイトにサインインすると、Firefox が数秒固まる問題を修正
- テキストフィールドでカーソルの近くをダブルタップ・長押しして単語を選択したり、タップしてカーソルを置いたりできない問題を修正
- macOS で、RSS リーダーなど他のアプリからバックグラウンドで開いたリンクが Firefox を前面に出す問題を修正
- macOS で、ダウンロードしたファイルが Finder で設定した既定のアプリではなく別のアプリで開くことがある問題を修正
- macOS で、保存先を毎回確認する設定のとき、同時に行うダウンロードが終わらない（最初のファイルしか保存ダイアログが出ない）問題を修正
- macOS の印刷ダイアログから「プレビュー」で開いた PDF の、意味のあるファイル名と通常の保存の流れを復元

Firefox 160 では 22 人の新しいボランティアを含む開発者が初めてのコード変更を寄せた。Firefox Enterprise の更新・修正は Firefox Enterprise Release Notes、ポリシーの変更は Firefox の管理者向けドキュメントの changelog を参照。

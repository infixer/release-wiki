## 要約

Firefox 158.0 は 2026-10-13 に Release チャネルで提供が始まった。Smart Window がフォーム入力の候補を提案するようになり（段階的に展開）、JPEG XL 画像形式に対応した。ページを PDF として保存・印刷したときにアクセシブルな PDF を作るようになり、スクロール位置を画面のピクセル単位に丸めなくなった。開発者向けには CSS `calc()` の型付き演算、`Notification` の `navigate` オプション、`PerformanceResourceTiming.deliveryType` の `cache` 値などに対応した。

## 新機能・主な変更

> [!tip] Smart Window でフォーム入力の候補を提案
> フォーム欄をクリックするか「Fill from sources」を選ぶと、Smart Window が関連する開いているタブや保存済みの自動入力データをもとに入力する値を提案する。この機能は段階的に展開される（一部のユーザーから先に有効になる）。

> [!tip] JPEG XL 画像形式に対応
> 一般に WebP・JPEG・PNG・GIF より圧縮率が高い JPEG XL 画像形式に対応した。

> [!tip] よりアクセシブルな PDF を作成
> ページを PDF として保存したとき、および Linux と macOS で印刷したときに、よりアクセシブルな PDF を作成する。数式記号が欠けるなどの PDF 描画の問題も修正された。

> [!tip] スクロールがより滑らかで正確に
> スクロール位置を画面のピクセル単位に丸めなくなった。高解像度ディスプレイやページを拡大しているときに特にスクロールが滑らかで正確になる。

> [!tip] 新しいタブの壁紙ライブラリと翻訳言語の追加
> 新しいタブは、直近の 1 枚だけでなくカスタム壁紙のライブラリを「Your images」に保持するようになった。翻訳機能がアルバニア語・ベラルーシ語・フィリピン語に対応した。

> [!tip] 開発者向け: Web プラットフォームの新機能
> - CSS `calc()` で型付き演算に対応し、数学関数の中で単位どうしを掛けたり割ったりできる
> - `Notification` コンストラクタと `ServiceWorkerRegistration.showNotification()` で `navigate` オプションに対応（通知をクリックしたときに移動する URL を指定する）
> - WebAuthn の conditional UI を `autocomplete="webauthn"` 属性だけの `input` 要素にも表示する（以前は `autocomplete="username webauthn"` のように他の自動入力値も含む場合だけ）
> - `PerformanceResourceTiming.deliveryType` の `cache` 値に対応し、HTTP キャッシュから配信されたリソースを判別できる
> - 対応する端末で WebGL 拡張 `EXT_polygon_offset_clamp` が使える
> - ネットワークモニターで、接続直後に届いた WebSocket メッセージを取りこぼすことがある問題を修正

- Ubuntu の既定テーマで、キーボードでアドレスバーの候補を選んだときにサイトアイコンがハイライト色に溶け込む問題を修正
- サイトアイコンの読み込み中に起きることがあるクラッシュを修正
- Windows と Linux で、アドレスバーの統合検索ボタンのメニューで検索エンジン名の先頭文字に下線が付き、キーボードショートカットが衝突することがある問題を修正
- Windows のハイコントラストテーマで「すべてのタブを一覧表示」・設定・統合検索などのメニューが読みにくい問題を修正（Windows の設定で選んだ背景色と文字色に従う）
- 企業向けの更新・修正は Firefox Enterprise のリリースノート、ポリシーの変更は Firefox 管理者向けドキュメントの変更履歴に記載
- このリリースで初めてコードを提供した開発者を紹介（うち 20 人は新しいボランティア）

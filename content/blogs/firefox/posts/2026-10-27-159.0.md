## 要約

Firefox 159.0 は 2026-10-27 に Release チャネルで提供が始まった。macOS の共有がネイティブの共有ピッカーを使うようになり、保存済みパスワードが既定でサイドバーから使えるようになった。Smart Window は `/watch` でページの変化（値下げや再入荷など）を見張れるようになった（段階的に展開）。開いているタブを検索するキーボードショートカットが加わった。開発者向けには CSS のスクロール駆動アニメーション、スコープ付きカスタム要素レジストリ、Web コンソールでの `let`・`const`・`class` の再宣言などに対応した。

## 新機能・主な変更

> [!tip] macOS でネイティブの共有ピッカーを使用
> macOS での共有がネイティブの共有ピッカーを使うようになり、ページのプレビューと最近の連絡先が AirDrop・メッセージなどのアプリと並んで表示される。選択した複数のタブを一度に共有することもできる。

> [!tip] 保存済みパスワードを既定でサイドバーに
> 「パスワード」ツールを追加しなくても、保存済みのパスワードがサイドバーから既定で使えるようになった。

> [!tip] Smart Window でページの変化を見張る
> チャットに `/watch` と入力すると、値下げや再入荷などのページの変化を見張る設定ができ、一致するものが見つかると Firefox がデスクトップ通知を送る。見張りはツールバーの Tasks ボタンか `about:smartwindowtasks` で管理できる。この機能は段階的に展開される（一部のユーザーから先に有効になる）。

> [!tip] 開いているタブをショートカットで検索
> Windows と Linux では `Ctrl+Shift+A`、macOS では `Cmd+Shift+A` で開いているタブを検索できる。ショートカットは `about:keyboard` で変更できる。

> [!tip] その他の変更
> - macOS で Firefox が既定のブラウザーのとき、既定のブラウザーでサインインするアプリ（ChatGPT など）のサインインページが Safari ではなく Firefox で開く
> - AI チャットボットの「ページを要約」が、ページのテキストではなくページのアドレスをチャットボットのプロバイダーに送るようになり、長いページの要約が途中で切れなくなった
> - ジャワ文字・バリ文字・カナダ先住民音節文字・ンコ文字で書かれた Web アドレスを、エンコードされた `xn--` 表記ではなくその文字のまま表示する

> [!tip] 開発者向け: Web プラットフォームの新機能
> - Web コンソールで `let`・`const`・`class` の変数を再び宣言できるようになり、スニペットを編集して再実行しても再宣言エラーにならない
> - スクロール駆動アニメーションに対応。CSS アニメーションと Web Animations API のアニメーションを、コンテナのスクロール位置や要素がスクロールで表示される度合いに合わせて進められる。`animation-timeline`・`scroll-timeline`・`view-timeline`・`animation-range` プロパティと `ScrollTimeline`・`ViewTimeline` インターフェイスを追加
> - スコープ付きカスタム要素レジストリに対応。`CustomElementRegistry()` コンストラクタで作ったレジストリはグローバルな `window.customElements` とは別になり、同じタグ名のカスタム要素を同じページで共存させられる
> - 対応する端末で、WebGL が `EXT_clip_control` と `EXT_texture_mirror_clamp_to_edge`、WebGL 2 が `EXT_texture_norm16` 拡張に対応
> - Sanitizer API が HTML をパースした後ではなくパースしながらサニタイズするようになり、サニタイザーが取り除く要素のカスタム要素コンストラクタが実行されなくなった

- ファイルのアップロードダイアログが、前回アップロードに使ったフォルダーではなく前回ファイルを保存したフォルダー（ダウンロードなど）で開く問題を修正
- Zoom の Web アプリなどを最小化したウィンドウで開いたままにすると、メモリ使用量が急増する問題を修正
- Windows で NVIDIA RTX Video HDR を有効にしていると、一部の動画が正しく表示されない問題を修正
- Google アカウントにサインインしている Google Chrome のプロファイルからブックマークをインポートできない問題を修正
- macOS の Apple Writing Tools の「置き換え」ボタンが、Gmail など一部のサイトで書き直したテキストではなくクリップボードの内容を挿入する問題を修正
- Web ページの長いドロップダウンリストで、スクロールするまで最後の選択肢の代わりに空白が表示されることがある問題を修正
- Slack など一部のサイトで、HTTP/3 のリクエストが拒否されたときに HTTP/2 にフォールバックせず読み込みに失敗する問題を修正
- Linux の AMD グラフィックスで、ChatGPT などのサイトで地図や場所の結果を表示するとメモリを使いすぎる問題を修正
- macOS の Web ゲームで、ゲームパッドのボタンを素早く押すと取りこぼすことがある問題を修正
- Linux の Wayland で、タブをクリックすると新しいウィンドウに切り離されることがある問題を修正
- Windows と Linux で、OS のアニメーション効果をオフにしていてもメニューやパネルがフェードインする問題を修正
- 企業向けの更新・修正は Firefox Enterprise のリリースノート、ポリシーの変更は Firefox 管理者向けドキュメントの変更履歴に記載
- このリリースで初めてコードを提供した開発者を紹介（うち 12 人は新しいボランティア）

## 破壊的変更・移行手順

> [!warning] 「アドオンとテーマ」のショートカットが変更
> タブ検索に `Ctrl+Shift+A` / `Cmd+Shift+A` が割り当てられたため、「アドオンとテーマ」のショートカットは Windows と Linux で `Ctrl+Shift+F`、macOS で `Cmd+Shift+E` になった。ショートカットは `about:keyboard` で変更できる。

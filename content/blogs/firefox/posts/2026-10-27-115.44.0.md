## 要約

Firefox 115.44.0 は ESR チャネル向けのリリースで、2026-10-27 に提供が始まった。Firefox ESR 115 は現在 Windows 7〜8.1 と macOS 10.12〜10.14 でのみサポートされており、それ以外の OS のユーザーは Firefox ESR 140 を使うよう案内されている。

## 新機能・主な変更

> [!info] ESR 115 のサポート対象 OS
> Firefox ESR 115 のサポート対象は Windows 7〜8.1 と macOS 10.12〜10.14 のみ。ほかの OS では Firefox ESR 140 を使う。

## 破壊的変更・移行手順

なし

## 要約

Firefox 159.0.1 はリリースチャネル向けの修正版で、2026-11-03 に提供が始まった。Facebook と Instagram のように関連サイト間でパスキーを共有するサイトでパスキーのサインインに失敗する問題、Windows で一部のセキュリティソフトがあるとクラッシュする問題、Linux の WebGL で赤と青が入れ替わる問題などを修正した。キューバが 2026-11-01 に夏時間を終了しないと決めたことに合わせてタイムゾーンのデータも更新している。

## 新機能・主な変更

- 注意が必要なタブを示すドットが、テーマやシステムのアクセントカラーによっては見えにくい問題を修正（Bug 2086347）
- Windows で、更新を適用するために Firefox を再起動するときにコマンドプロンプトのウィンドウが一瞬表示される問題を修正（Bug 2081809）
- Facebook と Instagram のように関連サイト間でパスキーを共有するウェブサイトで、パスキーでのサインインに失敗する問題を修正（Bug 2085450）
- Windows で、一部のウイルス対策ソフトなどのセキュリティソフトがインストールされているとクラッシュし、場合によっては WebGL が無効のままになる問題を修正（Bug 2083648）
- Linux で、WebGL を使う一部のサイト（ビデオ通話の背景エフェクトなど）で赤と青が入れ替わって表示される問題を修正（Bug 2087301）
- キューバが 2026-11-01 に夏時間を終了しないと決めたことを反映して、タイムゾーンのデータを更新（Bug 2086609）
- 設定画面の一部の説明文（セキュリティの警告など）が単語の途中で改行される問題を修正（Bug 2086282）

## 破壊的変更・移行手順

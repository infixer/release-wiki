## 要約

Firefox 155.0 では、AI アシスタント機能「Smart Window」がアメリカ・カナダ・フランスの全ユーザーに公開されたほか、アドレスバーにブロックしたトラッカー数を表示する機能が段階的に展開される。翻訳機能はマラーティー語・ウルドゥー語に対応し、コンテナの並べ替えなど細かな改善も入った。開発者向けには CSS の新機能（`attr()` の型拡張、`progress()`、`alpha()`）や WebAssembly の 2 つの提案、QUIC version 2、WebTransport・WebRTC の拡張などが追加されている。一方で、キャプティブポータル検出ドメインの変更や `mailto:` リンクの挙動変更など、環境によっては対応が必要な変更も含まれる。

## 新機能・主な変更

> [!tip] Smart Window がアメリカ・カナダ・フランスで全ユーザーに公開
> AI アシスタント機能「Smart Window」が、これまでの一部提供からアメリカ・カナダ・フランスの全ユーザーに公開された（段階的展開）。あわせて以下の機能が追加されている。
>
> - 作業中だった話題にすぐ戻れる、パーソナライズされた「再開」の会話の入り口
> - Exa のウェブ検索の出典表示によって、アシスタントの応答がこれまでの約 1/5 の時間で返るように
> - 「タブを整理」がタブのグループ分けと、より分かりやすいグループ名を提案するように改善

> [!tip] アドレスバーにブロックしたトラッカー数を表示（段階的展開）
> アドレスバーに、Firefox がブロックしたトラッカーの件数が表示されるようになった。組み込みのトラッカーブロック自体は変わらず、件数表示だけを設定でオフにできる。

- Windows で Nintendo Switch Pro コントローラーおよび対応する互換コントローラーが、方向パッドとアナログスティックを含めて Web ゲームで正しく動作するように
- 設定でコンテナの並び順を変更できるようになり、コンテナが表示される場所すべてにその順序が反映される
- 翻訳機能がマラーティー語・ウルドゥー語に対応
- Linux で特定のキーボードレイアウトを使って入力した際、Microsoft 365 Word Online などの Web アプリで文字が消える問題を修正
- Google ドキュメントで書式なし貼り付けのショートカットを使った際に、不要な貼り付け確認が表示される問題を修正
- タブのドラッグ操作を終了できずツールバーとタブバーが反応しなくなった場合に、Firefox が復帰できるように
- ボタン内のテキストが選択・コピーできず、X のダイレクトメッセージや YouTube のコメントをコピーできなかった問題を修正
- バックグラウンド再生中にネットラジオなどのライブ音声ストリームが停止してしまう問題を修正
- 別のウィンドウに移動したタブから再生インジケーターが消え、再生中の音を確認・ミュートできなくなる問題を修正
- 長時間のブラウジング後に Linux システムがスリープできなくなる問題を修正
- ノッチ付きカメラのある MacBook で、フルスクリーン再生時に映像がレターボックス表示される問題を修正（動画再生時に特に顕著）
- 他サイトの埋め込みコンテンツを含む一部のページで、矢印キーおよび Page Up/Down によるスクロールが効かない問題を修正
- Windows で一部のあまり一般的でない文字体系の文字が空の四角として表示される問題を修正
- macOS で `WebCodecs` の `VideoEncoder` が NV12 形式の `VideoFrame` をエンコードする際にハングする問題を修正
- PDF 印刷時に、用紙より小さい PDF を拡大率 100% 超に設定して用紙いっぱいに拡大できるように

開発者向け（DevTools・Web プラットフォーム）:

- ルールビューに `prefers-reduced-motion` メディア機能をエミュレートするトグルを追加（エミュレーション設定は at-rules（@）ボタンの新しいパネルに移動）
- デバッガーに、すべてのブレークポイントを一括で有効・無効にするキーボードショートカット `Ctrl+Alt+B`（macOS は `Cmd+Alt+B`）を追加
- JSON Viewer が JSON Lines（JSONL/NDJSON）形式のドキュメントに対応し、不正な行にはインラインでエラーを表示
- ストレージパネルが、検証対象ページ自身の Cookie に加えてプライベートウィンドウ・コンテナなど他のパーティションの Cookie まで表示してしまう問題を修正
- コンソールで、`Error` ではない例外を投げた場合に `Object` とだけ表示していたのを、プロパティ名も一覧表示するように改善
- CSS の `attr()` 関数が任意の型の値に対応し、`content` プロパティ以外でも文字列に限らず属性値を利用できるように
- CSS の `progress()` 関数をサポート
- CSS の `alpha()` 関数をサポート（色の alpha 成分だけを変更できる relative color 関数）
- `await` dictionary proposal の `Promise.allKeyed` / `Promise.allSettledKeyed` をサポート（Promise のオブジェクトを受け取り、同じキーを持つ結果のオブジェクトに解決する）
- WebAssembly の Compact Import Section 提案をサポート（import が多い Wasm モジュールのサイズを削減できる）
- WebAssembly の Wide Arithmetic 提案をサポート（暗号や多倍長演算向けの 128 ビット演算命令を追加）
- HTTP/3 接続で QUIC version 2（RFC 9369）をサポートし、サーバーが compatible version negotiation（RFC 9368）で選択した場合に使用
- Firefox 153 で追加された非標準の `::-webkit-scrollbar` 疑似要素のサポートを、全サイト対象から一部サイトの一覧のみに限定
- SVG の `<a>` 要素が、HTML のリンクと同じ `protocol`・`host`・`pathname`・`search` などの URL プロパティを持つように
- `SVGGraphicsElement.getBBox()` がオプション引数を反映するようになり、線幅・マーカー・クリッピングを含むバウンディングボックスを取得できるように
- `font-stretch` の標準名として `font-width` プロパティをサポート
- ネットワークエラーや HTTP エラーで失敗した動的 `import()` を、モジュールマップに失敗としてキャッシュしないように変更。同じ指定子での再試行が成功しうるように
- WebTransport が送信グループ（`createSendGroup()`）、書き込み可能な datagram ストリーム（`createWritable()`）、TLS セッションに紐づく鍵を導出する `exportKeyingMaterial()` に対応。コンストラクタの `protocols` オプションと `protocol` プロパティによるサブプロトコルのネゴシエーション、draining promise も追加
- WebRTC の相互運用性向上のため、データチャンネル障害用の `RTCError`、`RTCSctpTransport.maxChannels`、2 バイトの RTP ヘッダー拡張 ID、より正確な `RTCTransportStats` をサポート

> [!warning] 既知の問題
> - 縦置きタブを有効にしている場合、Firefox 再起動後にサイドバーの状態が保持されないことがある。再起動後にサイドバーのツールバーボタンをクリックすると再度有効化できる。Firefox 155.0.1 で修正済み。
> - UDP をブロックするネットワーク（TLS インスペクションで QUIC を遮断する企業ネットワークなど）では、一部サイトの読み込みが遅くなる・失敗することがある。回避策として、ポリシーで `network.http.happy_eyeballs_enabled` を `false` に設定する。Firefox 155.0.1 で修正済み。（Bug 2063452）
> - macOS で一部形式の SDR 動画の色が薄く表示されることがある。調査中で、将来のリリースで修正予定。（Bug 2068961）

## 破壊的変更・移行手順

> [!warning] CSS のネストを 75 段階までに制限
> 極端に深いネストによるクラッシュを防ぐため、CSS のブロックや関数のネストが 75 段階までに制限された。それを超えて深くネストしたルールや値は解析されなくなる。

> [!warning] キャプティブポータル検出ドメインの変更
> キャプティブポータルの検出・ネットワーク疎通確認に使うドメインが `detectportal.firefox.com` から `firefox-portal-detection.com` に変更された。旧ドメインを参照しているネットワークの許可リスト（アローリスト）は更新が必要。

> [!warning] `mailto:` リンクの挙動変更
> `mailto:` リンクは、ユーザーの明示的な操作に応じた場合にのみ開くようになった。ページ側がユーザーの操作なしにメールクライアントを起動することはできなくなる。

> [!warning] 非標準 `::-webkit-scrollbar` の適用範囲を縮小
> Firefox 153 で追加された非標準の `::-webkit-scrollbar` 疑似要素のサポートが、全サイト対象から一部サイトの一覧だけに限定された。全サイトへの適用を前提にしていた場合は影響を受ける可能性がある。

## 要点

React Aria Components v1.22.0。

- **`Sheet` を追加**: ビューポートの端からスライドして出てくる、スワイプ可能なオーバーレイ。ブラウザのネイティブなスクロール操作の上に作られている。モバイルのシート、ナビゲーションドロワー、通知バナーのようなタッチ向けのトレイに向く（仕組みは [ブログ記事](https://react-aria.adobe.com/blog/sheet) で解説）
- **`@react-aria/optimize-locales-plugin` が Turbopack に対応**
- **オーバーレイの配置がバーチャルキーボードを考慮**するように
- ほかにも多数の変更あり（詳細は Full Release Notes）

## 概要

S2（`@react-spectrum/s2`）の `style` マクロと、そのテーマ（`style/spectrum-theme.ts`）で使える CSS プロパティまわり。テーマに無いプロパティはマクロで黙って無視されるため、必要なものはテーマへ追加される。`scrollbarGutter` が追加された。`@react-spectrum/s2@1.8.1` の ESM ビルドでマクロの実行が `$kLxT8$propertiesmjs1 is not defined` で失敗する問題は、default import を使う回避策で修正された（未リリース）。

## 主な API・オプション

- `scrollbarGutter` — スタイルマクロで指定できるようになった（docs のスタイルプロパティ一覧にも記載）

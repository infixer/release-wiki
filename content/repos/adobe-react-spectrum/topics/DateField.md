## 概要

React Aria の日付入力（`useDateSegment` など）と React Aria Components の `DateField` まわり。ブラウザの CLDR データの更新でクラッシュすることがあり、`useDateSegment` にフォールバックを入れて対処した。

## 主な API・オプション

- `useDateSegment`（`react-aria`）
- `DateField`（`react-aria-components`）

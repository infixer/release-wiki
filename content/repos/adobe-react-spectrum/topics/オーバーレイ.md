## 概要

React Aria / React Aria Components の `Modal`・`Popover` などのオーバーレイの配置とスクロール制御（`usePreventScroll`）まわり。スクリーンキーボード（OSK）の開閉で visual viewport の大きさが変わる前に配置するとレイアウトがずれるため、キーボードの開閉を待ってから配置する仕組み（`runAfterKeyboard`）が入った。

## 主な API・オプション

- `Modal` / `Popover`（`react-aria-components`）— キーボードの開閉を待ってから配置する
- `runAfterKeyboard`（`react-aria` の utils、内部）— キーボードの開閉の後に処理を実行する

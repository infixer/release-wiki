## 概要

React Aria / React Aria Components の `Modal`・`Popover`・`Sheet` などのオーバーレイの配置とスクロール制御（`usePreventScroll`）まわり。ビューポートの端からスライドして出るスワイプ可能な `Sheet` が追加された（ネイティブのスクロール操作・CSS scroll snapping・view timeline で実装）。入れ子の `Popover` は親の `PopoverContext` を引き継がない。スクリーンキーボード（OSK）の開閉で visual viewport の大きさが変わる前に配置するとレイアウトがずれるため、キーボードの開閉を待ってから配置する仕組み（`runAfterKeyboard`）が入った。

## 主な API・オプション

- `Modal` / `Popover`（`react-aria-components`）— キーボードの開閉を待ってから配置する
- `Sheet` / `SheetContent`（`react-aria-components`）— スナップポイント、重ね表示、`swipeAnimation`・`stackAnimation`、複数の配置とスワイプ方向
- `PopoverContext` — `Popover` の中では常にクリアされる
- `runAfterKeyboard`（`react-aria` の utils、内部）— キーボードの開閉の後に処理を実行する

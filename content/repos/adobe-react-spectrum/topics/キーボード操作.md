## 概要

React Aria のキーボード操作まわり（`useKeyboard` と、`packages/react-aria/src/utils/keyboard.tsx` のグローバルイベント）。
パッケージの import 時に `setupGlobalEvents()` が呼ばれ、`window.screen.orientation` が無い環境では角度 `0` にフォールバックする（jsdom の shim も対応）。
ユーザーの `onKeyDown` / `onKeyUp` を `useKeyboard` 経由で扱い `stopPropagation` の挙動を揃える変更（Menu・DateField・DatePicker・DateRangePicker）は、一度入ったが revert されている。

## 主な API・オプション

- `useKeyboard` — キーボードイベントを扱うフック。ユーザーのハンドラーに期待される `stopPropagation` の挙動を与える
- `setupGlobalEvents()` — パッケージの import 時に呼ばれるグローバルイベントの設定

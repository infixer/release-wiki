## 概要

React Aria のキーボード操作まわり（`useKeyboard` と、`packages/react-aria/src/utils/keyboard.tsx` のグローバルイベント）。
パッケージの import 時に `setupGlobalEvents()` が呼ばれ、`window.screen.orientation` が無い環境では角度 `0` にフォールバックする（jsdom の shim も対応）。
ユーザーの `onKeyDown` / `onKeyUp` を `useKeyboard` 経由で扱い `stopPropagation` の挙動を揃える変更（Menu・DateField・DatePicker・DateRangePicker）は、一度 revert された後、2026-10-13 に再適用された。
`useKeyboard` の `shortcuts` への移行で抜けていたコレクションの Home・End・PageUp・PageDown のハンドラーと日付ピッカーの `preventDefault` が補われた。Toolbar では矢印キーでフォーカスした項目を `scrollIntoViewport` で完全に表示する。さらに、`window.screen` 自体が無い環境（React Native の Jest 環境・Deno など）でも import 時に例外を投げないよう、shim の条件に `window.screen != null` が加わった（未リリース）。

## 主な API・オプション

- `useKeyboard` — キーボードイベントを扱うフック。ユーザーのハンドラーに期待される `stopPropagation` の挙動を与える
- `setupGlobalEvents()` — パッケージの import 時に呼ばれるグローバルイベントの設定
- `useToolbar` — 矢印キーでのフォーカス移動後に `scrollIntoViewport(nextFocused, {containingElement})` を呼ぶ

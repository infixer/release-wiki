## 概要

React Aria Components の `Form` と、フォームに参加するコンポーネント（Select・CheckboxGroup）のリセット・送信まわり。
300 件を超える項目を持つ Select は `name` が無くても隠し input をレンダーし、フォームのリセットでデフォルトの選択に戻る。
CheckboxGroup は同じ更新で複数の値を外しても正しく反映され、リセットで全チェックボックスがデフォルトの選択に戻る。
`Form` の中に置いた `Form` は外側の `Form` の props（`onSubmit`・`id`・`className`・`validationErrors`）を引き継がない。ユーザーが自分で提供した `FormContext` はこれまでどおり効く。

## 主な API・オプション

- `Form` / `FormContext`（`react-aria-components`）— `Form` が提供する context には非公開のシンボルが付き、入れ子の `Form` はそれをマージしない
- `HiddenSelect`（`react-aria`）— `name` の有無に関係なく input をレンダー
- `useCheckboxGroupState`（`react-stately`）— `removeValue` は関数形式の state 更新

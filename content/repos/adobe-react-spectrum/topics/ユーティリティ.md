## 概要

`packages/react-aria/src/utils` の共通ユーティリティ。
`runAfterTransition` は、要素の複数のトランジションがキャンセルされても要素を保持し続けない（`transitioncancel` はプロパティごとに送られるため、リスナーの `once` を外した）。以前は DOM から外れた要素がメモリに残ったり、以後の `runAfterTransition` のコールバックが呼ばれなくなったりした。
`useDescription` は、既存の説明用ノードの ID で state を遅延初期化し、マウント時の余分なレンダーをしない。

## 主な API・オプション

- `runAfterTransition` — 実行中のトランジションが終わった後にコールバックを実行する
- `useDescription` — 共有の説明用ノードを作り、その ID を返す（`useDrag`、タグ、テーブルの列幅変更などで使用）

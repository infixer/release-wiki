## 概要

React Aria のドラッグ＆ドロップ（`useDrag` など）と、仮想化したコレクションでのドロップ位置の計算（`react-stately` の `ListLayout`）。
横方向の仮想化リストでドロップ位置が不正確だった問題が `ListLayout` で修正された。
ドラッグ可能な要素が使う `useDescription` は、既に説明用のノードがあればその ID で state を初期化し、マウント時の余分なレンダーをしない（仮想化リストを素早くスクロールしたときの React 19 の "Maximum update depth exceeded" の原因になっていた）。

## 主な API・オプション

- `useDrag`（`react-aria`）— 内部で `useDescription` を使う
- `ListLayout`（`react-stately`）— 仮想化したリストのレイアウト。横方向のドロップ位置の計算を修正

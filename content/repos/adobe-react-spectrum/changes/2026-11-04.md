## 新機能

### Table の `Row` にフォーカスイベント（[#10857](https://github.com/adobe/react-spectrum/pull/10857)）

> [!tip] 何ができるようになったか
> RAC の Table の `Row` が `onFocus`・`onBlur`・`onFocusChange` を受け付ける。既存の `useFocus` を使い、`GridListItem` と同じ形。
>
> - **使い方**: `<Row onFocusChange={...}>`
> - **嬉しい場面**: 行がフォーカスを得た・失ったときにプレビューなど別の UI を更新したいとき
> - **注意**: コールバックは行自体のフォーカスだけを報告し、セルやボタンなど内側へのフォーカスは別扱い（右矢印でセルに移ると行の blur が呼ばれ、子孫間の移動では行のコールバックは呼ばれない）。#6460 のうち Table の Row の部分

⏳ 未リリース · トピック: [[repos/adobe-react-spectrum/topics/Collections|Collections]]

### Tree の項目に説明テキスト（[#10710](https://github.com/adobe/react-spectrum/pull/10710)）

> [!tip] 何ができるようになったか
> Tree の項目で `Text slot="description"` を使えるようになった（#10665）。GridList と同じアクセシビリティの挙動で、継承した `aria-labelledby` により行の名前に説明も含まれる（例: 「Projects Shared project files」）。
>
> - **使い方**: `TreeItem` の中に `<Text slot="description">…</Text>`
> - **変更点**: Tree 固有の上書きを削除し、スロット・Storybook・ドキュメント（`Tree.mdx`）を追加。共有の GridList のフックは変更なし

⏳ 未リリース · トピック: [[repos/adobe-react-spectrum/topics/Collections|Collections]]

## 変更・修正

### optimize-locales-plugin: Turbopack の loader の `locales` を mutable な配列の型に（[#10889](https://github.com/adobe/react-spectrum/pull/10889)）

> [!quote] Before
> `optimizeLocales.turbopack()` が loader のオプションを `{locales: readonly string[]}` と宣言していたため、返した `rules` を型付きの `NextConfig` に展開すると、実行時は動くのに TS2322（`readonly string[]` を mutable な `JSONValue[]` に代入できない）になっていた（#10880）。

> [!success] After
> Next.js に渡す loader のオプションを `string[]` と宣言する（`LocalesPlugin.d.ts`）。入力の `Options` は `readonly string[]` のままなので、`as const` の配列も渡せる。`next@16.4.2`・TypeScript 6.0.3（`strict`）で `tsc --noEmit` が通ることを確認。

⏳ 未リリース · トピック: [[repos/adobe-react-spectrum/topics/ロケール最適化|ロケール最適化]]

### TabPanels: 入れ子の中身を描画した後に測り、サイズの変数を継承しない（[#10819](https://github.com/adobe/react-spectrum/pull/10819)）

> [!quote] Before
> TabPanels は新しいパネルをマウントしたのと同じコミットで新しいサイズを測っていたため、入れ子の Tabs の TabList・TabPanel がまだ描画されておらず、外側のパネルが誤った高さへアニメーションして、`auto` に戻るときに跳ねていた（#10292）。また `--tab-panel-height` / `--tab-panel-width` はアニメーション中の外側の TabPanels にしか設定されず、入れ子の TabPanels が外側のピクセル値を継承していた。

> [!success] After
> layout effect から予約した `requestAnimationFrame` で（描画の前、入れ子のコレクションが反映された後に）測ってトランジションを始め、すべての TabPanels が両方の変数をインラインで `auto` と定義する。

⏳ 未リリース · トピック: [[repos/adobe-react-spectrum/topics/Tabs|Tabs]]

### ComboBox: 入力欄と Popover が別の shadow root にあってもキーボードで開ける（[#10631](https://github.com/adobe/react-spectrum/pull/10631)）

> [!quote] Before
> `ComboBoxInput` と `Popover` が別々の shadow DOM のツリーに描画されると、`virtualBlur` イベントの `relatedTarget` が最も近い shadow を含む祖先に付け替えられるため、キーボードで開いた Popover がすぐ閉じていた。

> [!success] After
> 別の shadow root でもキーボード操作が正しく動く（`useComboBox.ts`・`focus/virtualFocus.ts` を修正し、ブラウザテストを追加）。

⏳ 未リリース · トピック: [[repos/adobe-react-spectrum/topics/ComboBox|ComboBox]]

### ComboBox: `isReadOnly` のときは blur で値を確定しない（[#10869](https://github.com/adobe/react-spectrum/pull/10869)）

> [!quote] Before
> 読み取り専用の ComboBox でも blur で `commitValue()` が走っていた。`value` と `inputValue` の両方を制御し、選択中の項目がコレクションに無い（非同期の項目がまだ読み込まれていないなど）と、変更イベントが発火し、選択から入力テキストを作るアプリではユーザーが触っていない欄が消えることがあった（#10846）。

> [!success] After
> `isReadOnly` のときは blur での確定を飛ばす（`useComboBoxState.ts`）。`onChange` / `onSelectionChange` は発火しない。

⏳ 未リリース · トピック: [[repos/adobe-react-spectrum/topics/ComboBox|ComboBox]]

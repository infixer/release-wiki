## 変更・修正

### Select の props から効果のない `excludeFromTabOrder` を削除（[#10790](https://github.com/adobe/react-spectrum/pull/10790)）

> [!quote] Before
> `Select`（と `useSelect`、それを使う S2・v3 の `Picker`）の型に `excludeFromTabOrder` があったが、指定しても何も起きなかった（#7221）。メンテナーのコメントでは、もともと Select の API に含める意図は無かった。

> [!success] After
> `AriaSelectProps` が `FocusableDOMProps` の代わりに `Omit<FocusableDOMProps, 'excludeFromTabOrder'>` を継承する。実行時にこの prop を読む箇所は無いため、型だけの変更。RAC の `SelectProps`、S2・v3 の `Picker` の型と生成ドキュメントからも消える。

> [!warning] 移行が必要
> `Select` / `Picker` に `excludeFromTabOrder` を渡しているコードは型エラーになるので、指定を削除する（もともと効果は無い）。

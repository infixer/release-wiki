## 新機能

### React Aria Components に `Sheet` コンポーネントを追加（[#10674](https://github.com/adobe/react-spectrum/pull/10674)）

> [!tip] 何ができるようになったか
> `react-aria-components` に、ビューポートの端からスライドして出てくるスワイプ可能なオーバーレイ `Sheet` を追加した。スナップポイント、重ね表示（stacking）、スワイプ操作に同期したアニメーション、オーバースクロール時のパディング、複数の配置とスワイプ方向に対応する。
>
> - **仕組み**: JavaScript でタッチを処理せず、ブラウザ標準のスクロール操作・CSS scroll snapping・view timeline の上に実装しており、ネイティブの 120fps で動く。`position="bottom"` の場合、200vh の高さのスクロールコンテナの下半分に sheet を置き、表示時に `scrollTo({top: '100vh', behavior: 'smooth'})` で入場アニメーションを行う
> - **アニメーション**: 背景と sheet 本体は `swipeAnimation`（スワイプに同期する CSS アニメーション、view-timeline 利用）に、重ね表示は `stackAnimation` に対応。タイムライン ID は `html` 要素で定義され、`SheetContent` 要素に結び付けられる
> - **変更箇所**: `src/Sheet.tsx`（新規）・`exports/Sheet.ts`（新規）・`Modal.tsx`、ストーリーと docs の例

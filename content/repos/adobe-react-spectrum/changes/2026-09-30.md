## 新機能

### PromptField で生成中も送信ボタンを表示（steering）、S2 Menu の仮想化に対応（[#10614](https://github.com/adobe/react-spectrum/pull/10614)）

> [!tip] 何ができるようになったか
> Coworker で使ってみて見つかった不足を埋める PR。`PromptField` は、応答の生成中でも欄にテキストが入っていれば送信ボタンを表示し、生成中に追加の指示を送る「steering」ができるようになった。S2 の `Menu` が仮想化（virtualized）に対応し、`PromptField` の `renderCompletions` のメニューで使われている。
>
> - **ExecutionTraceItems**: `onExpandedChange` を追加
> - **キー入力**: ユーザー指定の `onKeyDown` をトークンフィールドより上に移し、オートコンプリートのドロップダウン操作中のキー入力でコールバックが呼ばれないように
> - **見送り**: `renderCompletions` メニューでの非同期読み込みスピナーは今回は対象外

### Chat API の簡素化とデザイン調整（[#10577](https://github.com/adobe/react-spectrum/pull/10577)）

> [!tip] 何ができるようになったか
> `@react-spectrum/ai` の `Chat` / `Thread` コンポーネントの余白をデザイン仕様に合わせ、スレッドにスクロールフェードを追加した。これまでストーリー側に書いていたスタイルの一部を `Chat` / `Thread` に取り込み、API 全体を簡素化した（exports も整理）。S2 docs の AI コンポーネントページも更新。
>
> - **決まったこと**: スクロールボタンは（当面）必須。`ThreadItem` の自動ラップは見送り、各コンポーネントを個別に包む形のまま。`Thread` 内の GridList のスタイルは当面固定
> - **今後**: スタイルなし版は作る方針だが後回し

⏳ 未リリース · トピック: [[repos/adobe-react-spectrum/topics/AI-コンポーネント|AI-コンポーネント]]

### S2 の SideNav を SidePanel 内で折りたためるように（[#10421](https://github.com/adobe/react-spectrum/pull/10421)）

> [!tip] 何ができるようになったか
> S2 の `SideNav` に、SidePanel の中に置いたときの折りたたみ動作を実装し始めた。折りたたんだ状態では、子を持たないトップレベルのリンクはすぐに遷移し、子を持つ項目は SidePanel を開いて下の階層へ進めるようにする。
>
> - **補足**: 折りたたみ時に項目が展開するのか遷移するのか分かりにくい点はデザインと検討中。各言語の翻訳文字列（`intl/*.json`）も追加されている

⏳ 未リリース · トピック: [[repos/adobe-react-spectrum/topics/SideNav|SideNav]]

### React 18 で S2 の SideNav がビルドエラーになる問題を修正（[#10675](https://github.com/adobe/react-spectrum/pull/10675)）

> [!quote] Before
> React 18 では `ViewTransition` が存在しないため、webpack で `@react-spectrum/s2` の `SideNav` をビルドすると「`export 'ViewTransition' ... was not found in 'react'`」というエラーになっていた。

> [!success] After
> `import *` ではなく React のデフォルトエクスポートを使うようにし、React 18 でもビルドできるようにした。

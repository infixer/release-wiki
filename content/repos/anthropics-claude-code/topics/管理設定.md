## 概要

組織が配布する managed settings（`managed-settings.json`）と `managed-mcp.json` まわり。
リポジトリの `examples/settings/` には設定例があり、HIPAA の構成が適用された組織向けに、セッションの内容が開発者のコンピューターの外へ出る経路を絞る例（`settings-hipaa.json`・`managed-mcp-hipaa.json`・`README-hipaa.md`）が加わった（Claude Code v2.1.285 以降が必要。出発点としてのサンプルで、要件を満たすかの確認は各組織の責任）。
v2.1.296 では、managed settings の `PreToolUse` フックが `"continue": false` で拒否したとき（managed の `prompt` フックのブロックも同様）にターンが終わらない問題や、managed settings の PostToolUse フックで `updatedMCPToolOutput` が効かないことがある問題が修正された。

## 主な API・オプション

- `examples/settings/settings-hipaa.json` — HIPAA 向けの `managed-settings.json` の例
- `examples/settings/managed-mcp-hipaa.json` — HIPAA 向けの `managed-mcp.json` の例
- `examples/settings/README-hipaa.md` — 各設定の理由・編集箇所・確認方法・対象外の範囲

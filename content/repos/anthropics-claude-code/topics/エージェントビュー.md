## 概要

エージェントビュー（`claude agents`）とバックグラウンドのセッション・サブエージェントの扱い（リリースノートに載った変更）。
v2.1.299 で、エージェントビューの `/effort`・`/fast` が新しいセッションの既定を設定するようになり、引数なしの `/model`・`/effort`・`/fast` はピッカーを開く。`--safe-mode` で始めたバックグラウンドセッションには peek パネルに「safe mode」の行が出る。
v2.1.300 では、PR の状態の更新、`/tasks` からのサブエージェントの消失、パンくずの表示、一気に届いた入力の誤認、クラウドセッションのコンテナ置き換え後の再開の扱いなどが修正された。mod からは `$.ui.view({ agentId })` でエージェントの transcript をメインビューに出せる。
v2.1.311 で、サブエージェントの隔離 worktree がそこで起動したバックグラウンドのサブエージェントの作業中に削除される問題、auto mode のバックグラウンドエージェントが自分のシェルを待つたびに新しいメインのターンを始める問題、サブエージェントが開始後に接続した MCP サーバーのツールを使えない問題が修正された。v2.1.312 では、エージェントビューで終了直前に Ctrl+C で消した入力が次の起動で戻る問題と、空の `!` 入力から Ctrl+D で終了するとシェルモードで開き直す問題が修正された。
v2.1.319 で、`/tasks` に終了したサブエージェントを一覧する「Earlier in this session」の行が加わり、一覧から消えた後や再起動後でも開き直してメッセージを送れる。MCP サーバーが task として実行するツール呼び出しは、すぐにバックグラウンドへ移され、終わったら結果が Claude に伝えられる（`CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` で待つように）。

## 主な API・オプション

- エージェントビューの `/effort` / `/fast` / `/model` — 新しいセッションの既定（引数なしでピッカー）
- `--safe-mode` — バックグラウンドセッションの peek パネルに表示
- `$.ui.view({ agentId })` — mod からエージェントの transcript を表示（詳しくは [[repos/anthropics-claude-code/topics/mod-API|mod API]]）
- `/tasks` の「Earlier in this session」 — 終了したサブエージェントを開き直す（v2.1.319）
- `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` — MCP task をバックグラウンドに移さずツール呼び出しの中で待つ（v2.1.319）

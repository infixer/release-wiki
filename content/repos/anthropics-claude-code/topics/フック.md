## 概要

Claude Code のフック（settings の command・HTTP・`prompt`・`agent` フックと、mod の hooks モジュール）まわり。
command・HTTP フックは `onFailure: "block"` を指定すると、起動できない・タイムアウト・想定外の終了コードのときに操作を通さずブロックする。
「Block commands that...」のように指示の形で書いた `prompt`・`agent` フックが、ブロックすべきものを通してしまう問題は修正済みで、Stop・SubagentStop の `prompt` フックの判定も Claude が早く止まりにくいよう改善された。
mod の `classic.*` イベントのフックが、プラグインのフックワーカーの再起動中に飛ばされる問題も修正されている。

## 主な API・オプション

- `onFailure: "block"` — command・HTTP フックが失敗したときに操作をブロックする
- `prompt` / `agent` フック — 指示の形で書いた判定（Stop・SubagentStop を含む）
- `classic.*` — mod の hooks モジュールが受け取るイベント

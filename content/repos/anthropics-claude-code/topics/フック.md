## 概要

Claude Code のフック（settings の command・HTTP・`prompt`・`agent` フックと、mod の hooks モジュール）まわり。
command・HTTP フックは `onFailure: "block"` を指定すると、起動できない・タイムアウト・想定外の終了コードのときに操作を通さずブロックする。
「Block commands that...」のように指示の形で書いた `prompt`・`agent` フックが、ブロックすべきものを通してしまう問題は修正済みで、Stop・SubagentStop の `prompt` フックの判定も Claude が早く止まりにくいよう改善された。
mod の `classic.*` イベントのフックが、プラグインのフックワーカーの再起動中に飛ばされる問題も修正されている。
v2.1.296 では、managed settings の `PreToolUse` フックが `"continue": false` で拒否したとき・managed の `prompt` フックがブロックしたときにターンも終わるようになり、managed の PostToolUse フックの `updatedMCPToolOutput` が常に効くようになった。`UserPromptSubmit` フック（と mod の `prompt.submit` フック）の実行中の Esc・中断でヘッドレスセッションが終わる・プロンプトが消える・チェック前のプロンプトが通る問題、プラグインのヒントタグに似たテキストを含むフック出力が書き換えられる問題、同名のプラグインが先に動いていると後から読み込んだプラグインの SessionStart フックが飛ばされる問題も修正された。`/plugin` は、同名の別プラグインが有効なためにフックが外されたプラグインに注記を出す。
v2.1.300 でバックグラウンドのコマンドが動いている間に終了すると SessionEnd フックが動かないことがある問題が、v2.1.301 で `WorktreeCreate` フックが作った worktree を終了時に確認なしで削除する問題と、PreToolUse フックが Edit・Write を対象にしていると artifact の更新が拒否される問題が修正された。
v2.1.310 で、Windows で Git Bash が無く、フックのコマンドが引用符で囲んだ文字列だけのとき PreToolUse・PermissionRequest フックがツール呼び出しを通してしまう問題が修正された。

## 主な API・オプション

- `onFailure: "block"` — command・HTTP フックが失敗したときに操作をブロックする
- `prompt` / `agent` フック — 指示の形で書いた判定（Stop・SubagentStop を含む）
- `classic.*` — mod の hooks モジュールが受け取るイベント

## 概要

このリポジトリの `.claude-plugin/marketplace.json` で配っている `claude-code-plugins` マーケットプレイスまわり。
2026-10 に、プラグインの本体を [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official) に一本化した。マーケットプレイスは全プラグインを claude-plugins-official からインストールし、`plugins/` にあった古いコピーは削除された。
既存の `name@claude-code-plugins` の ID はそのまま使える。改名・削除はマーケットプレイスの `renames` マップに記録される（`renames` を読まない古いクライアントでは「not found in marketplace」エラーになる）。
`ralph-wiggum` は `ralph-loop` に改名され、公式のコピーが無い `claude-opus-4-5-migration` は廃止された。
`security-guidance` は一度削除（[#105270](https://github.com/anthropics/claude-code/pull/105270)）された後、[#105303](https://github.com/anthropics/claude-code/pull/105303) で再び一覧に載ったが、削除を適用済みのクライアントでは `/plugin enable` するまで無効のまま。

## 主な API・オプション

- `.claude-plugin/marketplace.json` の `renames` — プラグインの改名・削除の記録
- `/plugin install <name>@claude-plugins-official` — 公式マーケットプレイスからのインストール
- `/plugin enable` — 無効になったプラグインを有効に戻す
- `blockedMarketplaces` — `git-subdir` の URL には効かない（#105303 の注記）

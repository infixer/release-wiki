## 概要

`mods/telemetry` は、Claude Code のアナリティクスが有効な環境で、ビルトインのプラグイン向けにもテレメトリを収集する mod。呼び出し元（`next.origin`）を確認し、個人がインストールしたプラグインや管理者が拒否したプラグインは理由付きで拒否する。行は CLI 本体と同じ内容（デバイス・アカウント ID、クライアント種別、entrypoint、`env` ブロックなど）を `$` 経由でセッションに 1 回集めて持ち、エンジンだけが知る情報（バージョン・ビルド時刻・ランタイム）は空のまま扱う。行はキューに入り、最初の数秒後・100 件到達時・セッション終了時にバッチで送信され（1 回リトライ）、`log` / `mark` はキューに入った時点で解決する。CLI が守るアナリティクスのオプトアウトはすべて尊重し、送信の都度読み直す。

## 要点

- 追加: `permissions.blockWritesOutsideWorkingDirectories`。どの権限モードでも、Write・Edit・NotebookEdit が作業ディレクトリの外のパスを拒否する
- 追加: Claude apps gateway の upstream に任意の `groups` 一覧。一覧の IdP グループに属する開発者だけがその upstream に送られる（failover でも同じ）
- 追加: Claude apps gateway の Bedrock upstream に `guardrail_trace`。どの Amazon Bedrock guardrail のフィルターがリクエストに反応したかを、一致したテキスト抜きでログに残す
- 追加: VS Code と Claude Desktop の Code タブにアイドル時の compaction。200K トークン以上の会話を放置すると要約し、プロンプトキャッシュが切れていれば次のメッセージでその要約を使う
- 修正: 組織の管理者がモデルの effort に上限を設けていると「Invalid effort level」でターンが失敗し続ける問題（effort を下げて再試行し、使うレベルを伝える）
- 修正: 起動に失敗したとき `claude -p` が何も出力せず終了コード 0 で終わる問題（エラーを出して 1 で終了）。Bedrock で画像が多いセッションが毎ターンと `/compact` で「400 Input is too long.」になる問題（古い画像を外して compact する）
- 修正: Microsoft Foundry で既定の Sonnet・Opus・Haiku のデプロイが無いと失敗する問題（同じファミリーの古いモデルに切り替える）。tool search の `tool_reference` ブロックを受け付けない gateway の背後で拒否が続く問題（tool search 無しで 1 回送り直し、セッション中は覚える）
- 修正: managed settings まわり（Claude Desktop で管理者の TLS の信頼設定が効かない、自分の `--plugin-dir`・`--plugin-url` のプラグインが壊れているとモデル切り替えが拒否される、モデルを固定していても Bedrock・Vertex のアップグレードの提案が毎回出る、リモートの managed settings だけにある `forceRemoteSettingsRefresh` が保存済みのコピーの期限切れ後に効かずポリシー無しで起動しうる）。ほかに MCP のサインイン、`claude mcp logout`、CI での `claude ultrareview`・`claude remote-control` の信頼確認、TLS の `UNABLE_TO_GET_ISSUER_CERT` などの修正（本文は途中で切れている）

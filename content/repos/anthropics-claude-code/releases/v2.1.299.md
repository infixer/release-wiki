## 要点

- アイドル時の compaction を追加: ターミナルで 200K トークン以上の会話を約 54 分放置すると、1 時間のプロンプトキャッシュが切れる前に compact し、次のメッセージで全体を処理し直さずに済む。最小トークン数は `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` で変更でき、settings.json の `"idleCompaction": false` で無効にできる（どちらも v2.1.290 以降が必要）
- `CLAUDE_CODE_DISABLE_FILE_MENTIONS` を追加: `@` のファイルメンションで、ファイルの中身ではなくパスを渡し、Claude がファイルツールで読む
- managed settings でインストールした mod 向けに `$.prompt.media`（`prompt.submit` フックで添付の画像・文書のバイト列を読める）と `$.session.identity()`（サインイン方法と、managed の `forceLoginOrgUUID` にある組織ならその組織とメールアドレス）を追加
- mod の UI: `Text` に `size`・`weight`・`mono`・`tabular`、`Box` に名前付きの間隔（`xs`〜`xl`）。`bold` は非推奨になり `weight` に置き換え。`skill.prompt` フックにスキルの frontmatter・ソース・プラグイン名・ファイルパスを渡し、`session.append` フックに `queue` を追加
- エージェントビューで `/effort`・`/fast` により新しいセッションの既定を設定（引数なしの `/model`・`/effort`・`/fast` はピッカーを開く）。`--safe-mode` で始めたバックグラウンドセッションには peek パネルに「safe mode」の行を表示
- Claude apps gateway の背後のセッションで attribution ブロックにフィールドを追加。gateway の `code` ポリシーの `env` に `CLAUDE_CODE_ATTRIBUTION_HEADER=0` を設定すると、Claude Desktop の Code タブでも attribution ブロックを外せる
- そのほかの追加: `claude self-hosted-runner orchestrator` に `--shutdown-drain-sec`（SIGTERM 時に処理中のポーリングと spawn フックの終了を待つ）、`claude plugin eval` に `--disallow-tools` と `disallowed_tools`、`/plugin`・`claude plugin validate` で組織が管理する環境で飛ばされる mod のフックを注記、`/usage` に max effort・ワークフロー・常時のコンテキスト・大きなツール結果の警告、plan mode が確認なしで編集する場合の 1 回限りの注記
- 修正: `apiKeyHelper` のキー使用時にクラウドセッションの拒否エラーが別の組織を指す問題、独自の `ANTHROPIC_BASE_URL` の背後で gateway 固有のモデル名を使うと 200K トークン付近で「Prompt is too long · automatic compaction failed」になる問題など（本文は途中で切れている）

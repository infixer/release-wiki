## 要点

- managed setting `availableModelsMatch` を追加：`"exact"` にすると `availableModels` の各エントリはその名前のモデルバージョンだけを許可し、新しいリリースは列挙するまでブロックされる
- managed setting `deniedModels` を追加：`availableModels` で許可されていても特定のモデルをブロックできる
- `/doctor prompt-audit`（`/checkup prompt-audit` でも可）を追加：CLAUDE.md・skills・agents・commands に、古いモデル向けに書かれたプロンプトのパターンが無いかを監査する
- ゲートウェイのヒントヘッダーに `x-claude-code-prompt-id` を追加（1 つのユーザープロンプトに対応するリクエストをまとめられる。`CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` でオプトイン）
- `OTEL_LOG_TOOL_CONTENT=1` のとき、MCP ツール・WebFetch・WebSearch の出力も OpenTelemetry の `tool.output` span event に含める
- Claude apps gateway に、上流へ送らずに定型の応答を返す負荷試験用の `load_test_mode` と、Amazon Bedrock の Mantle エンドポイント向けの `mantle` upstream provider を追加
- MCP 関連の修正：バックグラウンドに移った長時間のツール呼び出しで進捗通知が捨てられる問題、起動中にセッションが終わると stdio MCP サーバーが残る問題、ステートレスなリモート MCP サーバーの一時的な 404 でそのサーバーがセッション中ずっと使えなくなる問題など
- `claude plugin validate` が、インストールできないプラグイン名・マーケットプレイス名を受け入れていた問題を修正（`marketplace.json` 内のそうした名前は検証エラーに）

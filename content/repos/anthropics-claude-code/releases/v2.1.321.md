## 要点

- 追加: Claude Fable 5.2（`claude-fable-5-2`）。Fable の既定モデルになる。1M コンテキスト、入力 $8 / 出力 $40（100 万トークンあたり）、キャッシュ読み取り $0.20
- 追加: `claude remote-control` に `--settings <file>`（起動するすべてのセッションに設定ファイルを適用。ファイルが変わると、`claude remote-control` を再起動するまで新しいセッションを開始しない）
- セキュリティ修正: サーバーがリダイレクトしたとき、MCP の OAuth のリクエストがリフレッシュトークンなどの秘密情報を別のホストに送っていた問題
- セキュリティ修正: 読み取り専用の Bash コマンドが権限の確認なしにサンドボックスの外で実行される場合があった問題、Bash の権限チェックが誤ったフォルダーを基準にファイルの書き込みを判定して確認しなかった問題、ディレクトリへの `cp`・`mv` が書き込むファイルに deny ルールと保護ファイルの確認が適用されなかった問題
- 修正: ネットワークパス（UNC 共有・WSL のフォルダー・`/net` のマウント）で Edit が複数の一致の最初を書き換える・空の `old_string` でファイル全体を置き換える、`NotebookEdit` がセルの指定の無い呼び出しで先頭のセルを削除・上書きする問題
- 修正: `/config` で、新しいセッションが auto mode で始まるのに既定の権限モードが Manual と表示される問題（「Auto (default)」で Space を押すと Plan ではなく Don't Ask を保存する）
- 修正: Windows で `watchPaths` で設定したパスの `FileChanged` フックが止まる問題、会話がコンパクションされたときに auto mode がバックグラウンドのサブエージェントの報告を失う問題、ツール定義のコンテキスト使用量の過大な見積もり、Remote Control（Web・モバイル）で `/compact` が 2 回表示される問題、プラグインの自動更新がワークツリー・フォルダーごとに再ダウンロードする問題 など（本文は途中で切れている）

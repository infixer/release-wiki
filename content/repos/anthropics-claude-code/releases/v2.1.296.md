## 要点

- Claude apps gateway: `managed.policies[]` に `code` キーを追加（`cli` と同じ設定を Claude Desktop の Code タブにも適用。`desktop` と並べると Claude Desktop の gateway モードを有効にする）
- サブエージェントの frontmatter と `--agents` の定義に `autoCompactWindow` を追加（メイン会話のウィンドウより早く自動 compact できる）
- 環境変数を追加: `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL`（ワークフローのエージェントをすべて 1 つのモデルで動かす。他のサブエージェントは各自のモデルのまま）、`CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS`（overloaded（529）のリトライのバックオフの最大待ち時間を長くする）
- Read ツールに `allow_large` オプション（ファイル全体が必要でコンテキストに余裕があるとき、通常のサイズ上限を超えるテキストファイルを 1 回で読める）
- `/plugin` で、同じ名前の別のプラグインが有効なためにフックが外されたプラグインに注記を表示
- フックの修正: managed settings の `PreToolUse` フックが `"continue": false` で拒否したとき・managed の `prompt` フックがブロックしたときに、呼び出しは拒否してもターンを終えていなかった問題、managed settings の PostToolUse フックで `updatedMCPToolOutput` が効かないセッションがある問題、`UserPromptSubmit` フックや mod の `prompt.submit` フックの実行中に Esc・中断するとヘッドレスセッションが終わる・入力したプロンプトが消える・チェック前のプロンプトが通る問題、プラグインのヒントタグに似たテキストを含むフック出力が書き換えられる問題、ヘッドレスセッション開始後に読み込んだプラグインの SessionStart フックが、同名（別表記を含む）のプラグインが先に動いていると飛ばされる問題
- gateway の修正: `allowedProviders` に `"gateway"` を返す gateway が、ユーザー設定でその gateway を指定したノート PC を締め出す問題、managed settings が `forceLoginMethod: "gateway"` で `forceLoginGatewayUrl` を指定しないマシンで保存済みの gateway のサインインが無視される問題（2.1.295 での退行）
- その他の修正: フォルダで無効にした `.mcp.json`・プラグインの MCP サーバーがディレクトリ移動・プラグイン再読み込み後にヘッドレスセッションで起動する、`--teleport` で履歴を読めないとき空の会話が開く、adaptive thinking のみのモデル（Haiku 5.5 など）のトークン数が一部の gateway の背後で失敗し他では budget thinking として数えられる、セッション終了で中断したツール呼び出しを、再開したサブエージェントが「ユーザーが拒否した」と伝えられる、共有 transcript・デバッグログの秘密情報のマスクで値の無いキーに続く値（シェル文字列内の JSON を含む）が漏れる、古い VTE 系ターミナル（MATE Terminal など）でコピー後に `52;c;…` が表示される、`/diff` のパネル・ダイアログを開いている間トースト・通知が表示されずに待たされる、など（本文は `claude self-hosted-runner` の修正の途中で切れている）

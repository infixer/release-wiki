## 要点

- 非推奨: Opus 4.8 の fast mode を 2026-10-30 付けで非推奨にし、2026-11-30 に削除する。削除後は Opus 4.8 の fast mode のリクエストはエラーになり、通常の Opus 4.8 にはフォールバックしない。高速化を続けるには Opus 5.5 へ移行する
- 追加: `CLAUDE_CODE_DISABLE_ULTRATHINK`（`ultrathink` キーワードを無効にする）、`CLAUDE_CODE_SUBAGENT_EFFORT`（ほかで指定が無いときにサブエージェントが使う effort。セッションの値を継承しない）
- 追加: Claude apps gateway にグループで共有する月間予算（spend limits の管理 API の `pooled_budget`。各メンバーの個別の上限に加えて適用）、`managed.policy_mode: layered`（一致したポリシーをすべて適用し、下のものに上のものを重ねる）、Bedrock upstream の `guardrail.input_tagging`（Bedrock guardrail の prompt attacks フィルター用の入力タグでプロンプトを囲む。`all_messages_and_system` でシステムプロンプトも対象）
- 追加: `CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP`（互いを証明し合うループ状のシステムのクロス証明書を残す。プライベート CA で必要なサーバー向け）
- 修正: Claude apps gateway がリクエストで指定されたすべてのモデルを `availableModels`・`deniedModels`・`models` で確認していなかった問題（ブロックされたモデルは、該当フィールドを示す 400 になる）。managed settings で gateway が必須のときに `claude auth login` が実行を拒否する問題（ターミナルでは gateway のサインインを表示）
- 修正: Claude Code が自分で終了したとき（認証情報の拒否、クラウドセッションのアーカイブなど）に macOS・Linux でシェルコマンドが動き続ける問題。Bash ツールで改行を含むエイリアスや `-` で始まる関数名が壊れる問題、`SHELLOPTS` を export していると最初のコマンドで止まる問題
- 修正: Vertex AI・Amazon Bedrock で `sonnet`・`opus`・`haiku` の最新モデルが使えないアカウントやリージョンで、古いモデルに切り替えずにセッション中にエラーを出す問題。`--restricted` のセッションが Read の allow ルールに含まれる作業ディレクトリ外のファイルをアップロードする問題
- 修正: PowerShell のフックが型キャスト・`param`・`using`・属性で始まると終了コード 2 でブロックしない問題、不可視文字を含むプロンプトの送信に Enter が 2 回必要な問題、managed の `autoMode.allow` に `"$defaults"` が無いのに組み込みの例外が戻る問題など（本文は途中で切れている）

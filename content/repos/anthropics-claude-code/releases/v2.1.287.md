## 要点

- Claude Mods を追加: プラグインがより深い挙動を変更できるように
- ビルトインの mod「You should know」を追加: サイドのエージェントが見張り、あなたや Claude が見落としそうなことを知らせる。`/plugin enable cc-plugin-you-should-know@builtin` で有効化（ファーストパーティのセッションでテレメトリが有効な場合）
- エージェントビューに、セッション名とタスクにマッチする `n:<text>` フィルターを追加（折りたたまれたセクション内の一致も表示し、Enter で最初の一致を開く）
- OpenTelemetry の `user_prompt` イベントに `prompt_text`（`prompt` のコピー）を追加。`prompt` を削除・マスクしている場合は `prompt_text` も同様に扱う必要がある
- 2025-11-25 プロトコルの MCP サーバーからの URL プロンプト（サインインなど）に対応。更新後に接続できなくなったサーバーは、MCP 設定に `"bareElicitationCapability": true` を追加する
- Windows: Bash ツールを拒否すると PowerShell ツールも無効になり、シェルツールが無くなる場合に起動時に警告
- セルフホストランナー: GitHub CLI が無い macOS・Linux で、Anthropic 管理の git を使うセッション向けに組み込みの `gh api`（REST のみ）を追加
- 修正: `/` やホームディレクトリへの `rm` のような危険なコマンドが、`~` やワイルドカードのパスへの出力リダイレクトを含むと常に確認する保護が外れていた問題、再開・コンパクション後にフォルダの CLAUDE.md が二重に添付される問題、`asyncRewake` のフックのスクリプトが無いと何度も Claude を起こす問題など

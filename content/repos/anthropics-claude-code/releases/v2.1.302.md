## 要点

- `CLAUDE_CODE_AUTO_MODE_MODEL` を追加: クライアント側の auto mode の分類器が使うモデルを選ぶ（サーバー側の auto mode のモデルは変わらない）
- `/config` に `Idle compaction` の行を追加し、アイドル時の compaction をオフ・オンにできるように。アイドル compaction 後の通知にもオフにする方法が出る
- `/design-sync`・`/design-login` に、単体の Claude Design（claude.ai/design）が 2026-12-14 までに終了するという通知を追加
- 修正: compact 中にターンを止めたときの「Prompt is too long」エラー、セッション途中で Vertex・Bedrock に切り替えた後の「diagnostics: Extra inputs are not permitted」、Read ツールが任意のサイズの画像（や画像名のパイプ・デバイス）をすべてメモリに読み込む問題（128 MB を超える画像は拒否）
- 修正: gateway が `anthropic/claude-opus-4-1` のように接頭辞付きで Opus 4 / 4.1 を名指すと `/autocompact`・`/effort` が別のモデルに保存される問題、セッション途中で追加したツールを ToolSearch や compaction 後に読み直すとプロンプトキャッシュが外れる問題
- 修正: `claude plugin` などのサブコマンドが設定の書き込み完了前に終了する問題、git の既定が reftable の環境でプラグインのマーケットプレースが毎回 clone し直される問題、PowerShell ツールがプラグインの `bin/` のコマンドを見つけない問題
- 修正: OpenTelemetry の `tool_decision` で auto mode の分類器のブロックの多くに `classifier_category` が無い問題と、`OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT` が小さいと新しい属性が `tool_use_id`・`tool_source`・`tool_parameters` を押し出す問題
- そのほか: エージェントビューで長い一覧を下に移動・セクションを折りたたむと行が空になる問題、プロトコル 2026-07-28 を交渉するが `resultType`・`ttlMs`・`cacheScope` を省く MCP サーバーでツールが出ない・呼び出しが失敗する問題、クレジットで払うモデルでプロンプトの提案が使用クレジットを消費する問題、など（本文は途中で切れている）

## 要点

- 追加: Code Mode（実験的なオプトイン）。Claude が JavaScript を書いてツールを呼び出す。有効化・組織での無効化は https://code.claude.com/docs/en/code-mode を参照
- 追加: `plugin.json` の `engines["claude-code"]`。記載した Claude Code のバージョン範囲の外ではプラグインをインストール・更新・読み込みせず、インストール・更新は範囲に合う最新のバージョンを選ぶ
- 追加: `claude plugin validate` がプラグインの TypeScript の hooks モジュールを型チェックする（指摘は警告で、`--strict` なら失敗）。mod の `engine.create` フックが追加・保留・置き換える `$` の名詞も表示する
- 追加: Claude Desktop のサードパーティプロバイダーのセッション向けに、managed settings で `CLAUDE_CODE_AUTO_MODE_MODEL` を設定できる（Claude Desktop がこのバージョンを取り込んでから有効）
- 追加: `claude -p` と SDK のセッションで、フックが長く動いている間 30 秒ごとに進捗のハートビートを送る（Claude Desktop などのホストがターンを応答なしとして終わらせないように）
- 追加: 使用クレジットがオフ・使い切りのときにモデルが使用クレジットを必要とした場合のオプションメニュー（停止・使用クレジットへの切り替え・アップグレード）、Artifact ツールのアセットのアップロードで `.docx` に対応、diff パネルに `/diff to close` のヒント
- 追加: 環境変数 `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES`（`1` でサブエージェントの進捗の要約とそのリクエストをオフ。2.1.318 から利用可）、`CLAUDE_CODE_RESUME_HINT_COMMAND`（終了時のヒントに起動元のプログラム自身の再開コマンドを出す）、`claude plugin install --json` の `unsetOptionCount`、mod のペインの props の `isPromptCovered`
- 追加: 起動時の警告（変数の値に `*` を含む Bash の allow ルール、例: `Bash(PORT=* npm run dev)`）、プラグインの言語サーバーが起動できないときの警告、Perforce の設定があるのにモードがオフのときの `CLAUDE_CODE_PERFORCE_MODE` の案内
- 修正: `/compact` を再度実行したとき・`/context` などのコマンドの後に実行したときに、まだ答えていないメッセージが要約で消える問題、再開したセッションで次のメッセージが再開していない古い中断メッセージにつながる問題、とても大きなファイルの変更後の次のプロンプトでのメモリの急増、セッション中に保存した設定が直前の `settings.json` の手編集を元に戻す問題（セッション中に削除した設定ファイルは削除されたままに）、`claude plugin`・`claude mcp list` がトークンの更新中に終わると Console のプロファイルからサインアウトする問題 など（本文は途中で切れている）

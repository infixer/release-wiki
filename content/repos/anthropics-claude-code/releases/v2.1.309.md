## 要点

- 修正（サンドボックス）: macOS・Linux でサンドボックスの Bash コマンドが、毎回シェルの起動ファイルをサンドボックスの外で実行していた問題、macOS の `denyWrite` のグロブがシンボリックリンク経由のフォルダで実際の場所に効かない問題、サンドボックスのコマンドや自動承認の編集が `--mcp-config` で渡した MCP 設定ファイルを変更できた問題
- 修正（権限チェック）: リダイレクトが開けない可能性のあるコマンドで設定した変数を Bash の権限チェックが信頼する問題、`cd` をラップ・接頭辞付きにしてから git を実行する複合コマンドで確認が出ない問題、サブシェルを含むコマンドで `Edit(path)` の deny ルールがそのパスへの Bash のリダイレクトを止めない問題
- 修正（worktree）: worktree で隔離したセッションが、ロケール接頭辞付きのコマンドや zsh の算術コマンドの一部を受け付けてしまう問題。Claude Code が作る worktree・ブランチのチェックアウトが git の replace refs を無視するように
- 修正: print・SDK セッションで、無効にした MCP サーバーが後の権限プロンプトで再接続される問題、設定ディレクトリがシンボリックリンク経由のときにプロファイルストアの書き込み保護が効かない問題
- 修正: とても大きなネストした CLAUDE.md の下のファイルを読むと compact を繰り返す問題（サイズ上限を超えるネストした CLAUDE.md は先頭だけを読み込む）
- 修正: ctrl+enter（すぐ送信）の挙動、`!` モードでキーに割り当てたスラッシュコマンドがシェルで実行される問題、ctrl+o で配信待ちの他のエージェント・セッションのメッセージが出ない問題（transcript の下に待ち状態として表示）、長いツール出力のプレビューが絵文字の途中で切れ、`jq` で読めない transcript になる問題
- 修正: split-pane のエージェントのチームメイトが、リーダーのコマンドラインの tool deny・`--tools` のルールを引き継がない問題、Claude Desktop のセッションの不具合、`claude remote-control` のステータス行など（本文は途中で切れている）

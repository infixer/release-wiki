## 要点

- WebFetch ツールを無効にする環境変数 `CLAUDE_CODE_DISABLE_WEB_FETCH` を追加
- `claude --desktop` を追加：現在のディレクトリ（`--continue` / `--resume <id>` ならそのセッション）で Claude デスクトップアプリを開く
- `claude plugin configure <plugin>` を追加：プラグインのオプションと未設定の項目を表示し、`--values-stdin` で標準入力から値を保存できる
- `claude plugin install --config` で `<server>.<key>=<value>` を指定でき、同梱の `.mcpb` MCP サーバーの設定をインストール時に渡せる
- managed setting `allowedProviders` を追加：そのマシンで使える API プロバイダー（Anthropic API、カスタムエンドポイント、Bedrock、Mantle、Vertex AI、Foundry、Claude Platform on AWS、Cloud gateway）を制限
- タイムアウトした非ストリーミングのフォールバックリクエストの再送回数を制限する `CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` を追加
- 修正: OS が managed settings ファイルの読み取りを拒否すると起動しなかった問題（警告を出してそのファイルのポリシーなしで起動。その他の読み取りエラーや解析できないファイルでは従来どおり停止）
- 修正: `claude -p --permission-prompt-tool` でバックグラウンドのサブエージェントの権限要求が自動拒否される問題、SSH でのプラグイン・マーケットプレイスのインストールが `GIT_SSH` / `core.sshCommand` を無視する問題、Remote Control で添付ファイルが 1 回のダウンロード失敗で抜け落ちる問題（最大 2 回再試行）など

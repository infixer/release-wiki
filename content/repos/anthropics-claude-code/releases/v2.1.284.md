## 要点

- Claude Sonnet 5.5（`claude-sonnet-5-5`）を追加し、Anthropic API での既定の Sonnet モデルに（1M コンテキスト、$2/$10 per Mtok、キャッシュ読み取り $0.20/Mtok）
- auto mode で作業ディレクトリ外を読む前の確認に「Yes, but ask again next time」を追加（その 1 回だけ許可し、以降は再度確認）
- Claude apps gateway の利用上限を `/usage` と status line に金額で表示（例: 「$271.40 / $500.00 spent this month」）。status line の `rate_limits.spend_limit` に `used_usd`・`limit_usd`・`period` を追加
- `/effort` スライダーのキーを `keybindings.json` で割り当て直せる `effortSlider:decreaseEffort`・`increaseEffort`・`toggleUltracode` アクションを追加
- 対話ターミナルで、接続に失敗した・認証が必要な MCP サーバーをまとめて再試行する `/mcp reconnect all` を追加
- Claude apps gateway: `telemetry.forward_to` の宛先に `auth: { google: {} }`（Google Cloud の OTLP エンドポイントへ直接送信）、IdP との証明書によるクライアント認証（`private_key_jwt`）、managed policy の `availableModels` が空・起動モデルを含まない場合の起動時警告を追加
- 修正: 壊れた応答ストリームで「JSON Parse error」などの生のエラーや「undefined」が出る問題（再試行または中断として報告）、thinking ブロック直後の overloaded / サーバーエラーでターンが終わる問題、compact 後も「Prompt is too long」が続く問題（さらにもう一度 compact する）
- 修正: 再開したセッションで MCP サーバーの接続中にツール呼び出しが「No such tool available」で失敗する問題（最大 10 秒待つ）、Agent SDK で不正な `source` を持つ画像を含むメッセージでセッションがクラッシュする問題

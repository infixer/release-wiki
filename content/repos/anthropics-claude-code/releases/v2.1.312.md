## 要点

- 追加: Claude apps gateway に `oidc.user_id_claim`。`sub` 以外の id_token のクレーム（Microsoft Entra ID の `oid` など）で利用者を識別できる
- 追加: 全画面表示で、キューに入ったメッセージの下の「to send now」のヒントをクリックするとすぐ送信される
- 変更: Bedrock・Vertex・Foundry・Mantle で、Claude Code が認識しないモデル名（カスタムのデプロイ名・推論プロファイルの ARN など）には、Sonnet・Haiku の前段であっても短いシステムプロンプトを使う。全文のプロンプトを使うには `CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0`
- 変更: フラグが付いたメッセージの後の自動のモデル切り替えが、認識しないモデル名にも適用される。無効にするには `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1`
- 修正: VS Code 拡張機能からサインインした後、managed settings と組織のポリシーがセッションの残りで取得されない問題
- 修正: サブディレクトリのとても大きな CLAUDE.md・ルールファイル・@ で読み込んだファイルを、先頭だけ見て上書きしてしまう問題（Write は全部読むかその場で編集するよう Claude に求める）。Bash で git リポジトリの深くへ `cd` した後、ディレクトリごとのスキルや `paths:` のスキルが見つからない問題。名前が不正なコマンドがあるとすべてのコマンドが読み込まれず `claude -p` が何も出力しない問題
- 修正: エージェントビューで、終了直前に Ctrl+C で消した入力が次の起動で戻る問題、空の `!` 入力から Ctrl+D で終了するとシェルモードで開き直す問題。vim モードの `d`・`c`・`y` と行数を超える `gj`/`gk` のカウントの扱い
- 改善: 作業中に変えた effort が次のメッセージまで待つ場合があることをプロンプトの表示で伝える。クラウドセッションで名前解決できないホストへの WebFetch のエラーが、許可されたネットワークドメインの外の可能性を説明する（本文は途中で切れている）

## 要点

- `/auto-mode-setup` を追加: プロジェクトと最近のセッションを読んで auto mode に環境を教えるガイド付きセットアップ。Bedrock・Vertex・Foundry・Claude apps gateway・テレメトリ無効のセッションでも使える
- mod の `tool.check` の回答に `decider: "person"` を追加（承認できるのは権限ダイアログかホストのコールバックだけで、尋ねる相手がいない場面では mod の理由付きで拒否される）。`tool.check` のイベントに、読み取り専用のツール呼び出しで立つ `e.isReadOnly` を追加
- 先に動くプラグインが mod のフックを飛ばしたとき、イベント名とプラグイン名を示す行を transcript に出すように
- `/claude-api managed-agents-secure` を追加: Managed Agents のエージェントの設定を Anthropic の公開セキュリティガイドと比べる（何も変更しない）
- transcript ビュー（Ctrl+O）の compaction の要約に、それまでに呼んだツールの名前を表示
- Pro・Max プランで、使われていない会話を再開すると 5 時間の使用上限のかなりの割合を使う場合に警告（そのまま再開するか、新しい会話を始めて前の会話を参照させるかを選べる）
- 修正: Linux で `sandbox.filesystem.denyRead` のグロブに文字クラスでない角括弧（`[user-id]` のようなルートフォルダ）があるとサンドボックスのコマンドが起動しない問題、マウントしたドライブやその直下のフォルダ（`/Volumes`・`/media`・WSL の `/mnt/c`）の `rm -r` に安全確認が出ない問題
- 修正: プラグインがサブエージェントを起動して headless 実行を `--max-turns`・Stop・入力終了の後も続けてしまう問題、mod の再読み込みに失敗すると残る版のツール・コマンドが消える問題、Remote Control の不具合など（本文は途中で切れている）

## 要点

- チームメイト向けの `agent.spawn`、プラグインのフックイベント全体で共通の 1 つのエージェント ID、`$.agent.list()` の idle / waiting 状態を追加
- [VSCode] サインアウトが増えた可能性がある、2.1.288 の `claude auth status` の変更を revert
- プラグインのコードペインで大きなファイルを開く速度を改善（ハイライト表示を最終的な幅で 1 回だけレイアウト）
- 修正（権限・管理）: managed なマシンで、複合シェルコマンドの入れ子部分への deny / ask ルールが、個人がインストールした mod の承認に優先されなかった問題。個人がインストールしたプラグインが、組織管理の MCP サーバーのサインインツールの説明を書き換えられた問題
- 修正（権限ルール）: シンボリックリンク経由で @ メンション・変更・IDE で選択したファイルに `Read` の deny ルールが効かない問題。サンドボックスの自動許可時に、展開値を持つ環境変数の接頭辞（例: `TZ="$HOME" rm -rf build`）や前置きの変数代入があると Bash の deny / ask ルールが効かない問題
- 修正: 閉じていない `<script>` タグが多い・`${` の入れ子が深い短いコードブロックでターミナルが固まる問題、アップグレード後の最初のセッションでインストール済みの mod が読み込まれない問題
- 修正（プラグイン・mod の描画）: localhost などのリンクでペインが何も描画しない、未知の枠線スタイルの Box で起動時に固まる、`ui.render` フックの値や `Client` の失敗でセッションが「unrecoverable interface error」で終わる（失敗した部分だけを差し替え、`ui.fault` を発生）など
- 修正（プラグインコマンド）: ローカルフォルダのマーケットプレイスからのプラグインで `plugin list` / `plugin eval` / `plugin update` が古いコピーを表示する問題、`claude plugin validate` がマーケットプレイスのマニフェストと同じフォルダのプラグインを飛ばす問題など

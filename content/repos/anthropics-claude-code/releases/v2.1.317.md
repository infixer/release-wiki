## 要点

- 追加: Claude apps gateway の管理 API にコストレポート `GET /v1/organizations/analytics/cost`（期間内の過去の支出を合計・開発者ごと・日ごと・IdP グループごとに取得）。`admin:` を設定した gateway では各開発者の IdP グループを毎日記録し、`admin.identity_retention_days` の間保持する（コストレポートのグループ分けに使う）
- 追加: Agent SDK のフックのコールバックに `onFailure: "block"`（コールバックが失敗したら操作を通さずブロック）
- 追加: OTel のメトリクス・イベント・span に `anthropic.plan`・`anthropic.seat_type`・`anthropic.provider`・`anthropic.custom_base_url`
- 追加: Web・シェルのツール呼び出しがアカウントのメールアドレスをネットワークに送る前に確認する。`/schedule` で新しいクラウドの定期タスクに頼んでいないコネクターが付いたときに警告し、外し方を示す
- 追加: Claude Desktop の Code タブで、組織のリモートの managed settings がセッションに読み込まれていないときと、読み込まれたときに通知。auto mode のチェックがサブエージェントのツール呼び出しに答えを出せないときの通知
- 追加: `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID`（セルフホストのランナーで `1` にすると、セッション内の `claude -p` が以前のようにそのセッションの ID と transcript を使う）
- 修正: 一部の Claude Desktop のセッションでプロジェクト・ローカルの MCP サーバーが最初のターンの後に切断される問題、base URL の LLM gateway がサーバー側の安全チェックに 403・422 を返すと auto mode が毎ターン失敗する問題、`claude auth status` が遅いトークン更新の保存前に終了してサインアウトされうる問題
- 修正: 事前に起動してプロジェクトで開くセッションでプロジェクトの `effortLevel` が無視される問題、`claude --from-pr` が古いセッションで「No conversations found」になる問題、自己ペースの `/loop` の起床が予約されないことがある問題、claude.ai から同期したスキルを書き込めないと 10 分ごとに失われる・再ダウンロードされる問題など（本文は途中で切れている）

## 要点

- mod 向けに `$.ui.selection()` を追加：フルスクリーンモードで最後に選択したテキストと、選択が transcript の 1 行に収まる場合はその行を返す
- Ctrl+C で消したプロンプトの復元を追加：空のプロンプトで ↑ を押すと、貼り付けたテキストや画像も含めて下書きが戻る
- `/code-review` に `--max-findings <n>|all` を追加：通常の上限より多く・少なく指摘を報告できる（`--max-findings default` を渡すまで選択は引き継がれる）
- エージェントビューに、セッションを名前で探す Ctrl+F と、グループ間を移動する Alt+↑/↓ を追加（リネームと合わせて keybindings.json で変更可能）
- GitHub CLI の無いイメージのクラウドセッションに組み込みの `gh api` を追加。ツール呼び出し中に MCP サーバーが追加の OAuth スコープを求めたときの再認証プロンプトも追加
- `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS` を追加：Mantle や structured outputs を拒否するゲートウェイの背後で、セッションタイトル・メモリの呼び出し・プロンプトフックが失敗する問題の修正に合わせ、structured outputs を無効にできる
- 修正: 応答途中の API タイムアウトでターンが失敗する問題（非対話セッションとサブエージェントは部分的な応答から続行し、thinking だけの応答は再試行）、最後の応答のトークン使用量が 0 のときに自動コンパクションせず「Prompt is too long」で失敗する問題
- 修正: `--resume` まわり（コンパクションで復元したファイルなどの文脈が落ちる、ターンの最後の応答が保存されない、読み込み中の書き換えで transcript が途中で切れる、2.1.286 以前に始めた会話で以前の thinking が落ちる）、auto mode の拒否が Bash 以外のツールでも Bash の権限ルールを示す問題など

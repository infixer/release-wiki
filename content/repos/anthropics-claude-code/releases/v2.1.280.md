## 要点

- Claude Opus 5.5（`claude-opus-5-5`）を追加し、Opus の既定モデルに。コンテキスト 1M、$4/$20 per Mtok、キャッシュ読み取り $0.20/Mtok
- フルスクリーンモードの一覧操作にマウス対応を追加：`/skills` 一覧のホイールスクロール、`/plugin` のスキル状態オプションのクリック
- `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` を追加。セッション内の全 MCP サーバーに対する、MCP ツール説明・サーバー指示の 2,048 文字上限を変更可能に
- `hook_execution_complete` の OpenTelemetry イベントに、hook 出力のサイズと、ファイルに保存された超過分の件数を追加

> [!warning] 破壊的変更
> Ctrl+C・Ctrl+D の二度押しや、誤った `y`/`n` の入力でダイアログが確定・終了していた挙動を修正。ダイアログの確定・キャンセルは Enter・Esc に統一された（`y`/`n` を使いたい場合は `keybindings.json` で `confirm:yes` / `confirm:no` に割り当てて復元できる）

- そのほかの修正: シンボリックリンク経由の書き込みで書き込み先の判定が不正だった問題（`acceptEdits`・許可ルール・auto mode がツリー外への書き込みを誤って許可）、safety check が拒否・無回答のときに auto mode が延々と再試行またはノーポーズで再試行し続ける問題（10 回で打ち切り）、Write 呼び出しの引数名の揺れ（`path`・`file_text`・`file_content` など）への対応、クリックが背後の項目まで発火する問題、Windows 端末での不可視文字除去後の描画崩れ、ペルシア語・アラビア語の結合文字の誤削除、音声入力停止操作の不具合、ホストアプリからのモデル切替やフォーク subagent の再開によるプロンプトキャッシュミス など

## 要点

- 追加: Claude apps gateway の `mantle` upstream に `assume_role`（別の AWS アカウントのロールを使う・開発者ごとに AWS のコストを割り当てる）
- 追加: mod の `$.model.fork` に `effort` オプション（セッションの effort に関係なく、ちょっとした別の処理を `low` で動かせる。結果には送った effort が入る）。セッション中に Claude Code が書いた mod を有効にするかを尋ねたときの回答を記録する
- 追加: 保存された claude.ai のサインインの期限を `claude auth status`（`loginExpiresAt`）と `claude -p` の JSON の結果（`credential_expires_at`）に表示。期限の 10 日前から `claude -p` のテキスト出力で stderr に 1 行の警告
- 修正: 不正なツール呼び出しのリトライが尽きた後に `--continue` で以前の会話が失われることがある問題（2.1.314 の退行）、多数の Bash コマンドが動く macOS のセッションがメモリを増やしながら止まる問題、メッセージ送信直後に打ったキーで権限の確認に答えてしまう問題
- 修正: 共有ネットワークのホームディレクトリで設定ファイルを更新できないとき、`/logout`・`claude auth logout`・`claude mcp remove` が成功と報告し、信頼・同意・MCP の設定変更が黙って捨てられる問題。`claude mcp add` / `remove` がロックなしで設定を書く問題（ロックを待つか終了コード 1）
- 修正: アイドル時の compaction が要約ではない返答で会話を置き換える問題、バックグラウンドのサブエージェントの実行中に「Now using usage credits」の通知が約 30 秒ごとに出る問題
- 修正: バージョン確認で終了する stdio の MCP サーバーを起動のたびに確認し直す問題（3 秒以内に自身の理由で終了するサーバーは 7 日間レガシーのハンドシェイクに固定）、同じマシンの別のログインが保存した `allowedProviders` で起動時に拒否される問題、`claude plugin validate` が `claude plugin marketplace add` の拒否するカスタム名のマーケットプレイスファイルを通す問題など（本文は途中で切れている）

## 要点

- 権限の確認が複数たまったとき、権限プロンプトに「2 of 5」のような件数を表示
- フルスクリーンモードで、リストの「N more」行をマウスでクリックするとリストの端へ移動できるように（ホバー・押下の表示付き）
- 修正: 既定のモデルやモデルのエイリアスが指すモデルを Anthropic API が拒否すると、毎ターン失敗していた問題（同じ tier の 1 つ前のモデルで 1 回再試行する）
- 修正: 前のセッションがクラッシュ・強制終了していた場合に、`claude --resume` / `--continue` で並列ツール呼び出しの後のターンがすべて失われることがあった問題
- 修正: ツールやフックがテキストではなくオブジェクト・数値・真偽値を返した後に API 400 エラーになる問題（再開したセッションでも）
- 修正: 組織のポリシーで Remote Control が無効になっても Remote Control のセッション（`claude remote-control` を含む）が接続されたままだった問題（通知を出して切断する）
- 修正: `claude auth status` が Console でサインインした API キーを `claude.ai` と表示していた問題（`api_key` と表示）、`/status` が API キーと並んで Anthropic のプロファイルを有効であるかのように表示していた問題
- 修正: MCP のエラーメッセージや、ログ・transcript で認証情報や秘密の値の一部が見えてしまう問題（`Bearer` / `Basic` が前に付く場合、パーセントエンコードされた Bearer トークン、キー名に不可視文字を含む場合など）

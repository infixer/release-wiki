## 要点

- `/claude-api api-version` を追加: Claude API のコードを API バージョン `2026-10-21` に移行する
- OpenTelemetry のイベント `claude_code.safety_event` を追加: 権限ルール・auto mode・安全チェック・フック・サンドボックスがツール呼び出しを止めた・確認を求めた・差し戻したときに 1 件ずつ出る
- 修正: `CLAUDE_CODE_DISABLE_1M_CONTEXT` を設定し、`opus[1m]` のような `[1m]` 付きのエイリアスを使うと model-not-found エラーになる問題、カスタムの `ANTHROPIC_BASE_URL` の gateway や Foundry に効果の無い `prompt-caching-scope` beta ヘッダーを送る問題
- 修正（MCP）: macOS でログインキーチェーンがロックされていると `claude -p` で「needs authentication」と出る問題（理由を示し、ロック解除後の次の実行で再サインインなしに接続）、接続中にスリープすると timed out 扱いのまま headless 実行で失敗し続ける問題、接続が途中で切れると HTTP MCP のツール呼び出しが 2 回送られる問題（リトライは読み取り専用・冪等なツールだけに）
- 修正（compaction）: PDF のページ・画像など大きなツール結果を多く読んだターンでの「Autocompact is thrashing」エラーの一部、クラウドセッションの再起動後に `/autocompact` が既定のウィンドウに戻る問題、`/clear` した会話がクラウド・self-hosted runner のセッション再起動後に戻ってくることがある問題
- 修正（Claude apps gateway）: gateway のセッションで `CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS` が無視される問題、`OTEL_EXPORTER_OTLP_HEADERS` 設定時に gateway の背後の Claude Desktop セッションのテレメトリが拒否される問題
- 修正: `/permissions` > Recently denied に拒否したシェルコマンドが出ない問題と、そこでの承認を auto mode のローカル分類器が再試行のコマンドで無視する問題、Agent SDK の `setModel()` で API の確認が 5 秒を超えるとモデル切り替えが拒否される問題（最大 15 秒待つ）、Cowork のクラウドセッションで WebFetch が 4xx や robots.txt の拒否をツールエラーとして扱う問題など（本文は途中で切れている）

## 要点

- Claude apps gateway が `desktop` policy blocks で新しい Claude Desktop 向けキー（`blockReadsOutsideWorkingDirectories`、`disableBypassPermissionsMode`）に対応
- Claude apps gateway の Bedrock upstream に `assume_role` を追加：STS 経由で IAM ロールを引き受けて Bedrock を呼び出す（別 AWS アカウントも可、開発者ごとに 1 セッションとする設定も可）
- Claude apps gateway の Bedrock upstream に `guardrail: {id, version}` を追加：Amazon Bedrock guardrail を適用（全 Bedrock upstream に設定するか、しないかのいずれか）
- Claude apps gateway の設定に `telemetry.resource_attributes` を追加。Claude Desktop・`/login` セッションのテレメトリに固定ラベルを付与できるように
- `settings.json` に `"attribution": false` を追加：コミット・PR の attribution 表記をすべて非表示にできる（バージョン間で共有する設定ファイルではオブジェクト形式を維持すると、古い CLI もそのファイルを読み飛ばす）
- 2026-07-28 版 MCP プロトコルの接続で URL モードの elicitation に対応。サーバーがブラウザベースのフローを開くよう要求できるようになった
- `claude plugin validate` に MCP サーバーのチェックを追加：`.mcp.json` の読み込み時に静かに落ちるエントリ、未宣言の `${user_config.*}` 参照、安全でない URL を報告する
- `/insights` に auto mode の推奨を追加。直近のセッションで auto mode が対応できたはずの許可プロンプト数を推定して表示

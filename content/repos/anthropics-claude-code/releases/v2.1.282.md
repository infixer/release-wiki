## 要点

- `maxProseWidth` 設定を追加：幅の広いターミナルで Claude の文章の幅を制限する（表とコードブロックは全幅のまま）
- プロジェクトの設定ファイルにあるテレメトリ変数のうち、無視されたもの・テレメトリを無効にしたものを、起動時の通知と `/status`・`claude doctor` に表示
- managed setting `allowClaudeInChromeWithManagedMcp` を追加：排他的な `managed-mcp.json` と `claude --chrome` を併用できる（Chrome がブロックされたときのエラーにこの設定名が出る）
- Claude apps gateway に `store.readiness_grace_seconds` を追加：データベースのフェイルオーバーなど短い Postgres 障害の間も `/readyz` を ready のまま保てる
- API が復号できない Web 検索結果を履歴に含む会話（サードパーティのゲートウェイ経由で応答したターンなど）で、すべてのリクエストが 400 エラーになる問題を修正
- `--continue` / `--resume` や `/model` などの即時スラッシュコマンド、`--tools` での再起動で、以前の extended thinking が失われる複数のケースを修正
- 要約リクエストが拒否されたときに compaction が失敗する問題を修正（フォールバックモデルで再試行）
- 他の Claude Code プロセスがサインインの更新中に閉じられた場合などに、最大 1 分間ログインエラーでリクエストが失敗する問題を修正

## 要点

- Claude apps gateway のサインインで、サインイン先アカウントを確認してから資格情報を保存するように（`/status` にもサインイン中のアカウントを表示）
- 送信キー（ctrl+enter、または ctrl+x ctrl+s）を追加：進行中のターンを中断し、キューに溜まったメッセージをまとめて送信する。送信済み・キュー中のメッセージはモデルが受け取るまでグレー表示
- 設定した `otelHeadersHelper` が失敗したときの起動時警告を追加。テレメトリが何も送信されないまま気づかれないケースを防ぐ
- claude.ai アカウントで有効にしている skills / plugins をターミナルセッションに同期するように（`syncClaudeAiSkills: false` / `syncClaudeAiPlugins: false` でオプトアウト可能）
- `/plugin install <plugin> --marketplace <source>` を追加。マーケットプレイスがまだ無ければ、インストール前に追加を提案する
- 多数のバグ修正: メモリファイルの経過時間表示によるプロンプトキャッシュミス、`--forward-subagent-text` でのサブエージェントメッセージ欠落、@メンションのファイル候補が MCP リソースの下に埋もれる問題、フルスクリーンでのバックグラウンドタスク通知位置、`claude plugin marketplace update` によるローカルコピー削除、URL に含まれる認証情報の誤表示 など

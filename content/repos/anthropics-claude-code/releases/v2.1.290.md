## 要点

- mod・プラグインのフック: `turn.step` フックの結果に `serverToolUses`（API 自身が実行したツール呼び出し（advisor）。id・name・input・開始と終了）、プラグインのフックの `tool.check` イベントに `agentId`（サブエージェントの権限チェックとメインセッションのものを区別できる）、mod の `tool.check` フックが読む question と verdict に `ceiling`（組織がツールに求める承認）を追加。プラグインのフックの型定義に `ThemeKey`・`Color` 型も追加
- `claude plugin validate` が、mod がゲーティング箇所に登録した各フックを `.catch` の有無付きで一覧表示（`--json` では `gatingHooks`）
- `claude attach <name>` と `claude logs <name>` を追加（セッション名の一部を ID の代わりに使える）
- `/claude-api managed-agents-onboard <url>`（ページが説明する Managed Agents のパターンを `ant apply` ファイルとして用意）と `/claude-api managed-agents-onboard <quickstart-name>`（`deep-researcher` などの Console クイックスタートのテンプレートを `ant` CLI で構築）を追加
- Claude apps gateway のサインイン承認ページに Deny ボタン（保留中のサインインを終わらせ、待っているターミナルは数秒で止まる）
- managed settings: 管理設定フォルダの外のファイルへのリンクになっている managed settings ファイルに警告、ユーザーが設定したサンドボックスの `allowRead` パスや許可ドメインを managed settings が無視しているときに /status と doctor で警告
- 修正: 一部のベータヘッダーを 400 以外のステータスで拒否するプロキシ・ゲートウェイの背後でリクエストが失敗する問題、数百枚の画像を含む長いセッションが「Request rejected as unprocessable by the model」で止まる問題、思考中に API の出力フィルタが止めると即座にターンが終わる問題（1 回リトライするように）、再開したサブエージェント・チームメイトが実行中にメッセージを受けると以前の思考とプロンプトキャッシュを失う問題
- 修正: WebFetch が 100,000 文字を超えるページのテキストを黙って捨てていた問題（未読の量を伝え、`offset` で続きを読める）、`/rewind` が作業中に送ったプロンプトを一覧に出さない問題、スケジュールされたタスク（間隔付きの `/loop`、リマインダー）が圧縮後の再開で戻らない・バックグラウンドへの引き渡し後に発火しない・再開のたびに余分に実行される問題、ヘッドレスの `--json-schema` 実行が構造化出力の後に接続が切れると非ゼロで終了する問題など

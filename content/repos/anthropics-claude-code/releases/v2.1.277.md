## 要点

- AGENTS.md 対応を追加：`CLAUDE.md` の無いプロジェクトでは `AGENTS.md` を読むように（`/config` の「Project instructions」で変更可能。Bedrock・Vertex・Foundry は未対応）
- `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` を追加：egress がフォワードプロキシしか無い Claude apps gateway 向けに、外向きリクエストがホスト名をローカルで解決せずプロキシに渡すように
- Claude apps gateway の upstream にオプションの `headers:` マップを追加。手前で動かすプロキシに静的ヘッダーを送れるように
- `/tasks` などのパネルを開いている間にバックグラウンドタスクが完了すると、更新を待っている旨の行を表示するように
- 多数のバグ修正: `claude -p` / Agent SDK が内部エラー後に結果を返さずハングする問題、空のテキストブロックによる全リクエスト失敗、同一マシン上の旧ビルド実行によるログアウト、`customApiKeyResponses` の不正値による起動ハング、アップデートチェックのエラー・ハング、`claude plugin install` の再インストール失敗、Grep/Glob がプロセス枯渇時に「マッチなし」と誤答する問題、Write ツールの誤ったターン終了、Edit ツールのエスケープ処理不具合、null バイトによるターン終了、バックグラウンドセッションの予期しない終了、`/mcp` や `/plugin manage` のクラッシュ など

## 要点

- `claude plugin install` に `--marketplace <source>` を追加（必要ならマーケットプレイスを `claude plugin marketplace add` と同じポリシーチェックで追加してから、そこからプラグインをインストール）
- Agent ツールに `effort` パラメータを追加（指定した effort レベルでサブエージェントを実行）
- 環境変数 `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` を追加（過負荷（529）のリクエストを再試行するときのバックオフの基本遅延を長くできる）
- mod 向け: プロンプト欄の補完一覧に独自の行を足すイベント `prompt.autocomplete`、`$.model.complete` のプロンプトキャッシュ（`prompt` と `system` がテキストのブロックを取り、ブロックの `cache: true` でそこまでをキャッシュ）、`agent.spawn` フックにワークフローのエージェント（run と index 付き。mod が拒否できる）を追加
- 修正（セキュリティ・権限）: PreToolUse フックの承認と auto モードが、ネットワーク（UNC）パスからのファイル読み取りで権限プロンプトを飛ばしていた問題（Security）。サンドボックス内のコマンドが `~/.claude/seed-admin` 以下の `/ultrareview` アップロードのステージングコピーを読めた問題、改ざんされた server-managed settings のディスクキャッシュが設定の取得失敗中に組み込みのポリシープラグインを無効化・差し替えできた問題、読み取り中に差し替えたリンクで承認範囲外のファイルを返せた問題（macOS・Windows のノートブック・PDF）など
- 修正（権限モード）: `permissionMode: auto` のサブエージェント定義が auto モードを使えないときにも auto モードに入る問題、auto / plan モードをターン途中で抜けるとスキルやスラッシュコマンドの `allowed-tools` ルールが後のターンで戻る問題、`claude --resume` のピッカーや `/resume` で再開したときに plan モードが戻らない問題
- 修正（その他）: `HTTPS_PROXY` 設定時に Claude Code 自身の API リクエストで `NO_PROXY` が無視される問題、名前が 128 文字を超える MCP ツールがあるとすべてのリクエストが失敗する問題（そのツールを外し、MCP のエラーで名前を示す）、`claude -p` と Agent SDK の one-shot 実行で最終結果の 5 秒後にバックグラウンドのコマンドが止められる問題、保存したスケジュールタスクが `/resume`・`/branch`・`/clear` 後に発火しない問題など

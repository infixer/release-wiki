## 要点

- 追加: Monitor ツールとプラグインの monitor が Bedrock・Vertex・Foundry と、テレメトリや必須でない通信を無効にした環境でも使えるように（長いフォアグラウンドの sleep もそこでブロックされる）
- 修正: `effort-2025-11-24` の beta 値や会話途中の system メッセージを拒否する一部のゲートウェイ・互換サーバーでリクエストが失敗する問題（それらを外して再試行する）
- 修正: 「Prompt is too long」エラーの後の compaction が、base64 や SVG のような密なテキストの会話を残しすぎて次のリクエストも失敗しうる問題。`cleanupPeriodDays` をとても大きくすると、バックグラウンドの掃除が貼り付けた画像などの最近のファイルを消す問題
- 修正: ファイル読み取りの権限プロンプトにシンボリックリンクの行き先が出ない問題、外部エディタで長く編集した後に質問の自動継続のタイムアウトがすぐ発火する問題
- 修正（Windows）: Git Bash が無く、フックのコマンドが引用符で囲んだ文字列だけ（引用したパスなど）のとき、PreToolUse・PermissionRequest フックがツール呼び出しを通してしまう問題
- 改善: auto mode の作業ディレクトリ外の最初の読み取り前のプロンプトが、それをブロックするとシェルコマンドが権限を求めるようになることを伝える。非対話セッション（`-p`、Agent SDK）で transcript がとても大きいときの compaction 中のメモリ使用量。mod の `Image` が tmux（`allow-passthrough`・`focus-events` 有効）や kitty・Ghostty・iTerm2 3.5+ の全画面描画でも描画される（以前は `alt` テキストだけ）
- 改善（Linux）: `/sandbox` とサンドボックス起動時の警告が、bubblewrap の起動を妨げる Ubuntu の AppArmor のユーザー名前空間の制限と、その解除方法を示す
- 変更: 非対話セッションで、サーバーの elicitation に答えがないまま MCP のツール呼び出しがタイムアウトしたとき、答えが来なかったので呼び出しを繰り返さないよう Claude に伝える
- VS Code: プランレビューのカードの「Send feedback and keep planning」で Enter を押すとプランが承認されてしまう問題などを修正
- クラウドセッション: Enterprise のカスタムロールに Claude Code のクラウドセッションと Remote Control の権限を追加（Owner がロールごとに制御できる）、クラウド環境のセットアップスクリプトをファイルから読み込む Choose file ボタン、編集ダイアログのエラー表示の修正など（本文は途中で切れている）

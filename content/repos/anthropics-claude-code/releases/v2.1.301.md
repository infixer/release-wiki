## 要点

- `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` を追加: 無人のリトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）で、利用上限のリセットが遠すぎるときは待たずにリクエストを終える
- OpenTelemetry の `tool_decision` イベントに `classifier_verdict`・`permission_mode`（auto mode の分類器の判定と権限ルールを区別できる）と、`OTEL_LOG_TOOL_DETAILS=1` のとき `classifier_category`（分類器のブロックが一致した組み込みルール）を追加
- vim モードに `%` モーション（対応する括弧へ移動。単独でも d/c/y と組み合わせても使える）
- mod の `Input` に `rows`（ターミナルで複数行のテキスト欄。Enter で送信、Shift+Enter か行末のバックスラッシュで改行）
- `claude-api` スキルに OpenTelemetry のトレースの案内（`ant` CLI でのトレース先の設定を含む）
- 修正: `WorktreeCreate` フックが作った worktree を、未 push のコミットがありうるのに終了時に確認なしで削除する問題、組織で最新の Fable モデルが使えないとき `fable`（と `best`）のエイリアスがエラーになる問題（前の Fable モデルで 1 回リトライする）、ディスクが一杯でログインを更新できないときの誤解を招く「Please run /login」エラー、検索プログラムが失敗したとき Grep・Glob が「一致なし」と報告する問題、ワークフローのエージェントがステップを飛ばしても成功と報告される問題、PreToolUse フックが Edit・Write を対象にしていると artifact の更新が拒否される問題
- そのほかの修正: 引数名が非常に多い・長いスキルやコマンドの呼び出しが止まる問題（先頭 64 個・各 64 文字まで）とメモリ使用量、VTE 0.53 より古いターミナルや一部の iTerm2 での不要な文字の表示、`awsAuthRefresh` の不要な実行、短いコマンドの終了がトークン更新と重なったときのサインアウト、ターン途中のメッセージで切れたツール呼び出しを「ユーザーが拒否」と伝える問題、など（本文は途中で切れている）

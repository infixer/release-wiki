## 要点

- 追加: `self-hosted-runner` に `--hold-idle-file` と `--max-hold-min`。ホストが残っているプロセスを報告している間、アイドルのセッションを保持する
- 追加: Explanatory 出力スタイルのヒント（Claude に説明を求めたときに表示）
- 修正: 標準コンテキストのセッションで 1 リクエストが 200K トークンを超えると「Usage credits required for 1M context」で止まる問題。会話を compact して続けるようになった。自動 compaction の直後に、セッション中に編集した MEMORY.md・CLAUDE.md の古い内容を Claude が見てしまう問題
- 修正: CLAUDE.md にとても長いリスト項目があると、起動時やファイルの読み取り・編集後に長く固まる問題。数千行を変える Write・Edit が実行後に最大 5 秒止まり、変更 0 行と報告する問題
- 修正: MCP サーバーがリソース読み取りに答えない・スキルのダウンロード中に、中断がタイムアウトまで効かない問題。サブエージェントが、自分の開始後に接続が終わった MCP サーバーのツールを使えない問題
- 修正: `SubagentStop` フックが、終了時の 1 回ではなく実行中のサブエージェントごとに 1 分に約 2 回動く問題。サブエージェントの隔離 worktree が、そこで起動したバックグラウンドのサブエージェントの作業中に削除される問題。auto mode のバックグラウンドエージェントが自分のシェルを待つたびに新しいメインのターンを始める問題
- 修正: `claude -p` と SDK のセッションで transcript のメッセージが順不同で保存される・取り消したメッセージが残る問題。@ ファイルピッカーが `.ignore`/`.rgignore` の否定ルールを無視する問題。`claude mcp add`/`remove`/`/mcp` がリポジトリのルートより下で実行したとき local スコープのサーバーのプロジェクトの項目ではなく現在のフォルダを示す問題
- 修正（Remote Control・クラウド）: プロキシが起動時のリクエストをブロックすると約 2 分「Connecting」のままになる問題、Claude が送ったメッセージがモバイルアプリで自分のメッセージとして出る問題、Cowork のクラウドセッションで WebFetch・WebSearch が止まった応答で固まる問題（300 秒で失敗するように）など（本文は途中で切れている）

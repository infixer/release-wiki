## 要点

- `sandbox.allowNestedUserNamespaces` を追加: Linux のサンドボックス内のコマンドが user namespace を作れるように（Chromium・rootless podman 向け）。サンドボックスのファイル保護を回避できるようになる点に注意
- `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` を追加: 無人のリトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）が、リセット前に解除された使用上限に気付けるように
- 修正（2.1.304 のリグレッション）: エンドポイントや gateway がツール検索を拒否すると Vertex・Bedrock などですべてのリクエストが失敗する問題。ToolSearch を無効にした gateway・`--tools` から外した場合も含め、ツール検索なしでリトライする
- 修正: モデル名が `modelOverrides` の値と大文字小文字や `[1m]` の有無で異なると `/effort`・`/autocompact` の設定が効かない問題、クラウドセッションやチームメイトで compaction が要約に収めるために古いメッセージを省いたことを Claude に伝えない問題
- 修正: bare リポジトリの新しい worktree が既定ブランチでなくローカルの HEAD から始まることがある問題、ディスクが一杯のときの Bash の生の `ENOSPC` エラー（ディスクが一杯で何も実行されなかったと伝える）、クラウドセッションや SDK の `setMcpServers` で渡した MCP サーバーが自分の設定の同名サーバーに置き換えられる問題
- 修正: Workflow の再開で完了済みの `pipeline()`・`parallel()` のエージェントを再実行する問題、スクリーンリーダーモードでの検索ボックスの読み上げ、self-hosted runner の不具合（`TERM` 設定時の `Resource temporarily unavailable`、`GIT_CONFIG` を使う credential helper でのリポジトリアクセス失敗など）
- `/usage` を改善: 各警告がその原因を示す 1 行の修正になり、`f` で修正を適用できる（本文は途中で切れている）

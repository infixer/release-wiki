## 要点

- Claude API・Enterprise ユーザー、および Bedrock・Vertex・Foundry・gateway 利用時の auto mode が、既定でサーバー側の分類器を使うように変更（分類器のオーバーヘッドは課金されない。`CLAUDE_CODE_AUTO_MODE_SERVER=0` で Bedrock・Vertex・Foundry・gateway ではオプトアウト可能。課金対象のフォールバック時は警告を表示）。詳細: https://code.claude.com/docs/en/auto-mode-classifier-billing
- `/status` に「Auto mode server」の行を追加。このセッションの auto mode 分類器がサーバー側で動いているかを表示

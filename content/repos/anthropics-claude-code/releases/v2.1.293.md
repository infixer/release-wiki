## 要点

- Claude Haiku 5.5（`claude-haiku-5-5`）を追加。Anthropic API での既定の Haiku モデルになった（1M コンテキスト、$0.10 / $0.50 per Mtok。100K を超えるプロンプトは $0.50 / $2.50）
- `subagentStatusLine` のペイロードに `agentType` を追加（スクリプトでカスタムのサブエージェントの種類を見分けられる）
- mod 向け: `$.tool.register` に `isDeferred` を追加（`false` にするとツールのスキーマをツール検索の裏ではなく最初からプロンプトに載せる）
- 修正（コンテキスト・接続）: コンテキストの compaction の前の自分の最後の操作を、後に行ったものとして扱い、終わった作業を取り消したりやり直したりすることがある問題。HTTP の MCP 接続が送ったリクエストを閉じるまで全部持ち続けるメモリリーク
- 修正（操作）: Claude の作業中に送ったメッセージが `←` でセッションをバックグラウンドに移すと失われる問題（キューのメッセージを移せないときは `←` は動かずにその旨を表示）。`/model` の effort の ←/→ が最高・最低を越えて回り、Low を既定の effort として保存してしまうことがある問題。`--chrome` で始めたセッションで `/tui` が Claude in Chrome を切断し、`--no-chrome` を無視する問題
- 修正（ツール・エージェント）: ホスト・権限ルール・`--tools` で `SendMessage` が外されたセッション（再開したものを含む）で、サブエージェントへの続行・メッセージ送信を指示される問題。サブエージェントや `--agent` セッションで、自分のツール一覧から外れただけのビルトインツールがセッション全体で無効と伝えられる問題
- 修正（その他）: `claude logs`・`stop`・`kill`・`rm`・`claude daemon status` などがログインの期限切れ前後にサインアウトさせることがある問題、`/ultrareview` のアップロードの誤った拒否、長い Remote Control・クラウドセッションの返信がストリーミングされない問題、mod の `classic.*` イベントのフックがプラグインのフックワーカーの再起動中に飛ばされる問題、`claude plugin test` が mod で失敗する問題など（本文は途中まで）

## 要点

- mod の追加: プロンプトの装飾に `virtualText`（プロンプト欄に描くが、下書きにも送信するプロンプトにも入らないテキスト）、`$.ui.view({ agentId })`（エージェントの transcript をメインビューに表示。`$.ui.view({})` で戻る）、`Text` の `dir`（右から左のテキスト）、`prompt.change` フック（履歴の呼び出し・クリア・undo・プラグインの入力など、タイプ以外でプロンプト欄が変わったとき）。`agent.spawn` フックでワークフローのエージェントの `prompt`・`model` を書き換えられる（以前は拒否しかできなかった）
- OpenTelemetry: `api_request` イベントに `cache_creation_5m_tokens`・`cache_creation_1h_tokens`（キャッシュ書き込みを寿命で分割）、トレースの span に GenAI のセマンティック規約の属性（`gen_ai.provider.name`・`gen_ai.conversation.id`・`gen_ai.tool.name`・`error.type` など）
- Claude Platform on AWS で `/advisor` を使えるように。`/advisor`・`advisorModel`・`--advisor` で選ぶまで advisor は動かず、`CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` で無効にできる
- 修正（フック・ログイン）: バックグラウンドのコマンドが動いている間に終了すると SessionEnd フックが動かないことがある問題、`forceLoginOrgUUID` で拒否されたログインで、その組織のトークンが保存されたまま・`/login` 後も有効になる問題
- 修正（エージェント）: `claude agents` で 1 件のデータが不完全だとどの PR の状態も更新しない、メッセージを送ったサブエージェントが終了後すぐ `/tasks` から消える、子を見ている間に完了した親エージェントがパンくずから消える、エージェントビューで一気に届いた入力の「up」「down」「escape」などの単語をキーとして扱う問題、クラウドセッションのコンテナ置き換え後に一度再開済みのバックグラウンドエージェントを「失われた」と伝える問題
- その他の修正: 自動ツール検索（`ENABLE_TOOL_SEARCH=auto`）が MCP サーバーの再接続中などに途中で切れる、`/autocompact` で小さいウィンドウを選ぶと高トークン使用の警告が出る、クラウドセッションで自分のネットワーク設定によるブロックを組織のポリシーと伝える、reftable のリポジトリで Claude Desktop・Remote Control の diff ビューが衝突した cherry-pick・revert に気付かない、Artifact ツールの行の表示、`claude --help` の `--restricted` の説明が削除済みのツールを挙げる、など（本文は途中で切れている）

## 変更・修正

### `security-guidance` プラグインのコピーを削除し、claude-plugins-official からのインストールへ（[#105270](https://github.com/anthropics/claude-code/pull/105270)）

> [!quote] Before
> このリポジトリの `claude-code-plugins` マーケットプレイスに `plugins/security-guidance` のコピー（2.0.0、5 月に手で更新されたまま）があった。開発・リリースは [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official) 側（2.0.16）で行われていた。

> [!success] After
> `plugins/security-guidance` と `.claude-plugin/marketplace.json` の項目、`plugins/README.md` の行を削除し、マーケットプレイスの `renames` マップに削除を記録した。plugin-dev の hook-development スキルの例も公式マーケットプレイスを指すようにした。

> [!warning] 移行が必要
> `security-guidance@claude-code-plugins` を有効にしている人は、マーケットプレイスの更新後にレビューが届かなくなる。使い続けるには `/plugin install security-guidance@claude-plugins-official`。
> Claude Code 2.1.306 では `claude plugin list` に一度有効・次に無効として出て、`enabledPlugins` からキーが消える。`renames` を読まない 2.1.144 以前では、読み込みのたびに「failed to load: Plugin security-guidance not found in marketplace」が出る（他のプラグインは読み込める）。
> なお、続く [#105303](https://github.com/anthropics/claude-code/pull/105303) で `security-guidance` は再び一覧に載った。

### マーケットプレイスの全プラグインを claude-plugins-official からインストールするように（[#105303](https://github.com/anthropics/claude-code/pull/105303)）

> [!quote] Before
> `claude-code-plugins` マーケットプレイスは、このリポジトリの `plugins/` にある各プラグインのコピー（`code-review`・`commit-commands`・`feature-dev`・`frontend-design`・`explanatory-output-style` など）を配っていた。

> [!success] After
> すべてのプラグインを [claude-plugins-official](https://github.com/anthropics/claude-plugins-official) からインストールし、ここにある古いコピーは削除した（変更ファイル 137 件）。既存の `name@claude-code-plugins` の ID はそのまま使え、`security-guidance` も再び一覧に載る（#105270 の削除で無効になるのを止める）。`ralph-wiggum` は `ralph-loop` に改名、公式のコピーが無い `claude-opus-4-5-migration` は廃止。

> [!warning] 移行が必要
> - #105270 の削除をすでに適用したクライアントは、`/plugin enable` するまで `security-guidance` が無効のまま
> - `ralph-wiggum` は 2.1.193 未満では読み込まれなくなる。新しいクライアントは 1 セッション後に `ralph-loop` へ移る。コマンドが変わるので、スクリプトは新しい名前を使う
> - 2.1.69 未満ではこのマーケットプレイスの追加が失敗する（既存のインストールは動く）。2.1.288 未満かつ git 2.39 より古いとインストールが失敗することがある（未検証）
> - 更新後の `hookify` は、これまで黙って失敗していた `block` ルールを実際に適用する
> - `renames` がプロジェクトの `.claude/settings.json` を書き換えることがある
> - `blockedMarketplaces` は `git-subdir` の URL に効かないため、公式リポジトリをブロックしている組織にもこれらのプラグインが届く

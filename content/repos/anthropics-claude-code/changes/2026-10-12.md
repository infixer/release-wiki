## 新機能

### HIPAA 向けの設定例を `examples/settings` に追加（[#100293](https://github.com/anthropics/claude-code/pull/100293)）

> [!tip] 何ができるようになったか
> HIPAA の構成が適用された組織が、セッションの内容が開発者のコンピューターの外へ出る経路を絞るための、managed settings の設定例が加わった。
>
> - **追加ファイル**: `settings-hipaa.json`（`managed-settings.json` の例）、`managed-mcp-hipaa.json`（`managed-mcp.json` の例）、`README-hipaa.md`（各設定の理由、プラットフォームごとに編集する箇所、コンピューターの確認方法、このファイルが扱わない範囲を説明）。`examples/settings/README.md` にも追記
> - **要件**: Claude Code v2.1.285 以降
> - **位置づけ**: 出発点として推奨するサンプル。自分の環境に何が必要かを決め、設定がそれを満たすかを確かめるのは各組織の責任
> - **ドキュメント**: [HIPAA setup（Claude Code）](https://code.claude.com/docs/en/hipaa-setup)、[HIPAA setup（Cowork）](https://claude.com/docs/cowork/hipaa-setup)

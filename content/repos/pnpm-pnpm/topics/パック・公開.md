## 概要

`pnpm pack`・`pnpm publish`・`pnpm deploy` と、ワークスペースのバージョン更新（changelog）まわり。isolated リンカーでも bundled dependencies（ワークスペースのパッケージやその依存を含む）を tarball に含められるようになり、`package.yaml`/`package.json5` のパッケージにも `files` が適用されるようになった。`pnpm publish --publish-wait-timeout` の反映待ちはタイムアウト後に余分な確認を送らないよう修正された。private パッケージはレジストリ確認なしでバージョン更新され、changelog はリポジトリの `CHANGELOG.md` に書かれる。未リリースの変更として、`files` に明示されない `.env` ファイルの警告と `pnpm pack --silent` の出力抑制が入った。`.env` の警告と `pnpm pack --silent` は v12.8.0 でリリースされた。`injectWorkspacePackages: true` での `pnpm deploy` の `ERR_PNPM_DEPLOY_AMBIGUOUS_PEER` も修正された（未リリース）。

## 主な API・オプション

- `pnpm pack` / `pnpm publish` — isolated リンカーで bundled dependencies を含める（PnP リンカーでは拒否）
- `files` フィールド — `package.yaml`/`package.json5` のパッケージでも適用
- `.env`/`.env.*` の警告 — `files` に明示されていなければ警告（テンプレートは対象外、v13 でエラー予定）
- `pnpm pack --silent`（`-s`、`--reporter=silent`、`--loglevel=silent`）— ファイル一覧とサマリーを出さない
- `pnpm deploy --package-import-method` — コマンドラインの指定を尊重
- private パッケージのバージョン更新 — 常に `repository` 方式で `CHANGELOG.md` に追記

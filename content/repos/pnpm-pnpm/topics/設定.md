## 概要

`pnpm-workspace.yaml`・グローバル設定・コマンドラインから読む設定値の扱い（読み込み時の検証と、`pnpm config` での見え方）。TypeScript 版の設定リーダーは、`allowUnusedPatches`（真偽値）、`ignoredOptionalDependencies`・`requiredScripts`（文字列の配列）が不正な形なら `pnpm:INVALID_SETTING` で読み込み時に失敗するようになった（未リリース）。v11.28.3 では `allowBuilds` の不正な値も `ERR_PNPM_INVALID_ALLOW_BUILDS` で失敗する。pnpm 12 では `--config.<setting>=<value>` で渡した設定が `pnpm config get`/`list` に出なかった問題が直った（未リリース）。未リリースの修正として、pnpm v12 も `failIfNoMatch` を `pnpm-workspace.yaml` と `PNPM_CONFIG_FAIL_IF_NO_MATCH` から読むようになった（`--no-fail-if-no-match` で 1 回だけ無効化）。未リリースの修正として、`pnpm config get`/`list` の `--global`・`--location=global` が v11・v12 ともグローバルの設定だけを読むようになった（v11.28.5 のリリースノートにも記載）。v12 では空の `nodeOptions`（`--config.node-options=` など）が下位の設定を上書きし、v11 では `httpProxy`・`httpsProxy` の検証と、設定の読み込みに失敗したときの警告の表示が加わった。未リリースの修正として、`pnpm config get`/`list` の `--global`・`--location=global` が v11・v12 ともグローバルの設定だけを読むようになった（v11.28.5 のリリースノートにも記載）。v12 では空の `nodeOptions`（`--config.node-options=` など）が下位の設定を上書きし、v11 では `httpProxy`・`httpsProxy` の検証と、設定の読み込みに失敗したときの警告の表示が加わった。未リリースの修正として、`pnpm config get`/`list` の `--global`・`--location=global` が v11・v12 ともグローバルの設定だけを読むようになった（v11.28.5 のリリースノートにも記載）。v12 では空の `nodeOptions`（`--config.node-options=` など）が下位の設定を上書きし、v11 では `httpProxy`・`httpsProxy` の検証と、設定の読み込みに失敗したときの警告の表示が加わった。

## 主な API・オプション

- `--config.<setting>=<value>` — 明示的に設定されたものとして記録され、`pnpm config get`/`pnpm config list` に表示（v12、未リリース）
- `allowUnusedPatches` — 真偽値以外は `pnpm:INVALID_SETTING`
- `ignoredOptionalDependencies` / `requiredScripts` — 文字列の配列以外は `pnpm:INVALID_SETTING`
- `allowBuilds` — オブジェクトでない、または値が `true`/`false`/文字列以外なら `ERR_PNPM_INVALID_ALLOW_BUILDS`（v11.28.3）
- `failIfNoMatch` — `pnpm-workspace.yaml`・`PNPM_CONFIG_FAIL_IF_NO_MATCH` から読む。`--fail-if-no-match` で上書き、`--no-fail-if-no-match` で無効化（v12、未リリース）
- `pnpm config get`/`list --global`（`--location=global`）— プロジェクトの `pnpm-workspace.yaml`・`.npmrc`、グローバルパッケージのマニフェストを読まない（v11・v12、未リリース）
- `nodeOptions` — 明示的な空の値が優先度の低い値を上書き。継承した `NODE_OPTIONS` は消さない（v12、未リリース）
- `httpProxy` / `httpsProxy` — 文字列以外や `null` は `INVALID_SETTING`（v11、未リリース）
- `pnpm config get`/`list --global`（`--location=global`）— プロジェクトの `pnpm-workspace.yaml`・`.npmrc`、グローバルパッケージのマニフェストを読まない（v11・v12、未リリース）
- `nodeOptions` — 明示的な空の値が優先度の低い値を上書き。継承した `NODE_OPTIONS` は消さない（v12、未リリース）
- `httpProxy` / `httpsProxy` — 文字列以外や `null` は `INVALID_SETTING`（v11、未リリース）
- `pnpm config get`/`list --global`（`--location=global`）— プロジェクトの `pnpm-workspace.yaml`・`.npmrc`、グローバルパッケージのマニフェストを読まない（v11・v12、未リリース）
- `nodeOptions` — 明示的な空の値が優先度の低い値を上書き。継承した `NODE_OPTIONS` は消さない（v12、未リリース）
- `httpProxy` / `httpsProxy` — 文字列以外や `null` は `INVALID_SETTING`（v11、未リリース）

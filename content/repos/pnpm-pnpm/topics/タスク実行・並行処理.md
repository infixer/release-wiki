## 概要

`pnpm-workspace.yaml` のタスクに、マシン全体で同時実行数を制限する「並行実行グループ」を追加する一連の変更。複数の worktree で重いタスク（Rust ビルドやテストなど）を同時に走らせてメモリ不足になる問題への対応で、枠はアドバイザリなファイルロックで管理される。待機タスクは当初 `try_lock` のポーリングだったが、到着順・優先度順にチケットで枠を取る方式に改善された。スクリプト実行まわりでは、`--filter`/`-r` 付きのショートハンド（`pnpm --filter api vitest run` など）でもスクリプトが無ければ `exec` にフォールバックするようになり、Windows で Ctrl+C 後にバッチシム経由のスクリプトが残って端末が戻らない問題が修正された（未リリース）。実行前の依存確認（`verifyDepsBeforeRun`）では、インストールするものが無いプロジェクトでインストールを省き、フィルタ付きインストール後に lockfile の更新時刻だけで再インストールしないようになった（v12.8.1・v11.28.2）。`autoDedupe` を有効にした CI で `pnpm run` のたびにインストールが走る問題は v12.8.2 で直った。未リリースの修正として、macOS・Linux で `Path` が `PATH` として渡る問題、PID 1 の入れ子の `pnpm run` が `SIGTERM` で止まらない問題が直り、`childConcurrency` の既定値が 5 になった。さらに v12 で `pnpm -s <script>` が受け付けられ、スクリプト名の後ろに `--filter` を書いてスクリプトが見つからないときは置き場所のヒントを出すようになり、グローバル仮想ストアの ESM ローダーが入っていても `ts-node index.ts` のような CommonJS フック経由のエントリポイントを実行できるようになった（いずれも未リリース）。未リリースの修正として、`verifyDepsBeforeRun` が起動する子のインストールに親コマンドの `--config.*` が渡るようになり（v11・v12）、Ctrl+C で止めたスクリプトに `[ELIFECYCLE]` の行を出さなくなった。未リリースの修正として、v12 の `pnpm run "/<regex>/"` が ECMAScript の正規表現エンジンでコンパイルされ、先読みや後方参照を使えるようになった（v11 と同じ）。未リリースの新機能として、v12 の `pnpm -r run`・`--stream`・`--parallel` などの出力で、pnpm の出力が色付きなら子に `FORCE_COLOR=1` を渡してスクリプトの色を保ち、カーソル移動などの制御文字を取り除くようになった。bail 時の `[ELIFECYCLE]` の行が他のプロジェクトの表示に紛れ込む問題も直った。

## 主な API・オプション

- `tasks.<name>.concurrencyGroup` — タスクが属するグループ名
- `concurrencyGroups.<group>: <limit>` — グループごとの同時実行数上限
- `<name>.priority` — 待機時に優先して枠を得るための優先度
- `pnpm --filter <project> <command>` / `pnpm -r <command>` — 選択したどのプロジェクトにもスクリプトが無ければ再帰的な `exec` を実行（`--if-present`・`--dry-run`・明示的な `pnpm run` では行わない）
- `pnpm tasks status` — 各グループの実行中/待機中タスクと待ち順・待ち時間を表示（`tasks` という名前のスクリプトがある場合は `pnpm pm tasks status` を使う）
- `verifyDepsBeforeRun` — フィルタ付きインストール後は実際に配置したものと lockfile を比較
- `childConcurrency` — 既定値 5（v12 も pnpm 11 に合わせた、未リリース）
- `pnpm -s <script>` — トップレベルの `-s`/`--sequential` を `run` とスクリプトのフォールバックで受け付ける（v12、未リリース）
- `Missing script` のヒント — スクリプト名の後ろに `--filter`/`-F`/`--filter-prod` があれば `pnpm --filter <selector> run <script>` を案内（v12、未リリース）
- `verifyDepsBeforeRun` — 起動する `pnpm install` に親の `--config.<key>=<value>` を引き継ぐ。`prompt` の確認表示には含めない（未リリース）
- `pnpm run "/<regex>/"` — ECMAScript の構文（先読み・後方参照）を受け付け、UTF-16 のコード単位で照合（v12、未リリース）

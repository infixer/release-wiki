## 概要

依存パッケージに同梱された AI エージェント向けのスキル（`skills/<name>/SKILL.md`）を、pnpm v12 がインストール時に見つけてエージェントのスキルディレクトリにリンクする機能（[pnpm/rfcs#35](https://github.com/pnpm/rfcs/pull/35)、v12.11.0 でリリース）。対象は各プロジェクトの直接依存で、承認したパッケージのスキルだけをリンクし、未承認のものは保留として記録して `pnpm approve` を案内する（インストールは失敗しない）。同じ PR でパッケージごとの `permissions` 設定（[pnpm/rfcs#36](https://github.com/pnpm/rfcs/pull/36) の後方互換な部分）も加わった。v12.11.0 のリリースノートによると、`pnpm permissions` で許可・拒否・承認待ちを一覧でき、`pnpm approve` でビルドスクリプトとスキルを一度に確認する。v12.11.1 では、リンク先のエージェントを判定する環境変数に Claude Code（`CLAUDE_CODE`）・Antigravity・Copilot・Codex と汎用の `AI_AGENT` が加わった。 main では、各スキルを `pnpm-<package>-<skill>` でなくスキル自身の名前（`SKILL.md` の `name` と一致するディレクトリ名）でリンクするよう変わった（未リリース）。2026-11-04 の回では（未リリース）、`pnpm approve` で複数のスキルのうち一部だけを承認できるようになり（`permissions.<pkg>.skills: [...]`）、`skills/` の下を 3 階層まで探してカテゴリ分けしたスキルも見つける。名前の衝突やその名前が pnpm 以外のもので埋まっているときは、自動で `pnpm-` で始まる名前に切り替える。

## 主な API・オプション

- `skills/<name>/SKILL.md` — 直接依存の中で探す場所（`--prod` などの依存グループの指定に従う。複数バージョンがあれば最も新しいもの）
- `pnpm approve` — 保留のスキルを承認する（保留は `.modules.yaml` に記録）
- リンク名 `<skill>`（パッケージ内のスキルのディレクトリ名。Agent Skills の仕様に合わせ、2026-11-02 の [#17520](https://github.com/pnpm/pnpm/pull/17520) で `pnpm-<pkg>-<skill>` から変更・未リリース）— ルートにある `.*/skills` ディレクトリと、環境から分かるエージェントのディレクトリ（無ければ作る）に置く
- `ERR_PNPM_AGENT_SKILL_NAME_COLLISION` — 承認した 2 つのパッケージが同じ名前のスキルを持つ（片方を拒否するよう案内）。2026-11-04 の [#17533](https://github.com/pnpm/pnpm/pull/17533) 以降は、衝突やリンク先が pnpm 以外のもので埋まっているときに自動で `pnpm-` で始まる名前に切り替える（未リリース）
- `skills.dirs` — リンク先の上書き。`[]` で機能を無効化
- `ERR_PNPM_AGENT_SKILL_PATH_OCCUPIED` — リンク先に pnpm 以外のものがある。`ERR_PNPM_NO_AGENT_SKILLS_DIR` — 承認したスキルの置き場所が無い
- `permissions` — パッケージごとの権限の設定（後方互換な部分のみ）
- `pnpm permissions` — 許可・拒否された権限と承認待ちのパッケージを一覧（v12.11.0 のリリースノートより）
- エージェントの判定 — `CLAUDECODE`/`CLAUDE_CODE` → `.claude/skills`、`ANTIGRAVITY_AGENT`・`CODEX_THREAD_ID`・`CODEX_SANDBOX`・`AI_AGENT` → `.agents/skills`、`COPILOT_AGENT`・`COPILOT_CLI` → `.github/skills`。個別の変数が `AI_AGENT` より優先（v12.11.1）
- `permissions.<pkg>.skills: [guide, migrate]` — 承認したスキルの一覧（`skills: true` はすべて）。`pnpm approve` がチェックリストを出す（未リリース）

## 概要

pnpm が管理する Node.js ランタイムやエンジン（固定された pnpm 自体を含む）のインストール・選択まわり。グローバル `node` シムが `.nvmrc`・`.node-version` を読めるようになり（v12.7.0）、ピン留めされた pnpm/ランタイムのインストールでロック競合時は短い待機のあとプロセス専用のプライベートコピーで実行する。`runtime:` の範囲に `||` を含む場合に npm パッケージ `node` と誤解決される問題が直り、`pnpm-workspace.yaml` の無い単一プロジェクトでも固定された pnpm の `minimumReleaseAge` 承認が記録されるようになった。arm64 musl Linux では pnpm 11 のスタンドアロン実行ファイルの配布をやめる変更が入った（未リリース）。

## 主な API・オプション

- グローバル `node` シムのバージョン解決順（同一ディレクトリ）: `package.json` の `devEngines.runtime`/`engines.runtime` → `.node-version` → `.nvmrc`。ディレクトリをまたぐ場合は最も近い宣言が勝つ
- `.nvmrc` / `.node-version` — コメント・`v` プレフィックス・nvm エイリアスに対応
- ピン留めされたエンジン/ランタイムのインストール — 共有スロットのロックを5秒待ち、取れない場合はストアの `tmp/private` 配下に専用コピーを作って実行
- `devEngines.runtime` の範囲 — `^22.18.0 || ^24.0.0` のような `runtime:` の和集合も npm リゾルバーに渡らない。影響を受けた lockfile は `pnpm install --fix-lockfile` で解決し直せる

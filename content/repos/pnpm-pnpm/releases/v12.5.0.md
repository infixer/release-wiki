## 要点

- Python を一級のエコシステムとして扱い始めた（Python 対応の各種基盤が入った最初のリリース）
- `pnpm add` が Package URL（`pkg:npm/...`、`pkg:cargo/...`、`pkg:pypi/...`）を受け付けるように。`pkg` は予約済みの指定子接頭辞になった
- `registries` のエントリに `ecosystem`（`npm`/`cargo`/`pypi`）を指定できるように。エントリに資格情報は書けず `.npmrc` から読む
- `supportedArchitectures` がプラットフォーム名の列挙（例: `linux-x64`、`darwin-arm64`）に対応。Rust ターゲットトリプルも受け付ける。`os`/`cpu`/`libc` 方式も引き続き有効
- タスクに `concurrencyGroup`/`concurrencyGroups` によるマシン全体の同時実行数制限を追加
- `tools.<name>.mirror`/`channels` で pnpm がダウンロードするツール（Node/Bun/Deno/Python 等）のミラーを設定可能に
- 1つのパッケージの取得済み tarball を別のパッケージに使い回してしまう不具合を修正

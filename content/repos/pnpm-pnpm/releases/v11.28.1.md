## 要点

- StackBlitz WebContainers で `pnpm install` が動くように。lockfile の無いプロジェクトでの `ENOENT ... pnpm-lock.yaml` や `this.db.exec is not a function` を解消し、`node:sqlite` が使えないときはインデックスを `index.fallback` に保存する
- `patchedDependencies` とパッチのハッシュが食い違う lockfile を修復し、Windows のコマンドシム・injected なワークスペース依存・`pnpm deploy` の多数の不具合を修正（リリースノートの冒頭より）
- Node.js 24.4.x 上で `devEngines.runtime` のランタイムをダウンロードした後も `pnpm install` が完了する
- レジストリのパッケージが自身の内部ディレクトリへの `file:` 依存を宣言していても失敗せず、npm・Yarn と同様にその内部ディレクトリへリンクする（lockfile には `link:<root>/...`）
- ビルドが必要な git 依存の準備で、その依存の未承認のビルドスクリプトをスキップ。lockfile を持たない pnpm ワークスペースの git 依存は npm ではなく pnpm で準備する
- `pnpm install --dev`/`pnpm fetch --dev` が devDependencies の optional dependencies もインストールする
- `gitBranchLockfile` 有効時、detached HEAD でも `pnpm install --frozen-lockfile` が動く。`preferFrozenLockfile: true` を明示すると CI で古い lockfile を更新せず失敗する

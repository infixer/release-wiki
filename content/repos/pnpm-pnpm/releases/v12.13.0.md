## 要点

- **`pnpm profile`**: レジストリのユーザープロフィールの設定を表示・更新するコマンドを追加
- **`pnpm token`**: レジストリの認証トークンの一覧・作成・取り消しを追加
- **`storeIndexFormat` 設定**: `files` にすると、ストアのパッケージ索引を SQLite の `index.db` ではなくパッケージごとに 1 ファイルで持つ。複数のマシンが同時に使うネットワークファイルシステム上のストアでは SQLite のロックがマシンをまたいで効かず、同時インストールで `index.db` が壊れることがあった
- **`nodePackageMap` 設定**: package map の設定をまとめる。`mode: write-only` は Node.js に読み込ませずに `node_modules/.package-map.json` をほかのツール向けに書き、`mode: load` は `nodeExperimentalPackageMap: true` と同じく Node.js にも読み込ませる。`nodePackageMap.type` は `nodePackageMapType` を置き換える（旧設定も引き続き使える）（[#14937](https://github.com/pnpm/pnpm/issues/14937)）
- Python の依存解決の高速化
- `pnpm setup` の修正: macOS で npm から入れた pnpm でも動く（[#16855](https://github.com/pnpm/pnpm/issues/16855)）。`globalShims` で pnpm を有効にしたときに全コマンドが失敗する問題（[#16874](https://github.com/pnpm/pnpm/issues/16874)）。Windows の MinGW 向けの pnpm（MSYS2 のパッケージなど）は MinGW の Rust ツールチェーンを入れる
- インストールの修正: macOS の virtiofs・SMB 上で `ERR_PNPM_LOCKFILE_WRITE_FILE` にならない（[#16846](https://github.com/pnpm/pnpm/issues/16846)）、macOS で pnpmfile を読むコマンドが不定期にハングしない、`uv_build` のプロジェクトがインストールできる、hoisted で削除した `link:` 依存のシンボリックリンクを消す（[#16884](https://github.com/pnpm/pnpm/issues/16884)）、スコープのレジストリのパッケージの tarball URL を lockfile に記録しない（[#16866](https://github.com/pnpm/pnpm/issues/16866)）
- リリースノートの本文は「Packing, auditing, and pipelines」の途中で切れている

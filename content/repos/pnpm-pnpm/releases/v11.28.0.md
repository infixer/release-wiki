## 要点

- `forceIgnoresPlatform` 設定を追加。`false` にすると `pnpm install --force` が、`os`/`cpu`/`libc` がホストと合わない optional dependencies をスキップする（既定は `true` のまま）
- `pnpm update --peer` を追加
- `pnpm deploy`、`--filter`、`nodeLinker: hoisted`、カスタム `modulesDir` まわりの多数の不具合を修正
- セキュリティ修正: `pnpm-workspace.yaml` の `userAgent` の環境変数を展開しない（プレースホルダー付きは無視）、カスタム `modulesDir` 内のパッケージをワークスペースプロジェクトとして扱わない（未承認のライフサイクルスクリプトが走る問題）、Nix で bin シムとランチャーが乗っ取られない、シェル補完から制御文字などを含む候補を除外、`pnpm runtime set`/`pnpm env use` が pnpm に見えるだけのスクリプトを再実行しない、`pnpm store prune` がシンボリックリンクの `dlx` キャッシュルートを辿らない
- `pnpm install` が TLS 証明書の検証に失敗したら、1 分以上リトライせずすぐに失敗し、証明書の問題を示す
- SSH 経由の git 依存で ssh をバッチモードで実行し、パスフレーズやホスト鍵の確認待ちで止まったように見えなくなった

## 要点

- `pnpm-workspace.yaml` の未知のタスク設定は、エラーで停止せず警告して継続するように（`packageManager` が固定するバージョンで実行している場合は引き続きエラー）
- Python インタプリタのインストールで、リリースメタデータ取得のリトライとキャッシュ（最大24時間、失効後1回再取得）に対応
- Python の `registries` が `packages` パターン（完全一致・接頭辞一致）でパッケージをルーティングするように。宣言順に依存しなくなった
- ワークスペース上位の Cargo 設定ファイルがシンボリックリンクの場合の「Too many levels of symbolic links」エラーを修正
- `dedupeDirectDeps` で `node_modules` を持たないプロジェクトが毎回フルインストールされていた不具合を修正
- 16MiB 以上の `pnpm-lock.yaml` の変更で再インストール高速パスが使われない不具合を修正

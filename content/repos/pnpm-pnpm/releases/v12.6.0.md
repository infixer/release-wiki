## 要点

- `autoDedupe` で解決中に互換なバージョンの依存関係を自動的に重複排除できるように（オプトイン）
- macOS/Linux で、移動・コピーしたプロジェクトの `node_modules` と bin シムを再インストールなしで再利用できるように
- `pnpm add --save-types` で利用可能な `@types/*` パッケージを自動的に `devDependencies` に保存
- `package.yaml` マニフェストを `add`/`update`/`remove`/`pkg`/`link`/`set-script`/`version` から更新可能に（コメント・キー順を保持）
- カタログエントリで `file:`/`link:` プロトコルに対応
- `pnpm tasks status` で並行実行グループの実行中/待機中タスクを確認可能に。待機タスクは到着順・優先度順に枠を取得
- `pnpm cache prune` を追加（読めなくなった古いレジストリメタデータキャッシュを削除）
- `macosBackup.excludeModulesDir`/`excludeStoreDir` で新規作成ディレクトリを Time Machine から除外可能に
- `pnpm add --tilde`（`--save-prefix=~` の別名）、`progress` 設定/`--no-progress` を追加

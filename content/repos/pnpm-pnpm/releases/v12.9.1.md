## 要点

- **WebContainer 版を別パッケージに**: StackBlitz WebContainers 向けの WebAssembly 版は `@pnpm/wasm` として配布される。`pnpm`・`@pnpm/exe` には含まれなくなり、展開後のサイズは約 55 MB から約 4 MB に戻った。WebContainer では `@pnpm/wasm` を npm でインストールして `pnpm` コマンドを使う
- GitLab CI からの provenance 付き `pnpm publish` が npm レジストリに 422 で拒否されなくなった（`invocation.parameters` に GitLab CI の変数を含める）
- `pnpm audit signatures` が、署名鍵のリクエストのリダイレクト先の TLS 設定を使う。プライベートレジストリにスコープした `cafile` でリダイレクト先が失敗しない
- injected なワークスペースパッケージが `peerDependencies` に catalog のエントリを使っても、`pnpm install --frozen-lockfile` が最新の lockfile を拒否しない
- `[<since>]` フィルタが Git 2.24〜2.27 で再び動く（2.24 未満は必要なバージョンを示して失敗）。非 ASCII のディレクトリ名のプロジェクトの変更も正しく検出し、`changedFilesIgnorePattern`・`testPattern` も一致する
- `pnpm` の実行ファイルが約 10% 小さくなった（macOS arm64 で 45.1 MB → 40.3 MB）。長い公開履歴のパッケージの信頼性の格下げチェックが速くなった
- `optimisticRepeatInstall: false` なら、`node_modules` が最新でもプロジェクト自身の `prepare` などのライフサイクルスクリプトを実行する
- Homebrew で入れた pnpm の `pnpm self-update` は失敗し、`brew upgrade pnpm` / `brew upgrade pnpm@11` などのコマンドを案内する（以前は Homebrew 版に隠れる 2 つめの pnpm を入れていた）

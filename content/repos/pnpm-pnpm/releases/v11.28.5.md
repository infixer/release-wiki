## 要点

- `pnpm config get --global` がプロジェクトの設定を無視する。キャッシュしたレジストリのメタデータの読み込みが速くなった（メタデータのキャッシュは `<cache-dir>/v12/` に移った）
- **セキュリティ（config 依存・lockfile）**: config 依存をインストール前にレジストリと照合する。lockfile の検証が `variations` の中の tarball も照合する。`pnpm audit signatures` は lockfile に記録された integrity に対して署名を検証する
- **セキュリティ（git 依存）**: lockfile のリポジトリが空・`-` で始まる・NUL バイトを含む git 依存を拒否する（git がコマンドラインのオプションとして読まない）。`#path:` のサブパスを持つ git 依存が、サブパス内のシンボリックリンク経由でリポジトリの外のファイルに届かない
- **セキュリティ（パッケージの中身）**: `pnpm pack`・`pnpm publish` と git・ローカルディレクトリの依存のインストールで、ディレクトリのシンボリックリンクや `bundleDependencies` のエントリがパッケージの外を指すファイルを含めない。`deployAllFiles` の `pnpm deploy` はパッケージの外を指すシンボリックリンクを拒否する
- **セキュリティ（アーカイブ）**: 負の PAX レコード長や 4 GiB 以上のエントリを持つアーカイブで止まらない。大きなダウンロードと gzip・bzip2 のアーカイブ内の大きなファイルのメモリを抑え、64 MiB を超えるマニフェストとアーカイブのメタデータを拒否する
- **セキュリティ（その他）**: `+`・`#`・`:`・`?` と `/` だけが異なる URL・ローカルパスの依存が仮想ストアのディレクトリを共有しない。`pnpm licenses` の表の出力から端末の制御文字を取り除く。無視したプロジェクトの `.npmrc` の警告で URL にスコープしたキーのユーザー名とパスワードを表示しない

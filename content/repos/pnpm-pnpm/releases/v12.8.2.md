## 要点

- Linux ppc64le で起動時にクラッシュする問題を修正（v12.8.1 の既知の問題）
- `NODE_EXTRA_CA_CERTS` を設定した CA 証明書の無い Linux（`node:24-slim` など）で `UnknownIssuer` になる問題を修正。追加の証明書は同梱の CA ルートに足される
- ストア操作のロックなどユーザーごとのロックファイルを、ユーザーだけが書ける `$XDG_RUNTIME_DIR` があればそこに作る（無ければ従来どおり `/tmp`）。`/tmp` への書き込みを禁じるサンドボックスでも使える
- POSIX の bin シムと `pnpm`/`pn`/`pnpx`/`pnx` ランチャーが Nix のビルド内でも動く（再インストールで既存のシムが置き換わる）
- 別バージョンの pnpm を固定したプロジェクトで、知らないオプション付きのコマンドを固定された pnpm へ引き渡す（`pnpm install --auto-dedupe` の「Unknown option」を解消）
- `pnpm install --frozen-lockfile` が `Cargo.toml` の要求を満たさない `Cargo.lock` で失敗する（クレートとロック済みバージョンを表示）
- injected なワークスペース依存と共有 lockfile のワークスペースで「Already up to date」が戻った（12.7.0 以降は毎回フルインストールしていた）。`injectWorkspacePackages: true` の新規インストールでも `link:` で記録する
- `pnpm dedupe` 直後の `pnpm dedupe --check` が通る。`minimumReleaseAge` で `latest` が隠れたときは同じメジャーのプレリリースを下位メジャーの安定版より優先
- `autoDedupe` を有効にした CI で `pnpm run` のたびにインストールが走らなくなった。macOS での解決と hoisted インストールが速くなった（リリースノートの冒頭より）

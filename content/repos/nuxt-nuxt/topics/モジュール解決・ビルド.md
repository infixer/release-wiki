## 概要

Vite・Nitro によるモジュール解決と外部化（externalisation）、レイヤー・型生成などビルドまわり。`vue`・`vue-router` のように dedupe すべきパッケージを絶対パスによる外部化から除外したり、nitro とその暗黙の依存関係をホイスティングに依存せず解決したりする修正が入っている。開発サーバー（vite dev 環境）では `nuxt` 自体が誤って外部化されないようにし、public ファイル探索は1度のインデックス化にまとめられた。レイヤーについては、`node_modules` にインストールしたレイヤーのエントリを明示的にスキャンして依存関係を事前バンドルし、シンボリックリンク経由のレイヤーディレクトリは実パスに解決される。ほかに、開発中のコンポーネント名変更時の import 更新、移したビルドディレクトリでの型の保持、`@nuxt/kit` の peer dependency 範囲の拡大が入っている。

## 主な API・オプション

- 開発者が直接設定する API はほぼ無く、主に Vite/Nitro 内部の解決ロジック・`noExternal` 設定に関する修正
- `optimizeDeps` — ユーザーのディレクトリに無いパッケージも pnpm で解決できるようになった
- `vite.resolve.preserveSymlinks` — シンボリックリンク経由のレイヤーの不具合（[#36401](https://github.com/nuxt/nuxt/issues/36401)）の修正前の回避策

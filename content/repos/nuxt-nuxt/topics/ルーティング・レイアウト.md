## 概要

クライアント側のルーター・レイアウト遷移・ルートルールまわり。Vue Router が知らないパス（`public/` のファイルへのリンクなど）へのクライアント側ナビゲーションは、404 を出さずにハードリロードへ切り替える（experimental オプション、デフォルト有効）。アプリ側のルートルールは base URL からの相対パスで照合される。h3 v2 はルートルールの文字列・配列の指定に対応しないため、`appMiddleware` の文字列・配列は Nuxt 側でオブジェクト形式に正規化される（未リリース）。`pages/` を使わない場合のルーターも base URL を考慮し、ミドルウェアのフラグをクリアする。レイアウトが切り替わる遷移では、`NuxtLayout` の `onBeforeLeave` が pending 中の `nuxtApp['~transitionPromise']` を再利用し、離脱したページの head エントリが確実に破棄される。アンカーの href はルーター経由で解決され、`pages/` を使わないユニバーサルルーターの挙動は vue-router に揃えられた。絶対 URL でないリンクの描画は速くなっている（絶対 URL はわずかに重い）。ページ遷移はあるがレイアウト遷移が無い状態でレイアウトの違うページへ移動したとき、新しい `<NuxtPage>` は離れるページが無ければ遷移を始めないので、`~transitionPromise` が pending のまま残ってスクロールや head の破棄が止まることはない。存在しないパスへのナビゲーションが中断・キャンセルされたときは、そのページを正しくスキップし、`router.afterEach` で 404 にしない（いずれも未リリース）。
プリレンダー済みページのハイドレーションで遅延したルートを復元するときも、ミドルウェアが設定したレイアウトを保つ（未リリース）。
`unrouting` は ^0.3.1 になり、パラメータは位置パラメータ（`:_0`）で表され、省略可能なパラメータは複数のパターンに展開される。不要な型付きルートの生成も省かれた（いずれも未リリース）。
ルートルールによるページのカバー判定（`ssr: false` のバンドルから外す最適化）は、base URL の下・非 ASCII のパス（h3 と同じエンコード）・メソッド付きのキー（`'GET /admin/**'`、h3 の `parseRouteKey` と同じ解析）にも対応し、正規表現で制約したパラメータのルールは動的ページ全体のカバーとみなさない。`router.options.sensitive: false` のときはサーバーのルートルールも大文字・小文字を区別せずに一致する（`sensitive` は有効のままが推奨）。`navigateTo()` がリダイレクト先を返すのは Nuxt のミドルウェアの実行中だけになり（カスタムの `beforeResolve`・`onBeforeRouteUpdate` の中では新しいナビゲーションを始める）、公開の戻り値の型から `RouteLocationRaw` が外された。`experimental.viewTransition` で中断した遷移の `updateCallbackDone` の reject も処理される（いずれも未リリース）。

## 主な API・オプション

- `external` 属性 — クライアント側ルーティングを使わないリンクにする。付け忘れた public ファイルへのリンクはハードリロードで表示される
- `NuxtLayout` / `NuxtPage` — レイアウト・ページの遷移。`nuxtApp['~transitionPromise']` で head エントリの破棄を遅らせる
- ルートルール（`routeRules`）— アプリ側では base からの相対パスで照合。`appMiddleware` の文字列・配列はオブジェクト形式に正規化
- `setPageLayout()` — レイアウト名、または `false`（型でも許可）を渡す
- `navigateTo()` — 公開の戻り値の型は `Promise<void | NavigationFailure | false> | false | void`。リダイレクト先を返すのはミドルウェアの実行中だけ
- `router.options.sensitive` — `false` でもサーバーのルートルールが大文字・小文字を区別せずに一致する
- `experimental.viewTransition` — View Transitions API を使ったページ遷移

## 概要

Nuxt 5.x（`5.x` ラベル）での、Nitro v2 形式のサーバーコードとの互換対応（`packages/nitro-server/src/compat.ts`）と、モジュールを `nuxt/server` に移行するための支援まわり。
ユーザーのコードが v2 形式のパターンを使っているかを検出し（型の import は無視）、依存しているときはログで知らせる。
ルートを持たない v2 形式のハンドラーはグローバルミドルウェアとして登録される。
モジュール作者向けには `@nuxt/kit` に `resolveServerVariant` が追加され、`addServerImports` が variant に対応した。
ドキュメントはアップグレードガイドとサーバー互換性（`docs/3.guide/4.modules/9.server-compatibility.md`）のページ。
Nitro v2 互換コードのスコープのパス照合は、シンボリックリンクを解決してから行う。
v4.6.0 の Release 本文では、Nuxt をサーバー非依存にする方向（`#app` やモジュールを h3・nitro のメジャーバージョンに縛らない）が最大の変更として説明されている。
v2 形式（`nuxt2`）の dev ハンドラーは、1 回の登録で nitropack v2・nitro v3 のどちらでも `/foo` と `/foo/**` が「`/foo` とその下」に一致する（`nuxt`・`nitro3` の variant はルートに完全一致のまま）。
nitro v2 は小文字のメソッドしか受け付けないため、kit がファイル名から決めるハンドラーのメソッドは nitro v2 では小文字になる（Nuxt v4 での `$fetch` の型の問題の修正、未リリース）。
互換モードの v2 の `render:response` フックは、実際に送られるレスポンスのステータスとヘッダーを受け取る（未リリース）。
エラーページの描画中にレガシーな `event.$fetch` を呼んでも止まらない（サブリクエストに `~rendering-error` のコンテキストを付ける。未リリース）。
Nitro v2 の import の検出は、サーバーのエントリが import しているものだけを数える（未リリース）。Nuxt v5 では `server/utils/` も直下のファイルだけがスキャンされ、入れ子のディレクトリからの自動 import を使っていると警告が出る。`nitroLegacy.imports` で v4 の挙動に戻せる（未リリース）。
互換スキャンでは、`#meta/nitro` のようなモジュールの仮想モジュールをエイリアスで解決せず id のままたどる（誤った `NUXT_B9003` や `ENOTDIR` の修正、未リリース）。
Nuxt 5.x のサーバーは Nitro 3 の RC（rou3 v1 対応の unrouting を使用）に移行した（破壊的変更、未リリース）。
Nuxt v5 への移行向けに診断が増えた: `h3` を v1 に解決しているのにサーバーのコードが `h3` から import していると `NUXT_B9009`、Nitro v2 の深い import には専用の診断、発火しない Nitro v2 のフックのリスナーの報告、その他の小さな診断。h3 v1 のシムに `toWebRequest` が加わり、互換の `$fetch` は現在の dev の app に送られる。Nitro v3 ではキャッシュするルートルールで island の props のクエリを保ち、許されないルートルールに分かりやすいエラーを出す。`nuxt/server` のハンドラーではリクエストボディを本当にストリームで読める（いずれも未リリース）。

## 主な API・オプション

- `resolveServerVariant()`（`@nuxt/kit`）— `nuxt/server` へ移行するモジュール作者向けのユーティリティ
- `addServerImports()`（`@nuxt/kit`）— variant の指定に対応
- `addDevServerHandler()`（`@nuxt/kit`）— nitropack v2 では `/foo/**` のベースパスも登録する
- `nitroLegacy.imports` — 入れ子の `server/utils` のスキャン（Nuxt v4 の挙動）を有効にする
- `nitroLegacy.h3` — ユーザーのコードの `h3` を h3 v1 のヘルパーに解決する（無効で h3 v1 を使っていると `NUXT_B9009`）

## 概要

`nuxt.config` のオプションとスキーマ（`packages/schema`）、モジュールから設定を操作する `@nuxt/kit` の API まわり。トップレベルの `prerender` が `nitro.prerender` の別名として追加され（`runtimeConfig`・`routeRules` と同じ位置づけ）、トップレベルに同じオプションがある `nitro.*` は非推奨になった。ビルダーに依存しないトップレベルのオプションを使うよう案内されている。モジュールの `setup()` から `updateRuntimeConfig()` を呼んでも、Nitro の初期化前に `NUXT_B8003` の警告が出ないようになった。デフォルトの無視対象に `.wrangler` ディレクトリが加わり、miniflare の書き込みによるリロードの繰り返しが起きない。`@nuxt/kit` の互換性チェックのバージョンの正規表現は nightly のバージョン形式に対応した。

## 主な API・オプション

- `prerender` — `nitro.prerender` の別名（トップレベル）。今後 Nuxt 独自のプリレンダリング用オプションも追加予定
- `nitro.*`（トップレベルと重複するもの）— 非推奨。トップレベルのオプションを使う
- `updateRuntimeConfig()`（`@nuxt/kit`）— 内部で `tryUseNitro()?.updateConfig()` を使い、Nitro の初期化前でも警告しない

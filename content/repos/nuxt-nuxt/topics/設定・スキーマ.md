## 概要

`nuxt.config` のオプションとスキーマ（`packages/schema`）、モジュールから設定を操作する `@nuxt/kit` の API まわり。トップレベルの `prerender` が `nitro.prerender` の別名として追加され（`runtimeConfig`・`routeRules` と同じ位置づけ）、トップレベルに同じオプションがある `nitro.*` は非推奨になった。ビルダーに依存しないトップレベルのオプションを使うよう案内されている。モジュールの `setup()` から `updateRuntimeConfig()` を呼んでも、Nitro の初期化前に `NUXT_B8003` の警告が出ないようになった。デフォルトの無視対象に `.wrangler` ディレクトリが加わり、miniflare の書き込みによるリロードの繰り返しが起きない。`@nuxt/kit` の互換性チェックのバージョンの正規表現は nightly のバージョン形式に対応した。`sourcemap.client` / `sourcemap.server` には `'nosource'` を指定でき、ファイル名と行のマッピングは残して元のソース（`sourcesContent`）を含めないソースマップを出力する（Vite・Nitro・webpack / rspack に対応。boolean として読む箇所では `true` 扱い）。webpack の dev で hidden のクライアントソースマップに有効な devtool を使うよう修正された（いずれも未リリース）。
`vite.config.ts` が vite-plus の設定ファイルなら警告を出さない（未リリース）。

## 主な API・オプション

- `prerender` — `nitro.prerender` の別名（トップレベル）。今後 Nuxt 独自のプリレンダリング用オプションも追加予定
- `nitro.*`（トップレベルと重複するもの）— 非推奨。トップレベルのオプションを使う
- `updateRuntimeConfig()`（`@nuxt/kit`）— 内部で `tryUseNitro()?.updateConfig()` を使い、Nitro の初期化前でも警告しない
- `sourcemap.client` / `sourcemap.server` の `'nosource'` — `sourcesContent` を含めないソースマップを出力

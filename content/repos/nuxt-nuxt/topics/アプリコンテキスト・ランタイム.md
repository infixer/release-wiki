## 概要

`nuxt/app` 内部のコンテキスト・ランタイム実装まわり。`consola`・`cookie-es`・`hookable` の型が nuxt core の公開 API として切り出され、Nuxt 自身が追跡できるようになった。また、クライアント環境では `AsyncLocalStorage` が無いため不要な `unctx` の読み込みを止め、`app.config` が1つしか無い場合は `defu` によるマージ呼び出しを省略するなど、クライアント側の初期化を軽くする変更が入っている。
vapor のスロットは vue の `rawVaporSlotKey` シンボルで検出する（vue 3.5 には無いため、v3.6 までは間接的に扱う。未リリース）。
`onNuxtReady` は `timeout` で待ち時間の上限を、`signal`（`AbortController`）で保留中のコールバックの取りやめを指定できる。`useCookie` の CookieStore 同期は、外部からの変更を反映している間は書き込まない（いずれも未リリース）。

## 主な API・オプション

- 開発者が直接使う設定 API の変更ではなく、`nuxt/app` の内部実装・型の持ち方に関する変更
- `onNuxtReady(cb, { timeout, signal })` — 待ち時間の上限と、保留中のコールバックの取りやめ
- `useCookie(name, { refresh, maxAge })` — CookieStore の `change` による書き直しのループを修正

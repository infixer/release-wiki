## 新機能

### `nitroLegacy` で入れ子の `server/utils` をスキャンし、使用時に警告（[#36641](https://github.com/nuxt/nuxt/pull/36641)）

> [!tip] 何ができるようになったか
> Nuxt v5 では `app/utils/` と同様に `server/utils/` の直下のファイルだけがスキャンされる（nitropack の挙動が異なっていた Nuxt v4 からの破壊的変更）。入れ子のディレクトリからの自動 import が使われていることを検出し、`nitroLegacy.imports` で v4 の挙動に戻せるようになった。
>
> - **使い方**: `nitroLegacy.imports` を有効にする
> - **嬉しい場面**: `server/utils/` のサブディレクトリの関数を自動 import していたプロジェクトを v5 に移行するとき

⏳ 未リリース · トピック: [[repos/nuxt-nuxt/topics/サーバー互換性|サーバー互換性]]

## 変更・修正

### Nitro v2 互換のスキャンで、アプリ専用のモジュールコードを対象にしない（[#36638](https://github.com/nuxt/nuxt/pull/36638)）

> [!quote] Before
> すべての alias を Nitro v2 の import についてスキャンしていたため、両方を明示的にサポートするモジュール（nuxt-modules/i18n で見つかった）で問題が起きることがあった。

> [!success] After
> サーバーのエントリが import しているものだけを数える。ほかのいくつかの誤検出も修正し、ドキュメント（アップグレードガイド・kit の builder）も更新した。

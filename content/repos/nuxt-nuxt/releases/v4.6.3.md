## 要点

v4.6.3 は v4.6.2 の次のパッチリリース（[compare changes](https://github.com/nuxt/nuxt/compare/v4.6.2...v4.6.3)）。セキュリティ修正 5 件・パフォーマンス改善・修正が中心で、新機能は無い（取り込んだ Release 本文は途中で切れているため、以下はその範囲の要約）。

> [!warning] セキュリティ修正を含む
> 開発サーバー（Vite）とリクエストパスの扱いに関する修正があるので、更新が推奨される内容。

- **セキュリティ修正**
  - vite: クライアントのエラーレポートに書かれたファイルを読まない（[GHSA-x287-wcfc-q46c](https://github.com/nuxt/nuxt/security/advisories/GHSA-x287-wcfc-q46c)）
  - vite: dev サーバーから nitro の dev 出力へのアクセスを拒否（[GHSA-648h-gw55-m2g7](https://github.com/nuxt/nuxt/security/advisories/GHSA-648h-gw55-m2g7)）
  - vite: dev で生成したアプリのシークレットを配信しない（[GHSA-3xf4-9g3c-4h4w](https://github.com/nuxt/nuxt/security/advisories/GHSA-3xf4-9g3c-4h4w)）
  - nitro, nuxt: リクエストパスのドットセグメントを処理（[GHSA-9v7c-q64q-vv33](https://github.com/nuxt/nuxt/security/advisories/GHSA-9v7c-q64q-vv33)）
  - nuxt: ページの island にもリダイレクトのルートルールを適用（[GHSA-2fxj-c3j7-rr69](https://github.com/nuxt/nuxt/security/advisories/GHSA-2fxj-c3j7-rr69)）
- **パフォーマンス**: サーバービルドで通常の style ブロックをコンパイルしない（#36711）、ESM の Vue をバンドルしキャッシュを再利用（#36710）、`fs.allow` の入れ子ディレクトリの確認を二乗の計算量で行わない（#36702）、内部のカスタムリンクを RouterLink なしでサーバー描画（#36707）、不要な型付きルートの生成を省く（#36645）
- **ルーティング・ナビゲーション**: 外部ナビゲーションでアプリのスコープの破棄を遅らせる（#36713）、`navigateTo` がリダイレクトを返すのはミドルウェアの実行中だけ（#36650）、`navigateTo` の公開の戻り値の型から `RouteLocationRaw` を外す（#36691）、中断した View Transition の `updateCallbackDone` の reject を処理（#36639）
- **ルートルール**: 制約付きのルートルールを動的ページのカバーとみなさない（#36701）、ページのパスをエンコードしてからキーと照合（#36683）、`sensitive: false` で大文字・小文字に依存する制約を拒否（#36708）、キーの正規表現の制約を case-fold しない（#36694）、例外を探すときのページの接頭辞を正規化（#36685）
- **データ取得・コンポーザブル**: `useCookie` の CookieStore 同期が `refresh` で書き直しを繰り返さない（#36673）、破棄したエントリを `_asyncData` から取り除く（#36709）、keyed function の id とページの import 名を `rootDir` からの相対でハッシュ（#36697）
- **ビルド**: 自動 import した `#app` のコンポーザブルを tree-shake（#36696）、ビルドキャッシュのハッシュに `shared/` を含める（#36704）、引用符付きの `import.meta` キーを置換しない（#36703）、nitro: 自分自身への fetch とプリレンダーのヒントを共有しない（#36705）
- **その他**: ローディング画面のシェーダーの縦横比を狭い画面でも保つ（#36654）

> [!info] 収録状況について
> この Wiki の changes ページでは、上の PR の多くを collect の判定どおり「⏳ 未リリース」と記載している（main にマージされたもの）。v4.6.3 の本文には同じ番号の修正が載っている。

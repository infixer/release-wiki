## 要点

v4.6.0 はマイナーリリース（取り込んだ Release 本文は途中で切れているため、以下はその範囲の要約）。

- **Nuxt CLI v4（`@nuxt/cli` v4）を同時リリース**: `nuxt` の依存として入るので、アップグレードすれば自動で使われる。詳細は [Nuxt CLI v4 のリリースノート](https://github.com/nuxt/cli/releases/tag/v4.0.0)
- **`nuxt dev` の対話的なターミナル UI**: URL・起動の進行・キーボードショートカットを表示し、エラーログ・ルート・ネットワークリクエストなどのパネルを開ける。リロード・再起動の理由、変わった `nuxt.config` のキー、起動やビルドが遅いときの時間の内訳、モジュールごとのセットアップ時間も表示する
- **CLI レベルのエラーチャンネル**（`my-bad` で表示）: `nuxt.config.ts` の構文エラーを直すと自動でリロードする、といった機能に使われる
- **`.nuxt/` のロックファイル**: 2 つ目の `nuxt dev`（エージェントが起動したものなど）が、先に起動したものを引き継ぐか譲るかを決められる。実行中のサーバーと通信する新コマンド `nuxt curl`・`nuxt task` もこれを使う
- **その他の CLI の新機能**: `nuxt docs "<query>"` による検索、`nuxt preview --takeover` で実行中のプレビューサーバーを置き換え
- **CLI の軽量化・高速化**（v3.37 → v4.0）: インストールサイズ 13.1 MB → 3.5 MB（-73%）、依存 70 → 31、`nuxt dev` の最初の描画 330 ms → 50 ms（6.6 倍）、ポートの確保 338 ms → 104 ms（3.2 倍）、待機時のメモリ（Linux）630 MB → 440 MB（-30%）
- **サーバー非依存の Nuxt へ**: このリリースの最大の変更として、Nuxt をサーバー非依存にする方向へ進めている。これまで `#app` のコンポーザブルが h3 の型を import し、サーバーのコードが `h3`・`nitropack` から import していたため、サーバーに触るモジュールが Nuxt の依存する h3・nitro のメジャーバージョンに縛られていた（本文はこの説明の途中で切れている）

> [!warning] CLI v4 の要件の変更
> CLI v4 はメジャーバージョンだが、Nuxt v4 の利用者には破壊的変更は無いとしている。ただし Node.js v22.21+・v24.11+・v26+ が必要になり、`nuxt init` は廃止（`npm create nuxt@latest` のみ）、Nuxt 2 と `@nuxt/bridge` はサポート対象外になった。

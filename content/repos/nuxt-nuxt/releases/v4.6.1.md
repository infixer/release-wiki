## 要点

v4.6.1 は v4.6.0 の次のパッチリリース（[compare changes](https://github.com/nuxt/nuxt/compare/v4.6.0...v4.6.1)）。新機能は無く、性能改善 1 件と修正が中心（取り込んだ Release 本文は途中で切れているため、以下はその範囲の要約）。

- **性能**: nitro — ポータブルなイベントの web view を、最初にアクセスしたときに作る
- **データ取得・型**: 応答の型を指定した fetch でも任意の `baseURL` を受け付ける（#36523）、`Serialize` のオブジェクト型を JSON に揃える（#36503）、グローバルな `$fetch` を Nuxt の `TypedFetch` で型付け（#36492）、async data のコンポーザブルから参照される型を export（#36478）、`onServerPrefetch` を残して `useId` のハイドレーションを保つ（#36430）
- **ルーティング**: `setPageLayout` の型で `false` を許可（#36506）
- **Vite・開発サーバー**: Vite 8.1 以降の optimizer のメッセージにも依存関係のヒントを出す（#36525）、インストール済みパッケージ内の仮想 import で依存関係スキャンを止めない（#36477）、インライン style の URL を囲む文字列の区切りを検出（#36476）。vite-server では、SSR 以外の環境で設定された `outDir` を public ディレクトリに（#36501）、dev のエラーレポートにリクエストを含める（#36489）、デプロイ先のプラグインと組み合わせても dev で動く（#36491）、エラーページの描画にパスを渡す（#36488）
- **Nitro・kit**: dev のハンドラーパスを両方の Nitro メジャーで一致させる（#36515）、dev サーバーのハンドラーを 1 回だけ登録（#36493）、`nuxt` の dev サーバーハンドラーに `RequestEvent` を渡す、nodenext で `nitropack/types` の宣言を解決、Windows のパスに解決されたときも Nuxt のランタイムをインライン化、サーバーバンドルで `unhead` を Nuxt から解決。kit は見つからないサブパスの属するパッケージをインストール（#36507）、セマンティックバージョンの正規表現を nightly の形式に合わせる（#36479）
- **その他の修正**: `BroadcastChannel` が例外を投げる環境では dev エラーのブロードキャストを無効化（#36480）、schema で `.wrangler` ディレクトリを無視（#36487）、`nuxt` の dev サーバーハンドラーの variant を型付け
- **リファクタ・docs・chore**: kit が `package-manager-detector` のワークスペース・deno の扱いを使う、dev サーバーハンドラーと `nuxt/server` のスコープを文書化、`CLAUDE.md` の削除（#36462）など

> [!info] 収録状況について

## 要点

v4.6.2 は v4.6.1 の次のパッチリリース（[compare changes](https://github.com/nuxt/nuxt/compare/v4.6.1...v4.6.2)）。新機能は無く、修正が中心（取り込んだ Release 本文は途中で切れているため、以下はその範囲の要約）。

- **サーバー・Nitro**: server island の head に `useHeadSafe` のルールを適用、h3 が一致させたパスからルーターのパラメーターを読む、ルーティングが case-sensitive でなければサーバーのルートルールを大文字・小文字を区別せずに照合、`render:response` のリスナーにレスポンスヘッダーを渡す（#36583）、`nitroAutoImports` が off のときだけ h3・nitro のプリセットを無効にする（#36548）、`nuxt/server` のランタイムで使わない h3 の import を避ける（#36609）、文字列・配列の `appMiddleware` を正規化（#36565）、kit が nitro v2 でファイル名から決めるハンドラーのメソッドを小文字に（#36567）
- **ルーティング・ナビゲーション**: ルート相対のパスを URL パーサーで判定（#36617）、数字で始まる ID へのスクロールのオフセットを修正（#36524）、遅延したプリレンダー済みルートの復元時にミドルウェアのレイアウトを保つ（#36560）、離れるページが無いときはページ遷移を始めない（#36535）、中断・キャンセルされたナビゲーションでエラー状態を保つ（#36546）
- **型・tsconfig**: shared のコンテキストで空のルートの型を解決（#36576）、ビルドディレクトリを移してもサーバーの tsconfig を保つ（#36494）、ドットを含むモジュールのディレクトリをアプリの tsconfig から除外しない（#36331）、`experimental.typescriptPlugin` に既定値（#36561）、出力されるサーバールートの型のために `AnyFetchPath` を再 export（#36610）、`nuxt/app` をアプリのランタイムに解決（#36587）
- **Vue**: vue の `rawVaporSlotKey` で vapor のスロットを検出（#36614）
- **Vite・開発サーバー**: コンパイルエラーのオーバーレイは新しく読み込んだページにだけ再送（#36611）、nitro のプラグインから dev の SSR エントリーをウォームアップ（#36615）、アセット URL のヘルパーをビルドごとに分ける（#36591）、dev でインライン化した `vue` をバンドラー向けのビルドに解決（#36569）、NUL バイトを含む仮想 CSS を `/@id/` 経由でリンク（#36549）、SPA のローディングテンプレートの場所を尊重（#36536）
- **依存関係の解決**: kit がモジュールの依存モジュールを宣言したモジュールから解決（#36542）、宣言していない依存関係にアクセスしない（#36541）、絶対パスの transpile ディレクトリの下にある依存関係をインライン化しない（#36540）
- **リファクタ・docs**: webpack・rspack の friendly errors プラグインをインライン化（#36568）、DeepWiki のバッジ削除（#36616）、`proxy` のルートルールへの言及、テスト環境の説明の明確化（#32963）など

> [!info] 収録状況について
> この Wiki の changes ページでは、上の PR の多くを collect の判定どおり「⏳ 未リリース」と記載している（`5.x` ラベル付きで main にマージされたもの）。v4.6.2 の本文には同じ番号の修正が載っている。

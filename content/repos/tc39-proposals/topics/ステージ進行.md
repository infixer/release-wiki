## 概要

TC39 の提案（proposals）が委員会の会議を経て Stage を進める・追加される・取り下げられるといった動きを追うトピック。tc39/proposals リポジトリでは、こうした動きは README 内の Stage 別提案一覧表の更新（行の追加・削除・移動）として PR に現れるため、この表の差分をもとに記録する。Stage 4 に到達した提案は README の表から外れ、`finished-proposals.md`（Expected Publication Year＝公開予定年つき）に移される。

2026-09-29 の TC39 会議では、Iterator Join・Iterator Includes・Iterator Chunking の 3 提案が Stage 4 に到達した（Iterator Join の公開予定年は 2027）。

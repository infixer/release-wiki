## 新機能

### `tsc` の wasip1（Wasm）ビルドを追加（実験的）（[#64174](https://github.com/microsoft/TypeScript/pull/64174)）

> [!tip] 何ができるようになったか
> `wasip1/wasm` 向けにビルドした `tsc.wasm` が加わった。1 つのファイルを 2 通りに使える。
>
> - **コマンドとして**: 任意の WASI ホストで実行すると、CLI・LSP サーバーなどとして動く
> - **リアクターとして**: インスタンス化して IPC ベースの JS API に渡すと、ブラウザを含めて同期・非同期の API が使える
> - **注意**: まだ実験的で、`tsc.wasm`・wasip1 のパッケージ（`packages/typescript-wasip1-wasm`）・`typescript/wasm` のホストはいずれも「無保証」扱い

⏳ 未リリース · トピック: [[repos/microsoft-TypeScript/topics/プログラム的API|プログラム的API]]、[[repos/microsoft-TypeScript/topics/開発ツールとCI|開発ツールとCI]]

### API に `createFileSystemFromSnapshot(oldSnapshot, extraFSLayer)` を追加（[#64679](https://github.com/microsoft/TypeScript/pull/64679)）

> [!tip] 何ができるようになったか
> 古いスナップショットが持つ合成のファイルシステムを、新しいスナップショットの既存のファイルシステムの上に適用し直して（git の rebase のように）新しいスナップショットを作れる。
>
> - **使い方**: `const rebased = next.update({ fileSystem: createFileSystemFromSnapshot(old) })`。第 2 引数で、さらに上に重ねるファイルシステムも渡せる
> - **注意**: `old` が `full` でファイルシステムを置き換えていた場合は、`new` のファイルシステムも完全に置き換わる（変わるのは下の実ファイルの読み直しだけ）

⏳ 未リリース · トピック: [[repos/microsoft-TypeScript/topics/プログラム的API|プログラム的API]]

## 変更・修正

### 文の位置のクラス宣言をエラーに（[#65005](https://github.com/microsoft/TypeScript/pull/65005)）

> [!quote] Before
> `if (cond) class C {}` のように、`if`・`else`・ループ・ラベル付き文の本体に直接書いたクラス宣言は、JavaScript エンジンでは `SyntaxError` になるのに、`tsc` は `.ts` でも `.js` でもエラーにしなかった（#22682）。

> [!success] After
> `interface`・`type` と同じく `error TS1156: 'class' declarations can only be declared inside a block.` を報告する。クラス式やブロック・case 節・名前空間・関数本体・トップレベルのクラス宣言は影響を受けない。

⏳ 未リリース · トピック: [[repos/microsoft-TypeScript/topics/型チェッカー・コンパイラ|型チェッカー・コンパイラ]]

## 概要

tsgo（TypeScript 7）の言語サービス（エディタ向け補完・LSP）で、いくつかの補完まわりの不具合が修正された。VS Code で tsgo を使うと `import {` のような名前付きインポートの途中でオートインポートの補完候補が一切表示されない問題や、テンプレートリテラル型などから作られたキー型のオブジェクトプロパティ名の補完がクォート設定（`single`/`double`/`auto`）を無視してダブルクォートで挿入される問題を修正した。LSP まわりでは、判別共用体（discriminated union）のデコードを、VS Code のクライアントが判別子を先頭に置くという前提を使って最適化し、クロスプロジェクトのパニック処理にあったスペルミスも直した。

## 主な API・オプション

- 補完の `filterText` — import 文の補完で、生成される文全体（`insertText`）と同じ値を持つようになった
- クォート設定（`single` / `double` / `auto`）— オブジェクトプロパティ名の補完にも反映されるようになった

## 概要

tsgo（Go 移植後のコンパイラ、`tsc/internal/checker` など）の型チェッカーまわりでは、細かな正しさの修正とパフォーマンス改善が続いている。制約（`extends`）付きジェネリック関数を再帰的に呼び出すコード（Zod のようなライブラリが依存するパターン）で誤って報告されていた循環参照エラーを抑制し、オブジェクトの分割代入パターンのデフォルト値の扱いを配列と揃え、`as const` のタプルが `never` 型のコンテキストで誤って `readonly` を失う不具合を修正した。算出プロパティ名（computed property name）の再構築処理をシンボル追跡から分離するバグ修正や、シンボルリンクの重複ルックアップの削除・シンボルテーブルの事前確保といった内部的なパフォーマンス改善も入っている。composite project のルートチェックでは、正規化済み（canonical）のソースファイルパスを常に使うよう修正された。`lib.es5.d.ts` の `RegExp.source` の JSDoc に残っていた誤記も削除された。グローバル診断の集め方は Strada（旧 TypeScript）のやり方に戻し、エディタでは診断を出さないチェッカーからのグローバル診断を返さないようにした。`target` / `lib` には `es2026` も指定できるようになった。テンプレートリテラル型の大きさに上限（5,000 万文字・プレースホルダー 10 万）が設けられて TS2589 を報告するようになり、`resolveObjectTypeMembers` の冪等性の回復で無限循環するインスタンス化を示す新しいエラーが出るようになった。Zod などの再帰スキーマ向けの交差型の扱いの変更、`never` 簡約の最適化、宣言出力（宣言マップ・`isolatedDeclarations`・打ち切り後の複製）の修正、JSX 出力や JS の TS2565 のリグレッション修正なども入っている。また宣言出力では、型の循環や打ち切りを黙って `/* elided */ any` にせずエラーとして報告するようになり、reverse mapped type の保持や配列・タプル型の循環検出、名前空間の expando export・`export=` とトップレベル `export type` の可視性の修正が続いた。型引数からの推論のキャッシュ（キャッシュキーの不足による推論の欠落を修正）、再帰的な呼び出し解決での制約による絞り込み、static プロパティの誤った循環エラーの抑制、マージされた宣言の診断位置の決定化も入った。`esnext` の lib には `Promise.allKeyed` / `Promise.allSettledKeyed` が追加され、`verbatimModuleSyntax` ではデフォルト import の横の空の `{}` を出力しなくなった。TC39 の Source Phase Imports にも対応し、`getInferTypeParameters` の結果の順序が安定化された。同梱の DOM の型定義（`lib.dom.d.ts`・`lib.webworker.d.ts`）も更新され、Web Serial・Document Picture-in-Picture・`CloseWatcher`・`Element.setHTML()`・WebGPU・WebTransport などの型が加わった（`WritableStreamDefaultWriter.write()` の chunk 引数の必須化や `HTMLImageElement.crossOrigin` の型の絞り込みなど、互換性に影響しうる変更もある）。emit の有無で出たり出なかったりする不安定な診断（JS のコンストラクタで定義したプロパティ、`typeof import()` の型修飾子）の修正、decorator metadata の出力でデコレータ付きのオブジェクトリテラルのメンバーがクラッシュする問題の修正、`node_modules` 経由と相対 import の両方で到達するファイルの外部ライブラリ判定が実行ごとに変わる問題の修正も入った。メモリ面では、`Symbol` をヘッダーとデータに分け、インスタンス化したシンボルが元のデータを共有するようにした（96 → 24 バイト）。宣言出力の `getAlternativeContainingModules` は外部モジュールの export の索引を使うようになり、インクリメンタル再ビルドが大幅に速くなった。計算されたプロパティ名は親の文法エラーに関係なく常にチェックされ、名前空間の束縛を持たない deferred import は拒否される。emit では、不正な分割代入や、デコレータ付きクラスの重複したプライベート名でのクラッシュが直った（いずれも未リリース）。`esnext` の lib には iterator のメソッドの型定義（`lib.esnext.iterator.d.ts`）が加わった。ページ単位の link store は密に割り当てるようになり、複数チェッカーでのコンパイル（VS Code を 8 チェッカー）でメモリ使用量が 8〜9% 減った（いずれも未リリース）。`ValueSymbolLinks` も 16 バイト小さくなり、シンボルテーブルの種別マスクの誤りで無効になっていたエイリアスのキャッシュとメンバーの高速パスが働くようになった。名前型付きのジェネリックな mapped type の `keyof` の簡約が移植され、同じファイルで宣言した ambient module の中の import は Strada と同じく解決しない（`@types/lodash` 全体の取り込みによる大量のインスタンス化を回避）。`es2023.intl` には `Intl.PluralRules.prototype.selectRange` が加わった。宣言出力と emit では、`--stripInternal` で型エイリアスの右辺が消えたときのパニック、到達できないパッケージの `exports` の使用、JSDoc の修飾子の計算、ダウンレベルした `static {}` ブロック内の関数の `this` の書き換え、デコレータ付きクラス（無名クラス・プライベートメンバーの自己参照）の出力が修正された（いずれも未リリース）。メモリ最適化の一連の変更（#64734）として、union・intersection の正規化でキャッシュヒット時の割り当てをなくし（割り当てバイト数 8.51% 減）、型ノードのリンクとシグネチャから任意の状態を切り出して小さくし、AST の `nodeData` を生成したアクセサに置き換えてバイナリを 3.44% 縮めた。`getSimplifiedType` は条件型の結果もキャッシュし、`compareNodes` には同じ親を持つノードの高速パスが入った。JSDoc の `@extends` の型引数を呼び出し式の継承でも正しく再解析するよう修正された（いずれも未リリース）。`prop?: undefined` の合成プロパティを名前ごとでなく元のシンボルごとにキャッシュするようにし、宣言出力が他のファイルや `--checkers` の値に左右されなくなった（未リリース）。クラス・インターフェースの型のメンバーは共有のメンバーレイアウトから遅延して解決するようになり、mapped type ではシグネチャの問い合わせでプロパティを解決しなくなった（MUI の docs で 8.10% 高速化、いずれも未リリース）。import 属性の無い import では、パターンの ambient module があっても通常の解決が成功すればモジュールでないことのエラーを報告するよう戻し、関数型の束縛パターンの暗黙の `any` エラーを確実に報告するようにした。reverse mapped type は public 以外のメンバーを写さなくなり（`Readonly<C & T>` の推論での TS2352 のリグレッション修正）、import-equals の出力ではマージされた名前空間への参照を名前空間名で修飾する。性能面では、シンボルテーブルのエントリを `*ast.Symbol` だけにして改名をプロキシのシンボルで表し、交差型のプロパティ名の数え上げを map と slice にし（mui-docs で 5.83% 高速化）、printer のバッファの事前確保をファイル全体の出力時だけにした（いずれも未リリース）。
`if (cond) class C {}` のような文の位置のクラス宣言は TS1156 になり、es2026 の `JSON.parse` の reviver は再び省略可能になった。union の部分集合の判定はソート済みの構成要素の走査で行う（いずれも未リリース）。

## 主な API・オプション

- `target` / `lib` の `es2026` — 新たに指定可能に
- `lib` の `esnext`（`esnext.promise`）— `Promise.allKeyed` / `Promise.allSettledKeyed` の型定義
- `lib.dom.d.ts` / `lib.webworker.d.ts` — DOM の型定義。`navigator.serial`・`documentPictureInPicture`・`CloseWatcher`・`Origin`・`Element.setHTML()` などを追加
- `lib` の `esnext`（`lib.esnext.iterator.d.ts`）— iterator のメソッドの型定義（[#64095](https://github.com/microsoft/TypeScript/pull/64095)）
- `lib` の `es2023.intl` — `Intl.PluralRules.prototype.selectRange` の型定義（[#63424](https://github.com/microsoft/TypeScript/pull/63424)）

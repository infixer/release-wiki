## 概要

tsgo（Go 移植後のコンパイラ、`tsc/internal/checker` など）の型チェッカーまわりでは、細かな正しさの修正とパフォーマンス改善が続いている。制約（`extends`）付きジェネリック関数を再帰的に呼び出すコード（Zod のようなライブラリが依存するパターン）で誤って報告されていた循環参照エラーを抑制し、オブジェクトの分割代入パターンのデフォルト値の扱いを配列と揃え、`as const` のタプルが `never` 型のコンテキストで誤って `readonly` を失う不具合を修正した。算出プロパティ名（computed property name）の再構築処理をシンボル追跡から分離するバグ修正や、シンボルリンクの重複ルックアップの削除・シンボルテーブルの事前確保といった内部的なパフォーマンス改善も入っている。composite project のルートチェックでは、正規化済み（canonical）のソースファイルパスを常に使うよう修正された。`lib.es5.d.ts` の `RegExp.source` の JSDoc に残っていた誤記も削除された。グローバル診断の集め方は Strada（旧 TypeScript）のやり方に戻し、エディタでは診断を出さないチェッカーからのグローバル診断を返さないようにした。`target` / `lib` には `es2026` も指定できるようになった。テンプレートリテラル型の大きさに上限（5,000 万文字・プレースホルダー 10 万）が設けられて TS2589 を報告するようになり、`resolveObjectTypeMembers` の冪等性の回復で無限循環するインスタンス化を示す新しいエラーが出るようになった。Zod などの再帰スキーマ向けの交差型の扱いの変更、`never` 簡約の最適化、宣言出力（宣言マップ・`isolatedDeclarations`・打ち切り後の複製）の修正、JSX 出力や JS の TS2565 のリグレッション修正なども入っている。また宣言出力では、型の循環や打ち切りを黙って `/* elided */ any` にせずエラーとして報告するようになり、reverse mapped type の保持や配列・タプル型の循環検出、名前空間の expando export・`export=` とトップレベル `export type` の可視性の修正が続いた。型引数からの推論のキャッシュ（キャッシュキーの不足による推論の欠落を修正）、再帰的な呼び出し解決での制約による絞り込み、static プロパティの誤った循環エラーの抑制、マージされた宣言の診断位置の決定化も入った。`esnext` の lib には `Promise.allKeyed` / `Promise.allSettledKeyed` が追加され、`verbatimModuleSyntax` ではデフォルト import の横の空の `{}` を出力しなくなった。TC39 の Source Phase Imports にも対応し、`getInferTypeParameters` の結果の順序が安定化された。同梱の DOM の型定義（`lib.dom.d.ts`・`lib.webworker.d.ts`）も更新され、Web Serial・Document Picture-in-Picture・`CloseWatcher`・`Element.setHTML()`・WebGPU・WebTransport などの型が加わった（`WritableStreamDefaultWriter.write()` の chunk 引数の必須化や `HTMLImageElement.crossOrigin` の型の絞り込みなど、互換性に影響しうる変更もある）。emit の有無で出たり出なかったりする不安定な診断（JS のコンストラクタで定義したプロパティ、`typeof import()` の型修飾子）の修正、decorator metadata の出力でデコレータ付きのオブジェクトリテラルのメンバーがクラッシュする問題の修正、`node_modules` 経由と相対 import の両方で到達するファイルの外部ライブラリ判定が実行ごとに変わる問題の修正も入った。メモリ面では、`Symbol` をヘッダーとデータに分け、インスタンス化したシンボルが元のデータを共有するようにした（96 → 24 バイト）。宣言出力の `getAlternativeContainingModules` は外部モジュールの export の索引を使うようになり、インクリメンタル再ビルドが大幅に速くなった。計算されたプロパティ名は親の文法エラーに関係なく常にチェックされ、名前空間の束縛を持たない deferred import は拒否される。emit では、不正な分割代入や、デコレータ付きクラスの重複したプライベート名でのクラッシュが直った（いずれも未リリース）。

## 主な API・オプション

- `target` / `lib` の `es2026` — 新たに指定可能に
- `lib` の `esnext`（`esnext.promise`）— `Promise.allKeyed` / `Promise.allSettledKeyed` の型定義
- `lib.dom.d.ts` / `lib.webworker.d.ts` — DOM の型定義。`navigator.serial`・`documentPictureInPicture`・`CloseWatcher`・`Origin`・`Element.setHTML()` などを追加

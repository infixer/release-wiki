## 変更・修正

### `%TypedArray%.prototype.filter` / `with` の誤ったアサーションを修正（[#3979](https://github.com/tc39/ecma262/pull/3979)）

> [!quote] Before
> `filter` と `with` の手順にあるアサーションが、コールバックや値の変換の途中で元の `ArrayBuffer` がリサイズ・切り離し（detach）される場合に成り立たず、仕様のバグになっていた（#3978）。

> [!success] After
> 誤ったアサーションを直した（Editorial。`spec bug`・`has test262 tests` ラベル付き）。PR 本文によると、切り離しが関係するのは `filter` だけで、`with` は変換が `IsValidIntegerIndex` の確認より前に行われるため該当しない。

```js
let rab = new ArrayBuffer(16, { maxByteLength: 16 });
let ta = new BigInt64Array(rab);

ta.with(0, { valueOf() { rab.resize(8); return 0n; } });
ta.filter(() => { rab.resize(8); return true; });
```

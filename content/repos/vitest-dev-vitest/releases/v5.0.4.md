## 要点

新機能（experimental）とバグ修正のリリース（取り込んだ Release 本文は途中で切れているため、以下はその範囲の要約）。

- experimental: キャッシュディレクトリに `CACHEDIR.TAG` を置く（[#11461](https://github.com/vitest-dev/vitest/issues/11461)）
- experimental: `test.ui.theme` オプションに対応（[#11499](https://github.com/vitest-dev/vitest/issues/11499)）
- experimental: トレースビューでセレクターが複数一致したときにハイライト（[#11489](https://github.com/vitest-dev/vitest/issues/11489)）、トレースビューアーにフィット・ズームの操作を追加（[#11490](https://github.com/vitest-dev/vitest/issues/11490)）
- experimental: `--changed` の実行時に、影響を受けたテストの数と合計を表示（[#11424](https://github.com/vitest-dev/vitest/issues/11424)）
- experimental: 依存関係を静的に解析する代わりにキャッシュするオプションを追加（[#11515](https://github.com/vitest-dev/vitest/issues/11515)、`experimental.recordDependencies`）
- 修正: git と位置指定フィルタのエラーで実行を失敗させる（[#11430](https://github.com/vitest-dev/vitest/issues/11430)）、`--changed` でプロジェクトのファイルとモックを追跡（[#11432](https://github.com/vitest-dev/vitest/issues/11432)）
- 修正: `fsModuleCache` をデフォルトで有効化（[#11435](https://github.com/vitest-dev/vitest/issues/11435)）。キャッシュをリファクタし、プロジェクト名の `:` を修正、`results` キャッシュの形を変更（[#11453](https://github.com/vitest-dev/vitest/issues/11453)）
- 修正: `taskTitleValueFormatTruncate` が 0 のとき `$` の文字列値を省略しない（[#11485](https://github.com/vitest-dev/vitest/issues/11485)）、クライアント環境で Node のビルトインを解決（[#11417](https://github.com/vitest-dev/vitest/issues/11417)）、#11421 以降のモジュールグラフのビルトインの external を修正（[#11491](https://github.com/vitest-dev/vitest/issues/11491)）

## 要点

バグ修正のリリース（取り込んだ Release 本文は途中で切れているため、以下はその範囲の要約）。

- API トークンのファイルを守りつつ、Vite の既定の `fs.deny`（`.env`・`*.pem`・`.git`）を保つ（[#11578](https://github.com/vitest-dev/vitest/issues/11578)）
- `--changed` で引用符付きのファイル名を扱う（[#11583](https://github.com/vitest-dev/vitest/issues/11583)）
- `import.meta.hot` のスタブに `data` を追加（[#11590](https://github.com/vitest-dev/vitest/issues/11590)）、`skipIf` で `skip` を設定し `undefined` のオプションを無視（[#11591](https://github.com/vitest-dev/vitest/issues/11591)）
- Node 26.12 対応: 非同期リーク検出でビルトインの読み込みを無視（[#11598](https://github.com/vitest-dev/vitest/issues/11598)）、ネイティブローダーのエラーで import の位置を保つ（[#11599](https://github.com/vitest-dev/vitest/issues/11599)）
- 後のフックが失敗してもフックのクリーンアップを実行（[#11605](https://github.com/vitest-dev/vitest/issues/11605)）、終わったテストファイルのモックを解放（[#11607](https://github.com/vitest-dev/vitest/issues/11607)）、キャンセル時に実行中のテストをすべて中断（[#11606](https://github.com/vitest-dev/vitest/issues/11606)）
- browser: 合成の `pagehide` を無視（[#11582](https://github.com/vitest-dev/vitest/issues/11582)）、サーバー作成時にプラグインの `buildStart` を実行（[#11593](https://github.com/vitest-dev/vitest/issues/11593)）、閉じたセッションの遅れた接続を捨てる（[#11600](https://github.com/vitest-dev/vitest/issues/11600)）、ブラウザの終了を 30 秒待つ（[#11601](https://github.com/vitest-dev/vitest/issues/11601)）、`browser.instances` のグローバルセットアップを 1 回だけ実行（[#11596](https://github.com/vitest-dev/vitest/issues/11596)）
- reporter: ワーカーのクラッシュ時に終了理由を `'failed'` に（[#11568](https://github.com/vitest-dev/vitest/pull/11568)）

## 要点

バグ修正のみのリリース（取り込んだ Release 本文は途中で切れているため、以下はその範囲の要約）。

- `repeats` の各回で `result.status` を分離（[#11218](https://github.com/vitest-dev/vitest/issues/11218)）。`test.fails` が期待どおり失敗したときはリトライしない（[#11219](https://github.com/vitest-dev/vitest/issues/11219)）
- キャッシュキーの生成関数をプロジェクト単位に（[#11281](https://github.com/vitest-dev/vitest/issues/11281)、[#11301](https://github.com/vitest-dev/vitest/issues/11301)）。cache: キャッシュ済みモジュールの import を再検証（[#11381](https://github.com/vitest-dev/vitest/issues/11381)）
- browser: サーバーの `listen` をテストの実行開始まで遅延（[#11366](https://github.com/vitest-dev/vitest/issues/11366)）、モックのパスの境界を確認（[#11361](https://github.com/vitest-dev/vitest/issues/11361)、[#11362](https://github.com/vitest-dev/vitest/issues/11362)）、ブラウザが使う環境の設定を保持（[#11378](https://github.com/vitest-dev/vitest/issues/11378)）、キャンセル中のページのクラッシュを無視（[#11386](https://github.com/vitest-dev/vitest/issues/11386)）、リトライしたテストで `toMatchScreenshot` が誤った参照画像を使う不具合を修正（[#11393](https://github.com/vitest-dev/vitest/issues/11393)）
- ブラウザモードでインターセプターの警告を出さない（[#11377](https://github.com/vitest-dev/vitest/issues/11377)）
- expect: `expect.extend` の非対称マッチャーに現在の等価性テスターを渡す（[#11401](https://github.com/vitest-dev/vitest/issues/11401)）
- deps: `why-is-node-running` を `3.2.1` に固定し、`ERR_PNPM_TRUST_DOWNGRADE` を回避（[#11403](https://github.com/vitest-dev/vitest/issues/11403)）
- jsdom: jsdom 30.1 の `Blob` に対応
- この回の PR では、vm プールで Vite の環境をまたいでスクリプトを再利用しない修正（[#11395](https://github.com/vitest-dev/vitest/pull/11395)）も 📦 v5.0.3 に収録されている

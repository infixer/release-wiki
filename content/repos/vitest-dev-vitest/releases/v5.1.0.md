## 要点

機能追加のマイナーリリース（取り込んだ Release 本文は途中で切れているため、以下はその範囲の要約）。

- 前回失敗したテストだけを実行する `--last-failed`（[#11558](https://github.com/vitest-dev/vitest/issues/11558)）と、前回の実行からの変更を見る `--since-last-run`（[#11516](https://github.com/vitest-dev/vitest/issues/11516)）
- 失敗したスナップショットを対話的にレビュー（[#11325](https://github.com/vitest-dev/vitest/issues/11325)）
- `vi.setSystemTime()` が `Temporal.Instant`・`Temporal.ZonedDateTime` に対応（[#11321](https://github.com/vitest-dev/vitest/issues/11321)）、`node:timers`・`node:timers/promise` のフェイクタイマー（[#10899](https://github.com/vitest-dev/vitest/issues/10899)）
- リトライ・繰り返しの試行ごとの結果を公開（[#11232](https://github.com/vitest-dev/vitest/issues/11232)）
- カバレッジのプロバイダーが fs モジュールキャッシュにデータを保存できる（[#11747](https://github.com/vitest-dev/vitest/issues/11747)）
- browser: import map によるモジュールのモック（[#11534](https://github.com/vitest-dev/vitest/issues/11534)）、実験的な `pointer` API（[#10780](https://github.com/vitest-dev/vitest/issues/10780)）
- browser: トレースビューが実験的扱いを外れ（[#11518](https://github.com/vitest-dev/vitest/issues/11518)）、aria スナップショットを記録（[#11492](https://github.com/vitest-dev/vitest/issues/11492)）、失敗時にターミナルへステップのタイムラインを表示（[#11594](https://github.com/vitest-dev/vitest/issues/11594)）、失敗したテストだけを残すモードを追加

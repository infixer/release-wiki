## 概要

Vitest のブラウザモード（`packages/vitest/src/node/plugins/browserLoader.ts` など）。ブラウザ用のサーバーはテストの実行が始まるまで `listen` しないため、VS Code 拡張のようにテストを収集だけして実行しない使い方でも、optimizer の処理が途中で打ち切られてエラーになることがない。

## 変更履歴

- 2026-09-28 — テストの実行が始まるまでブラウザモードのサーバーの `listen` を遅らせ、テストの収集だけを行う VS Code 拡張で optimizer がエラーになる問題を修正（[#11366](https://github.com/vitest-dev/vitest/pull/11366)）⏳ 未リリース · [[repos/vitest-dev-vitest/changes/2026-09-28|変更]]

## 概要

`vi.spyOn` などモック・スパイまわりの実装。ビルトインオブジェクトのプロトタイプメソッドにスパイを仕込んだ際、内部的な呼び出し記録処理がスパイ自身を再度呼び出してしまわないようにする、といった再帰まわりの不具合修正が中心。ブラウザモードのモックでは、モック対象のパスがルート配下かどうかを境界（末尾のスラッシュ）付きで判定する。モックのインターセプター（別の公開パッケージ）はセキュリティが改善され、ブラウザモードでは警告を出さない。ブラウザモード（Chromium）でモックがランダムに効かない問題（`vi.mocked(...).mockX is not a function` など）は、インターセプトを最初の `vi.mock` 登録時に 1 回だけ有効にし、有効化を確認してから登録を完了するよう修正された。確認できなければ 5 秒でエラーにする。`vi.resetAllMocks()`（`mockReset: true` を含む）は、呼ばれた・設定し直されたモックだけをリセットし、`isolate: false` の大規模なスイートで大幅に速くなった。in-source testing でもモジュールのモックがラップされる。jsdom・happy-dom などのクライアント環境では、ファクトリー無しの `vi.mock('os')` のように Node のビルトインもモックできる。ブラウザモードでは、セットアップファイルの `vi.mock` の準備をテストファイルの import 前に待つようになった（Node では以前から待っている。未リリース）。`vi.mock` の相対パスは、URL エンコードされたスタックトレースのパスをデコードしてから解決するため、空白を含むディレクトリでも効く。ネイティブローダーでは、ホイストする呼び出しが無いファイルの import を書き換えず、`export *` の循環した再エクスポートも扱える。ブラウザモードの `vi.unmock` / `vi.doUnmock` は Playwright のルートを正しく削除する（いずれも未リリース）。v5.0.5 では、`isolate: false` で各ファイルの終わりにモッカーをリセットし、終わったファイルのモックファクトリーを解放する。Node 26.12 でモックしたモジュールの読み込みエラーから import の位置が失われる問題は、`wrapDynamicImport` が位置を記録して補うことで直った。v4 系にも手動モック・リダイレクトのモックの堅牢化がバックポートされた（v4.1.12）。モックファクトリーの実行中に始まった並行する import は完了を待って同じモックを受け取り、元のモジュールを受け取るのはファクトリーの中からの import だけになった（`AsyncLocalStorage` で判定。未リリース）。v5.1.0-beta.1（プレリリース）では、`vi.setSystemTime()` が `Temporal.Instant`・`Temporal.ZonedDateTime` を受け付け、`vi.useFakeTimers({ fakeNodeBuiltins: true })` で `node:timers`・`node:timers/promises`（名前付き import を含む）もフェイクにできるようになった。ブラウザモードの `vi.mock` は import map のルールで実現される。その後（未リリース）、評価中のモジュールが後からファクトリーを待ち始める循環も検出し、ファクトリーに部分的な export を渡すようになった（互いに待ってタイムアウトしない）。`spy: true` と automock は元のプロトタイプチェーンを変えなくなり（ジェネレーター・`Object.create` で作ったプロトタイプ・`Symbol.toStringTag` を持つクラス）、`vi.mock` に渡したパッケージ名がワークスペースのパッケージのように `node_modules` の外に解決されても、まず `<root>/__mocks__` を探すようになった（`deps.moduleDirectories` の設定は不要。いずれも未リリース）。fs モジュールキャッシュのキーに deps optimizer の `cacheDir`・`browserHash` が含まれるようになり、optimizer のメタデータが変わったときに `vi.mock` が黙って効かず同じ依存が 2 回読み込まれる問題（#11773）が直った（未リリース）。

## 主な API・オプション

- `vi.useFakeTimers({ fakeNodeBuiltins: true })` — `node:timers`・`node:timers/promises` もフェイクにする
- `vi.setSystemTime(Temporal.Instant | Temporal.ZonedDateTime)` — Temporal の値でシステム時刻を設定

## 概要

実行するテストを絞り込む仕組み（`--changed` / `--related` によるソース・git の変更での絞り込み、位置指定フィルタ）。`--changed` で実行すると、影響を受けたテストの数と総数が表示されるようになった（experimental）。`--changed` での git のエラーや不正な位置指定フィルタは、黙って無視・成功扱いにせず、エラーを表示して終了コード 1 で終わる。`--changed` の影響範囲には、テストファイルの import グラフに加えて、セットアップファイル・グローバルセットアップ・カスタムランナー／環境・設定ファイルの依存・`@vitest-environment` コメント・`__mocks__` のファイルも含まれ、モックに置き換えられたモジュールは除外される。ソースでの絞り込みも transform service 経由でモジュールを変換するため、`fsModuleCache` を使える。新しい `experimental.recordDependencies` を有効にすると、`--changed` / `related` はモジュールグラフを静的に解析する代わりに、前回実行したファイルの依存関係のキャッシュと比べて実行するテストを決める。実行するテストが無いときは変換フェーズを省けるため、規模によっては大幅に速い（未リリース）。

## 主な API・オプション

- `--changed` — git の変更に関係するテストだけを実行（影響を受けたテスト数と総数を表示）
- `--related` — 指定したソースに関係するテストだけを実行

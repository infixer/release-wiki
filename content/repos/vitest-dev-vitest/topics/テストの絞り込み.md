## 概要

実行するテストを絞り込む仕組み（`--changed` / `--related` によるソース・git の変更での絞り込み、位置指定フィルタ）。`--changed` で実行すると、影響を受けたテストの数と総数が表示されるようになった（experimental）。`--changed` での git のエラーや不正な位置指定フィルタは、黙って無視・成功扱いにせず、エラーを表示して終了コード 1 で終わる。ソースでの絞り込みも transform service 経由でモジュールを変換するため、`fsModuleCache` を使える。

## 主な API・オプション

- `--changed` — git の変更に関係するテストだけを実行（影響を受けたテスト数と総数を表示）
- `--related` — 指定したソースに関係するテストだけを実行

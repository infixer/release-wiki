## 概要

選択肢を入力で絞り込む UI の提案。`<select>` の決まった選択肢から絞り込んで選ぶ **filterable select** と、
任意の入力も受け付ける `<input>` + `<datalist>` の **combobox** は、別々の explainer に分かれている。
現時点では filterable select を優先して進めている。combobox の explainer は、`<input>` と `<datalist>` のフィルタリングとキーボード・フォーカス操作を扱う。

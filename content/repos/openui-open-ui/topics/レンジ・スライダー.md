## 概要

`<input type="range">` のスタイル指定と、複数のつまみを持つレンジを扱う提案（Enhanced Range Input）。
複数のつまみは、1 つ以上の `<input type="range">` を共通のトラックにまとめる新しい `<rangegroup>` 要素で実現する（つまみ 1 つでも有効。非対応ブラウザでは中の range がそのまま表示される）。
疑似要素は CSS Forms Level 1 の `::slider-track` / `::slider-fill` / `::slider-thumb` に揃え、つまみ間の区間や目盛りを独自に追加している。
CSSWG が決めた `::slider-fill-under` / `::slider-fill-over` とは、つまみ 1 つのとき `::slider-segment(1)` / `(2)` に当たる。

## 主な API・オプション

- `<rangegroup>` — 複数の `<input type="range">` を 1 つのスライダーとして表示する
- `::slider-track` / `::slider-fill` / `::slider-thumb` — CSS Forms Level 1 の疑似要素
- `::slider-segment(n)` — つまみの間の区間（この explainer の追加）
- `::slider-thumb(n)` / `::slider-thumb(*)` — 番号・全部のつまみ（#1449 で提案）
- `::slider-tick` / `::slider-tick-label` — `<datalist>` と組み合わせた目盛りとラベル

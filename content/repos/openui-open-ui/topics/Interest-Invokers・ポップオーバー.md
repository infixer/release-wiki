## 概要

ホバーやフォーカスなど「関心を示した」ときにポップオーバーを開く Interest Invokers と、関連する `popover=hint` の提案。
Interest Invokers は Open UI での設計議論を終えて「卒業した提案」になり、今後の議論・issue は WHATWG で扱う（WHATWG では引き続き作業中）。
explainer には MDN の解説ページへのリンクがある。

## 変更履歴

- 2026-08-13 — Interest Invokers を「Graduated Proposals」に移し、`popover=hint` の explainer から WHATWG の PR リンクを外した（[#1502](https://github.com/openui/open-ui/pull/1502)）⏳ 未リリース · [[repos/openui-open-ui/changes/2026-10-01|変更]]

## 概要

`<input>` / `<textarea>` の中の文字列に範囲を張り、位置の取得やハイライトをできるようにする提案（Richer Text Fields）。
範囲の部分は Microsoft が提案した `OpaqueRange` に切り出された。`createValueRange(start, end)` で得る live な範囲で、内部ノードはスクリプトに公開されず、フィールドの外にはまたがれない。
`AbstractRange` を継承するので、CSS Custom Highlight API にそのまま渡せる。
仕様 PR（whatwg/dom・whatwg/html・csswg-drafts）は未マージ、WPT は tentative。Mozilla・WebKit は賛成で、Chromium は 152 から既定で有効。

## 主な API・オプション

- `HTMLInputElement.createValueRange(start, end)` / `HTMLTextAreaElement.createValueRange(start, end)` — `OpaqueRange` を返す
- `OpaqueRange.getClientRects()` / `getBoundingClientRect()` / `disconnect()`

[GitHub](https://github.com/openui/open-ui) · ブランチ: `main` · [サイト](https://open-ui.org/)

W3C Open UI Community Group のリポジトリ。フォーム部品やポップオーバーなどの UI コンポーネントについて、調査と提案（explainer）をまとめ、WHATWG・CSSWG での標準化につなげている。

## 最新リリース

- 安定版: なし
- プレリリース: なし

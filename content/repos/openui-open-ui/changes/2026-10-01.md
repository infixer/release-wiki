## 新機能

### オーバースクロールに `show-overscroll` / `hide-overscroll` コマンドを追加（[#1507](https://github.com/openui/open-ui/pull/1507)）

> [!tip] 何ができるようになったか
> Overscroll Actions の explainer で、オーバースクロール領域を操作する invoker のコマンドが `toggle-overscroll` の 1 つから 3 つになった。
>
> - **使い方**: `<button commandfor="menu" command="show-overscroll">`（開く）・`hide-overscroll`（閉じる）・`toggle-overscroll`（切り替え）
> - **ポイント**: オーバースクロール構造として認識されるには `show-overscroll` か `toggle-overscroll` の invoker が必要（`hide-overscroll` は不要。`::overscroll-backdrop` が閉じる役を兼ねる）
> - **inert の扱い**: `toggle-overscroll` の invoker は領域の開閉で inert にならないので、閉じた領域からはみ出させたトグルボタンにできる。`show-`/`hide-` は通常どおり inert の対象

⏳ 未リリース · トピック: [[repos/openui-open-ui/topics/オーバースクロール|オーバースクロール]]

### レンジに関数型の疑似要素と重なったつまみの操作ルールを追加（[#1449](https://github.com/openui/open-ui/pull/1449)）

> [!tip] 何ができるようになったか
> Enhanced Range Input の explainer で、複数のつまみを持つ `<rangegroup>` 向けに、つまみ・区間を番号で選ぶ疑似要素を提案した。
>
> - **疑似要素**: `::slider-thumb(n)` / `::slider-thumb(*)`（n 番目・全部のつまみ）、`::slider-segment(n)`（つまみの間の区間）、`::slider-tick(*)`・`::slider-tick-label`（`<datalist>` と組み合わせた目盛り）
> - **重なったつまみ**: 同じ位置に重なったつまみは、押した直後には動かさず、一定距離動かした向きで動かすつまみを決める（小さい値の方向なら左端、大きい値の方向なら右端のつまみ）
> - 作者・最終更新日と目次も追加

⏳ 未リリース · トピック: [[repos/openui-open-ui/topics/レンジ・スライダー|レンジ・スライダー]]

### switch 属性の explainer からスタイル指定の API を外す（[#1498](https://github.com/openui/open-ui/pull/1498)）

> [!quote] Before
> `<input type="checkbox" switch>` の explainer は、`::slider-track` / `::slider-thumb` 疑似要素によるカスタマイズや UA スタイルシートのアニメーション例を含んでいた。

> [!success] After
> 当初の範囲は `appearance: auto`（ブラウザ標準の見た目）だけにし、内部パーツのスタイル指定は `appearance: base` とフォーム部品の疑似要素の議論（CSSWG）に委ねた。
> 例のマークアップのアクセシビリティを修正し、`change` イベントの表で `cancelable` を `false` に直した。

⏳ 未リリース · トピック: [[repos/openui-open-ui/topics/スイッチ|スイッチ]]

### filterable select と combobox の explainer を分割（[#1501](https://github.com/openui/open-ui/pull/1501)）

> [!quote] Before
> 1 つの explainer で、`<input>` + `<datalist>` の combobox と、`<select>` の選択肢を絞り込む filterable select の両方を扱っていて分かりにくかった。

> [!success] After
> filterable select を新しい explainer（`filterable-select.explainer.mdx`）に分けて書き直した。combobox の explainer は `<input>` と `<datalist>` のフィルタリングとキーボード・フォーカス操作に絞った。
> 現時点では combobox より filterable select を優先して進めている。

> [!quote] Before

### switch 要素の explainer を switch 属性の採用に合わせて更新（[#1376](https://github.com/openui/open-ui/pull/1376)）

> [!quote] Before
> 新しい `<switch>` 要素を提案する explainer で、WHATWG の switch 属性は代替案の扱いだった。

> [!success] After
> Open UI が switch 属性（`<input type="checkbox" switch>`）の支持を決めた（#1282）ことを受け、非アクティブな提案に移した。理由（非対応ブラウザではチェックボックスになる、Safari が実装済み、調べた例の多くが属性で足りる）と、44 のデザインシステムの分析結果、チェックボックス・ラジオ・トグルボタンとの違いを追記した。今後は保守しない。

⏳ 未リリース · トピック: [[repos/openui-open-ui/topics/スイッチ|スイッチ]]

### rangegroup の explainer を CSS Forms Level 1 に合わせて整理（[#1513](https://github.com/openui/open-ui/pull/1513)）

> [!quote] Before
> CSS Forms Level 1 にある疑似要素と、この explainer 独自の追加が混ざって書かれていた。つまみが 1 つの `<rangegroup>` の扱いも決まっていなかった。

> [!success] After
> `::slider-track` / `::slider-fill` / `::slider-thumb` は CSS Forms Level 1、`::slider-segment` / `::slider-tick` / `::slider-tick-label` はこの explainer の追加だと区別した。
> CSSWG が 2026-02-19 に決めた `::slider-fill-under` / `::slider-fill-over` との対応（つまみ 1 つなら `::slider-segment(1)` / `(2)` と同じ、2 つ以上なら `::slider-segment(n)` を使う）を追記した。
> つまみ 1 つの `<rangegroup>` も有効とし、interaction mode の説明も加えた。

## 新機能

### シリアライズと転送を同じ agent cluster に制限できるように（[#13055](https://github.com/whatwg/html/pull/13055)）

> [!tip] 何ができるようになったか
> シリアライズ・転送の手順で、結果を同じ agent cluster の中だけに制限できるようになった。`VideoFrame` や `MediaSourceHandle` のように agent cluster の外に出せないオブジェクトを、仕様で正しく表せる。
>
> - **使い方**: インターフェースに `[SameAgentCluster]` 拡張属性を付けると、そのインターフェースを実装するすべてのオブジェクトが同じ agent cluster に制限される
> - **挙動**: 別の agent cluster で `StructuredDeserialize`・`StructuredDeserializeWithTransfer` すると例外を投げる（`SharedArrayBuffer` もこの仕組みを使うようになった）。`StructuredDeserializeWithTransfer` は、転送を受け取る手順を実行する前にこのチェックと、シリアライズ・転送されたインターフェースがすべて公開されているかのチェックを行う。こうしたオブジェクトをストレージ向けにシリアライズすると例外を投げる
> - **嬉しい場面**: これまでは `[Exposed=(Window,DedicatedWorker)]` で近似していたが、別の agent cluster の `Window` 同士も通信でき、shared worker が作った dedicated worker は shared worker の agent cluster に入るため不正確だった。Web Codecs（[w3c/webcodecs#717](https://github.com/w3c/webcodecs/issues/717)）や、おそらく OffscreenCanvas で使われる見込み

## 新機能

### フラグメントパーサーのオプションを Trusted Types と統合（[#12583](https://github.com/whatwg/html/pull/12583)）

> [!tip] 何ができるようになったか
> Trusted Types の `createHTML` を呼んでいた箇所で、`createParserOptions` があればそれも呼ぶようにした（「get trusted type compliant string」の代わりに「get trusted type compliant input」を使う）。これにより default policy が、従来のマークアップ挿入（`innerHTML`・`outerHTML`・`insertAdjacentHTML()`・`createContextualFragment()`）にサニタイザーを与えたりスクリプト実行の挙動を変えたりでき、`setHTMLUnsafe()`・`parseHTMLUnsafe()` のサニタイザーやスクリプトの挙動も変えられる。
>
> - **対象外**: `srcdoc`・`document.write()`・`DOMParser.parseFromString()`・`execCommand` の `insertHTML`（`createParserOptions` でサニタイズすべきかは別途決める）
> - **仕様の構造**: 「set and filter HTML」/「fragment parsing algorithm steps」の safe フラグと scriptingMode 引数を、fragment parser mode の列挙（Safe: `setHTML()`・`parseHTML()` / Unsafe: `setHTMLUnsafe()`・`parseHTMLUnsafe()` / Legacy: `innerHTML` など）に置き換えた。Safe と Unsafe は常に HTML パーサーを使い宣言的 Shadow Root を許可し、Legacy は従来どおり（XML 文書では XML パーサー、宣言的 Shadow Root なし）

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/サニタイザー|サニタイザー]]

### worklet に cross-origin isolated capability と time origin を公開（[#13006](https://github.com/whatwg/html/pull/13006)）

> [!tip] 何ができるようになったか
> 「set up a worklet environment settings object」で、cross-origin isolated capability と time origin を `outsideSettings` の値から返すようにした。これまで前者は worklet を HTML に移したとき（#6056）から `TODO` のまま、後者は「呼ばれることはない」と assert されていた（#7339）。
>
> - **嬉しい場面**: Web Audio API の `AudioWorkletGlobalScope` で `performance.now()` を公開する提案（[w3c/hr-time#169](https://github.com/w3c/hr-time/pull/169)）を支えるもので、他のコンテキストと同じ精度の丸め（coarsening）になる
> - **実装の状況**: Chromium と Gecko が関心を示している

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/ワークレット|ワークレット]]

## 変更・修正

### `HTMLScriptElement` の Trusted Types 向け IDL を HTML 本体に取り込む（[#12195](https://github.com/whatwg/html/pull/12195)）

> [!quote] Before
> `HTMLScriptElement` の IDL 属性と getter・setter の手順は、Trusted Types の仕様が外から書き換える（monkey patch）形で定義されていた。

> [!success] After
> HTML 本体に取り込んだ。`HTMLScriptElement` は `innerText` と `textContent` を shadow して `TrustedScript` を受け取り、`src` は `TrustedScriptURL`、`text` は `TrustedScript` を受け取る。挙動の変更はない（Chromium・WebKit・Firefox は実装済み）。あわせて `text` の setter と `src` の getter にあった仕様上の誤りを直した。[w3c/trusted-types#607](https://github.com/w3c/trusted-types/pull/607) に依存する。

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/script要素|script要素]]

### 削除された・別の文書に移された popover が隠れない問題を修正（[#13001](https://github.com/whatwg/html/pull/13001)）

> [!quote] Before
> 要素を取り除くときの手順は hide popover アルゴリズムを実行するが、その最初の popover の妥当性チェックが「要素が接続されていない」ことで例外を投げるため、popover が表示されたまま top layer に残っていた。node document が fully active でない場合も同じだった。

> [!success] After
> 妥当性チェックで接続済み・fully active を要求するのは、表示しようとするときだけにした（#9161 を修正。#9457 と whatwg/dom#1185 を置き換え）。hide popover は `beforetoggle` の発火後などに文書を渡してチェックし、close watcher は hide の完了時にだけ破棄する。fully active でない文書で表示中の popover に `hidePopover()` を呼ぶと隠れるようになった。

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/popover|popover]]

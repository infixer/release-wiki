## 変更・修正

### 複製した Document のベース URL を考慮するように（[#12674](https://github.com/whatwg/html/pull/12674)）

> [!quote] Before
> DOM の `baseURI` が使う Document の「get the base URL」アルゴリズムが HTML 側で定義されておらず、複製（clone）された文書のベース URL の扱いが定まっていなかった（[whatwg/dom#454](https://github.com/whatwg/dom/issues/454)）。また、iframe の srcdoc 文書の中で `DOMParser` が作った Document で、fallback base URL のアサーションに引っかかることがあった。

> [!success] After
> 「get the base URL」は document base URL を返すと定義した。document base URL は DOM が複製時に設定する base URL override を考慮するため、`base` 要素を持たない複製は複製元の文書のベース URL を返す。複製時には Document の about base URL もコピーされ、複製内の `base` 要素が元の文書と同じように解決される。fallback base URL のアサーションは削除した。

Chromium と WebKit が関心を示している。テストは [wpt#61231](https://github.com/web-platform-tests/wpt/pull/61231)・[wpt#61232](https://github.com/web-platform-tests/wpt/pull/61232)。

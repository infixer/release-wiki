## 変更・修正

### `img` の寸法を同期的に決めるように（`picture` の `source` の `width`・`height`）（[#13057](https://github.com/whatwg/html/pull/13057)）

> [!quote] Before
> 仕様では、`img` 要素の dimension attribute source（寸法の属性をどの要素から取るか）は画像のソースを選ぶとき（microtask の中）にしか更新されなかった。一方ブラウザは、`picture` 要素の中で一致した `source` 要素の `width`・`height` 属性を DOM の変更時点ですぐに `img` に適用し、計算済みスタイルにも即座に反映していた（#8207）。

> [!success] After
> 「update the image data」は、早期 return の前に同期的にソースセットを更新する。「update the source set」は `source` 要素を見る前に dimension attribute source を `img` 要素に戻すので、`source` 要素を削除したり `img` を `picture` の外に移したりすると元に戻る。画像を on demand で取得する場合も、relevant mutation でソースセットを更新する。画像の URL の選択は、error イベントが早すぎるタイミングで発火しうるため microtask のまま。全ブラウザの既存の挙動に合わせた変更で、WPT のテストがある。

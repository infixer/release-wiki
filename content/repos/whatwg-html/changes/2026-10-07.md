## 新機能

### サニタイズのアルゴリズムで MathML の `<a>` を扱うように（[#12592](https://github.com/whatwg/html/pull/12592)）

> [!tip] 何ができるようになったか
> サニタイズの安全な既定の設定（safe default configuration）に、MathML の `a` 要素と `href`・`hreflang`・`type` 属性を追加した。SVG と HTML の `a` 要素の扱いに合わせたもの。
>
> - **実装の状況**: Gecko と WebKit が関心を示しており、Chromium・Gecko・WebKit に実装バグが登録されている。テストは Chromium のレビュー（8212842）

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/サニタイザー|サニタイザー]]

## 変更・修正

### classic 以外の script の `type` から空白を取り除かない（[#13031](https://github.com/whatwg/html/pull/13031)）

> [!quote] Before
> `script` 要素の `type` 属性の値から空白を取り除いてから判定していたため、たとえば `type=" module "` もモジュールスクリプトとして扱われうる書き方になっていた（#13012。36470c1 の follow-up）。

> [!success] After
> WebKit・Chromium と同じく、先頭と末尾の ASCII 空白を取り除くのは JavaScript MIME type の判定のときだけにした。`type=" module "` はモジュールスクリプトにならない。テストは [wpt#63237](https://github.com/web-platform-tests/wpt/pull/63237)、Gecko に実装バグ（Bug 2077692）が登録された。

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/script要素|script要素]]

### COOP・COEP のヘッダーに structured field の型を要求（[#13032](https://github.com/whatwg/html/pull/13032)）

> [!quote] Before
> `Cross-Origin-Opener-Policy`・`Cross-Origin-Embedder-Policy`（とその Report-Only 版）のヘッダーの値と `report-to` パラメータの型が定められていなかった。

> [!success] After
> ヘッダーの値は token、`report-to` パラメータは string でなければならないとした。エンドポイント名は token で、`Permissions-Policy` などは `report-to` に token を使うため string は意外だが、Chromium と WebKit の実装に合わせた。テストは [wpt#63239](https://github.com/web-platform-tests/wpt/pull/63239)。

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/COOP-COEP|COOP-COEP]]

### `img` の relevant mutation から `width` を外す（[#13033](https://github.com/whatwg/html/pull/13033)）

> [!quote] Before
> `img` 要素の `width` 属性の変更が relevant mutation（画像を読み直すきっかけになる変更）に含まれていた。これを実装したエンジン（Servo）では、いくつかのテストが不安定になったり誤って通ったりしていた。

> [!success] After
> `width` を relevant mutation から外した（#9371 を修正）。Chromium・Gecko・WebKit はすでにこの挙動。全エンジンがテストに通るようにするためのテストの更新は [wpt#63308](https://github.com/web-platform-tests/wpt/pull/63308)。

## 変更・修正

### 「fire a focus event」の対象として Window を許可（[#12875](https://github.com/whatwg/html/pull/12875)）

> [!quote] Before
> 「fire a focus event」はイベントの対象として要素のみを受け取る定義になっていたが、フォーカス更新の手順ではエントリが `Document` の場合に `Window` オブジェクトを渡しており、`Window` には `view` 属性の値を取得するための node document が無く不整合だった。

> [!success] After
> 「fire a focus event」の対象として `Window` も受け取れるように定義を修正した。

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/フォーカス|フォーカス]]

### XML 宣言からのエンコーディング検出範囲を宣言内に限定（[#12967](https://github.com/whatwg/html/pull/12967)）

> [!quote] Before
> `text/html` として解釈する文書で XML 宣言をスニッフィングする際、宣言中の最初の `>` バイトまでしか見ておらず、宣言より後ろのテキストが文書のエンコーディング判定に影響してしまうことがあった。

> [!success] After
> エンコーディングを探す範囲を XML 宣言そのものに限定し、Chromium・Gecko・WebKit の実装と一致するようにした。

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/エンコーディング判定|エンコーディング判定]]

### frame の子ナビゲーブル作成タイミングを iframe に合わせた（[#12925](https://github.com/whatwg/html/pull/12925)）

> [!quote] Before
> `frame` 要素の子ナビゲーブルは、本来ブラウジングコンテキストの作成やイベント発火を行ってはいけない挿入手順（insertion steps）の中で作成されていた。また shadow tree 内で接続された `frame` は `iframe` と異なり子ナビゲーブルを作成できなかった。

> [!success] After
> 子ナビゲーブルの作成を接続後手順（post-connection steps）に移し、ブラウジングコンテキストの有無は node document を使って判定するようにした。これにより shadow tree 内に接続された `frame` も `iframe` と同様に子ナビゲーブルを作成できるようになり、タイミングも Chromium・WebKit と一致する（Firefox は現状、挿入前に frame と iframe 両方のウィンドウを作成している）。

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/フレームとナビゲーブル|フレームとナビゲーブル]]

### Trusted Types で書き換えられた javascript: URL を評価（[#12959](https://github.com/whatwg/html/pull/12959)）

> [!quote] Before
> javascript: URL ナビゲーションの仕様では、Trusted Types のデフォルトポリシーによって URL が書き換えられた場合の扱いが明確でなかった。

> [!success] After
> Trusted Types によって書き換えられた（rewritten）javascript: URL を評価するよう仕様を修正した。Chromium・Gecko・WebKit はすでにこの挙動を実装している。

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/javascript-URL|javascript-URL]]

### javascript: URL ナビゲーションの追加修正（[#12978](https://github.com/whatwg/html/pull/12978)）

> [!quote] Before
> 先行コミット（javascript: URL ナビゲーション処理の書き換え）に、いくつかの細部が反映されていなかった。

> [!success] After
> 以下を修正した。
> - CSP チェックがリクエストの URL を書き換えうることを明記
> - 合成リクエスト（synthetic request）に client を設定（w3c/trusted-types#548 に準拠）
> - デフォルトポリシーがコンテナを削除した場合は iframe の load イベント手順を実行しないようにした
> - 「evaluate a javascript: URL」に navigation ID を渡すようにした

⏳ 未リリース · トピック: [[repos/whatwg-html/topics/javascript-URL|javascript-URL]]

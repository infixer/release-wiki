## 概要

HTML の動的なマークアップ挿入（`dynamic-markup-insertion`）で定義されるサニタイズのアルゴリズムと、その安全な既定の設定（safe default configuration）に関する仕様。安全な既定の設定には、HTML と SVG の `a` 要素に加えて、MathML の `a` 要素（`href`・`hreflang`・`type` 属性付き）も含まれるようになった。フラグメントの解析は fragment parser mode（Safe: `setHTML()`・`parseHTML()` / Unsafe: `setHTMLUnsafe()`・`parseHTMLUnsafe()` / Legacy: `innerHTML`・`outerHTML`・`insertAdjacentHTML()`・`createContextualFragment()`）で区別され、どのマークアップ挿入でもサニタイザーを使えるようになった。Trusted Types の default policy は `createParserOptions` で、Legacy の挿入にサニタイザーを与えたりスクリプト実行の挙動を変えたりできる（`srcdoc`・`document.write()`・`DOMParser.parseFromString()`・`insertHTML` は対象外）。

## 主な API・オプション

- safe default configuration — サニタイズの安全な既定の設定。MathML の `a`（`href`・`hreflang`・`type`）を含む
- fragment parser mode — Safe / Unsafe / Legacy。Safe・Unsafe は常に HTML パーサーで宣言的 Shadow Root を許可、Legacy は従来どおり
- `createParserOptions`（Trusted Types）— default policy からサニタイザーやスクリプト実行の挙動を指定

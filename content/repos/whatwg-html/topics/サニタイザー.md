## 概要

HTML の動的なマークアップ挿入（`dynamic-markup-insertion`）で定義されるサニタイズのアルゴリズムと、その安全な既定の設定（safe default configuration）に関する仕様。安全な既定の設定には、HTML と SVG の `a` 要素に加えて、MathML の `a` 要素（`href`・`hreflang`・`type` 属性付き）も含まれるようになった。

## 主な API・オプション

- safe default configuration — サニタイズの安全な既定の設定。MathML の `a`（`href`・`hreflang`・`type`）を含む

## 概要

カスタム要素（custom elements）の定義・アップグレードと、カスタム要素レジストリに関する仕様。アップグレードのリアクションがキューに入ってから実行されるまでの間に要素が別の文書に adopt され、要素のカスタム要素レジストリが null になった場合、「upgrade an element」は active custom element constructor map のエントリーを null にせず削除する。HTML 要素のコンストラクターは、現在のグローバルオブジェクトに対応する Document のカスタム要素レジストリにフォールバックする。別のグローバルなカスタム要素レジストリを持つ文書に adopt された場合は、アップグレードは失敗する（未リリース）。

## 主な API・オプション

- 「upgrade an element」 — 要素をカスタム要素にアップグレードするアルゴリズム
- active custom element constructor map — アップグレード中のコンストラクターとレジストリの対応

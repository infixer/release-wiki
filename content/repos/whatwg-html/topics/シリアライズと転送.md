## 概要

serializable / transferable なオブジェクトのシリアライズ・転送（`StructuredSerialize`・`StructuredDeserialize`・`StructuredDeserializeWithTransfer` など）に関する仕様。2026-10-16 の取り込みで、シリアライズ・転送の結果を同じ agent cluster の中だけに制限できるようになった。`[SameAgentCluster]` を付けたインターフェースのオブジェクト（と `SharedArrayBuffer`）は、別の agent cluster でデシリアライズすると例外を投げ、ストレージ向けのシリアライズも例外を投げる。`StructuredDeserializeWithTransfer` は、転送を受け取る手順の前にこのチェックとインターフェースが公開されているかのチェックを行う。

## 主な API・オプション

- `[SameAgentCluster]` — インターフェースを実装するオブジェクトのシリアライズ・転送を同じ agent cluster に制限する拡張属性
- `StructuredDeserialize` / `StructuredDeserializeWithTransfer` — 別の agent cluster では制限されたオブジェクトに対して例外を投げる

## 概要

フォーカスの移動に伴って `focus` イベントを発火する「fire a focus event」手順まわりの仕様。イベントの対象（target）には要素だけでなく、エントリが `Document` のときの `Window` も渡されうる。
「has focus steps」は、対象の文書の node navigable が null（`document.implementation.createHTMLDocument()` で作った文書など）なら、top-level traversable にアクセスする前に false を返す（2026-11-04 に取り込んだ PR、Chromium・Gecko・WebKit の既存の挙動に一致）。

## 主なアルゴリズム

- `fire a focus event` — フォーカスに伴うイベントを発火する処理。対象は要素または `Window`。
- `has focus steps` — node navigable が null なら false を返す

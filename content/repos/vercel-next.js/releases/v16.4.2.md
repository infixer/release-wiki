## 要点

16.4 系（`lts-active`）へのバックポートを集めたパッチリリース。主に Turbopack と turbo-tasks の修正。

- **turbo-tasks**: スナップショットの一貫性の修正（[#99644](https://github.com/vercel/next.js/pull/99644)、[#99732](https://github.com/vercel/next.js/pull/99732)、[#99649](https://github.com/vercel/next.js/pull/99649) → [#100002](https://github.com/vercel/next.js/pull/100002)）。GC で依存の辺が中途半端に壊れたまま残る 2 つの経路を修正（[#100209](https://github.com/vercel/next.js/pull/100209)）
- **Turbopack**: Pages Router の開発時のモジュールグラフの連結をバックポート（[#98823](https://github.com/vercel/next.js/pull/98823)、[#99910](https://github.com/vercel/next.js/pull/99910)、[#100091](https://github.com/vercel/next.js/pull/100091) → [#100008](https://github.com/vercel/next.js/pull/100008)）
- **Turbopack**: モジュール解決で realpath のエラーを Node と同じく無視（[#100217](https://github.com/vercel/next.js/pull/100217)）
- **Turbopack**: 遅延 dynamic import のチャンクリストの衝突を修正（[#100211](https://github.com/vercel/next.js/pull/100211)）
- **next-code-frame**: 表示範囲を文字の境界にそろえる（マルチバイト文字での panic の修正）（[#100212](https://github.com/vercel/next.js/pull/100212)）
- **ドキュメント**: v16.4.0 以降のドキュメントの修正をバックポート（[#100246](https://github.com/vercel/next.js/pull/100246)、[#100262](https://github.com/vercel/next.js/pull/100262)）

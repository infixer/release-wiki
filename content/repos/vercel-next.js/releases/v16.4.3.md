## 要点

16.4 系（`lts-active`）へのバグ修正のバックポートを集めたパッチリリース。canary の新機能・変更はすべては含まない。

- **next/font**: 拡張子の無い Google Fonts の URL を webpack・Turbopack の両方で扱えるように（[#100277](https://github.com/vercel/next.js/pull/100277)）
- **proxy.ts**: `proxy.ts` で app-page のランタイムを読み込まないように（[#100423](https://github.com/vercel/next.js/pull/100423)）
- **Turbopack**: ローダー変更の検知（[#95732](https://github.com/vercel/next.js/pull/95732)）を取り消し（[#100438](https://github.com/vercel/next.js/pull/100438)）
- **OpenTelemetry**: リクエストのトレースを 1 つにまとめる一連の修正をバックポート（[#100349](https://github.com/vercel/next.js/pull/100349)、[#100294](https://github.com/vercel/next.js/pull/100294)、[#100324](https://github.com/vercel/next.js/pull/100324)、[#100350](https://github.com/vercel/next.js/pull/100350)、[#100552](https://github.com/vercel/next.js/pull/100552)、[#100583](https://github.com/vercel/next.js/pull/100583) → [#100542](https://github.com/vercel/next.js/pull/100542)）
- **サーバーの起動**: サーバーの起動時に単体の React を読み込まないように（[#100610](https://github.com/vercel/next.js/pull/100610)）
- **リリースの CD**: リリース bot の認証情報を GitHub の environments の内側に限定（[#100123](https://github.com/vercel/next.js/pull/100123)）、リリースの下書き解除を bot-autonomous の後続ジョブに移動（[#100572](https://github.com/vercel/next.js/pull/100572)）
- **テスト**: `react-virtualized` のバージョンを固定（[#100545](https://github.com/vercel/next.js/pull/100545)）

## 要点

セキュリティ修正のリリース。次のアドバイザリに対応している。

- **High**: 画像最適化（Image Optimization）でのサーバーサイドリクエストフォージェリ（SSRF）（[GHSA-cjq9-62q9-8jv4](https://github.com/vercel/next.js/security/advisories/GHSA-cjq9-62q9-8jv4)）
- **Medium**: App Router のメタデータ画像ルートで `dynamicParams` を迂回した情報漏えい（[GHSA-f87g-xv8r-7p7x](https://github.com/vercel/next.js/security/advisories/GHSA-f87g-xv8r-7p7x)）
- **Medium**: セルフホストの Next.js アプリで SSG・ISR ページのキャッシュポイズニング（[GHSA-4jqv-mc3x-m676](https://github.com/vercel/next.js/security/advisories/GHSA-4jqv-mc3x-m676)）
- **Medium**: SSG/ISR のレンダリングでのキャッシュポイズニングにより、別ユーザーのコンテンツへの差し替えや持続的なサービス拒否が起きる問題（[GHSA-mcj8-r9mp-w47p](https://github.com/vercel/next.js/security/advisories/GHSA-mcj8-r9mp-w47p)）
- **Medium**: 保留中の `use cache` の充填により、Draft Mode のコンテンツが通常のレスポンスや永続化されたページに漏れる問題（[GHSA-3w37-wq28-93x7](https://github.com/vercel/next.js/security/advisories/GHSA-3w37-wq28-93x7)）
- **Medium**: ネストした `'use cache'` 関数で root param の値をまたいでキャッシュが漏れる問題（[GHSA-h694-7cp9-m8p3](https://github.com/vercel/next.js/security/advisories/GHSA-h694-7cp9-m8p3)）
- **Low**: 開発サーバーの Model Context Protocol エンドポイントでの情報漏えい（[GHSA-39w2-rjm5-chcv](https://github.com/vercel/next.js/security/advisories/GHSA-39w2-rjm5-chcv)）

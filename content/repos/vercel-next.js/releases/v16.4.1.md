## 要点

セキュリティ修正のリリース。次のアドバイザリに対応している。

- **Critical**: `use cache` 関数が型付き配列（typed array）を返す場合の、認証不要のリモートコード実行（[GHSA-673q-mjm6-r5xr](https://github.com/vercel/next.js/security/advisories/GHSA-673q-mjm6-r5xr)）
- **Critical**: SVG ファイルを使う場合の画像最適化 API での、認証不要のリモートコード実行（[GHSA-2464-fhr4-w9xw](https://github.com/vercel/next.js/security/advisories/GHSA-2464-fhr4-w9xw)）
- **High**: Server Actions を使う App Router でのサービス拒否（DoS）（[GHSA-p3m5-59mp-jv5r](https://github.com/vercel/next.js/security/advisories/GHSA-p3m5-59mp-jv5r)）

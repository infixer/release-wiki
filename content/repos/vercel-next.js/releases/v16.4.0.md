## 要点

Next.js 16.4 の安定版。変更の概要は [16.4 の告知記事](https://nextjs.org/blog/next-16-4) を参照するよう案内されている。Release 本文の Core Changes・Misc Changes から主なものを挙げる（本文は途中までしか取り込めていない）。

- **Turbopack**: `resolveAlias` の設定で `false` を指定できるように（[#93331](https://github.com/vercel/next.js/pull/93331)）。CSS の先頭の BOM を取り除いてからパース（[#96678](https://github.com/vercel/next.js/pull/96678)）、失敗したプラグインのワーカースレッドを終了（[#96592](https://github.com/vercel/next.js/pull/96592)）
- **バンドルアナライザー**: analyze を実行するたびに履歴のスナップショットを記録（[#93520](https://github.com/vercel/next.js/pull/93520)）
- **proxy**: 複合的な `pageExtensions` でも `proxy.ts` を正しく検出（[#93246](https://github.com/vercel/next.js/pull/93246)）
- **ナビゲーション**: 動的なナビゲーションの後もセグメント単位のプリフェッチを保持（[#96583](https://github.com/vercel/next.js/pull/96583)）、ハイドレーション前に「戻る」したときの競合を修正（[#96252](https://github.com/vercel/next.js/pull/96252)）
- **キャッシュ**: 完了したキャッシュエントリをリクエストの残りで再利用（[#96727](https://github.com/vercel/next.js/pull/96727)）、フォアグラウンドのキャッシュ再検証を利用側から導出（[#96731](https://github.com/vercel/next.js/pull/96731)）
- **プリレンダリング**: HTML を制限するボットの判定をプリレンダーのバイパス規則で修正（[#96584](https://github.com/vercel/next.js/pull/96584)）。App Page・App Route のレンダリングとプリレンダリングのパイプラインを分離（[#96659](https://github.com/vercel/next.js/pull/96659), [#96662](https://github.com/vercel/next.js/pull/96662)）
- **create-next-app**: Tailwind の Turbopack ローダーを使用（[#96606](https://github.com/vercel/next.js/pull/96606)）
- **ドキュメント**: ランタイムプリフェッチの experimental の注記を削除（[#96615](https://github.com/vercel/next.js/pull/96615)）、AI エージェント向けガイドの Skill を手順として説明（[#96751](https://github.com/vercel/next.js/pull/96751)）

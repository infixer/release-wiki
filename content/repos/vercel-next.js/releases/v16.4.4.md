## 要点

16.4 系（`lts-active`）へのバグ修正のバックポートを集めたパッチリリース。canary の新機能・変更はすべては含まない。Release の本文では、11 月のセキュリティリリースが翌日に公開されると予告されていた（→ [[repos/vercel-next.js/releases/v16.4.5|v16.4.5]]）。

- **Turbopack**: 起動時の CSS の更新を取りこぼしたときにリロードする（#100619）
- **Turbopack**: 「Optimize strict module factory chunks（#98421）」を取り消し（#100866）
- **Turbopack / CSP**: PPR の resume で Turbopack の共有ランタイムのブートストラップを出力し、CSP の nonce が付くように（#100907）
- **アナライザー**: ルートのサマリーをアナライザーのルートの索引として使う（#100974）
- **依存関係**: `jsonwebtoken` の代わりに `fast-jwt` を使う（#100885）
- **テスト・CI**: `reads fallback params after a client navigation` のデプロイテストを無効化（#100668）、デプロイテストを Node.js 22.x に固定（#100886）

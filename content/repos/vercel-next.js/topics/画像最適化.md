## 概要

`next/image`（Image コンポーネント・`getImageProps`）と、サーバー側の画像最適化（image optimizer）の実装。外部画像を取得するときは DNS 解決の結果を固定するようになった。Vercel アダプターのデプロイで不変（immutable）な設定を扱えるように、画像のオプションを設定を書き換えずに一度だけ用意して使い回す変更が入っている。安定版 v16.3.8 では、画像最適化での SSRF（High）のセキュリティ修正が公開された。画像最適化の変換処理は公開のサブパス `next/image-optimizer-transform` から import でき、場所とエクスポートが安定した契約になった（`next/dist/server/image-optimizer/*` への依存が不要に）。Turbopack の画像処理では webp が wasm 版も含めて常に有効（いずれも v16.5.0-canary.8）。`next/image` の非推奨の props（`priority` など）は、エディターで `@deprecated` として表示されるようになった。Turbopack の画像処理は AVIF の幅・高さを正しく取得するようになった（最適化・エンコードはまだ行わない）（いずれも v16.5.0-canary.10）。安定版 v16.4.1 / v15.5.28 では、SVG ファイルを使う場合の画像最適化 API でのリモートコード実行（Critical）のセキュリティ修正が公開された。

## 主な API・オプション

- `images.qualities` — 許可する画質。開発時の blur 用の品質はこの配列に追加せず、検証時に直接許可される
- `getImageProps` — 固定のオプションをモジュール初期化時に一度だけ用意する
- `next/image-optimizer-transform` — 画像最適化の変換処理の公開サブパス（`imageOptimizerTransform`・`optimizeImage`・`getSharp`・`getMaxAge`・`ImageError`）
- `priority`・`onLoadingComplete`・`layout`・`objectFit`・`objectPosition`・`lazyBoundary`・`lazyRoot`（`next/image`）— 非推奨の props。`priority` の代わりは `preload`

## 概要

Next.js の CLI が送る匿名テレメトリの送信処理（`packages/next/src/telemetry/`）。送信には Node.js のネイティブ `fetch` を使い、タイムアウトはネイティブの `AbortController` で実装している。以前は Edge Runtime の ponyfill の `AbortController` を使っていたため、Node.js 24 では送信前にエラーになり、エラーが抑えられたままイベントが届いていなかった。送信は 1 回だけ再試行し、最後のエラーは表示しない。

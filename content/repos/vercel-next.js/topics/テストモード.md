## 概要

Next.js の実験的なテストモード（experimental test mode）の実装。テストモードは `@mswjs/interceptors` を同梱して使っており（MSW が使う interceptor の依存とは別）、v16.5.0-canary.24 で 0.42.6 から 0.45.9 に更新された。0.42.6 では、HTTPS の keep-alive ソケットが `Content-Length` 付きのモックのレスポンスを 2 回受け取った後に実際のソケットへのパススルーに切り替わると、Node が `SIGSEGV` でクラッシュすることがあった（16.3.0-canary.98 の [#96059](https://github.com/vercel/next.js/pull/96059) で入った依存）。v16.5.0-canary.29 では、`experimental.testProxy` 使用時に圧縮された HTTP レスポンスが壊れる問題が修正された。テストのコンテキスト外のリクエストとプロキシの `continue` はネイティブの HTTP パススルーで元のバイトとヘッダーを保ち、fetch したレスポンスの古い `Content-Encoding` / `Content-Length` は正規化される（明示的に作ったモックはそのまま）。

期間: 2026-11-04 〜 2026-11-06 · PR 46 件（新機能 2 / 変更・修正 28 / その他 16）· Release 0 件

この期間は、oxlint の型認識 lint が新しいバックエンド `tsrs-lint` を探して優先的に使うようになったこと、`no-redeclare` の `ignoreDeclarationMerge` オプションの追加が新機能。修正では、Oxfmt の `sortTailwindcss` で整形が 1 回で安定しない（非冪等な）問題の連続した修正、ES2022 クラス変換のプライベートフィールド・メソッド・アクセサーへの代入の修正、codegen の `Infinity` の出力とソースマップの重複マッピングの修正、多数の lint ルールの修正が入った。すべて未リリース。

## 新機能

### oxlint: 型認識 lint で `tsrs-lint` を探して使う（[#28751](https://github.com/oxc-project/oxc/pull/28751)）

> [!tip] 何ができるようになったか
> oxc-project/tsrs#857 で導入された `tsrs-lint` ランチャーを、`node_modules/.bin`・`PATH`・ディレクトリの上書き指定から探して優先的に使うようになった。見つからなければ `tsgolint` にフォールバックする。実行ファイルのパスを明示した場合はそれが優先される。Go のプロファイリングのオプションを使うときは、`tsrs-lint` がそのフラグに対応していないため引き続き `tsgolint` を選ぶ。互換な実行ファイルが見つからないときは、必要なパッケージを報告する。
>
> - **使い方**: 型認識 lint の実行時に自動で探索（`crates/oxc_linter/src/tsgolint.rs`）
> - **嬉しい場面**: `tsrs-lint` を入れたプロジェクトで型認識 lint を動かしたいとき（PR 本文によれば、実際の tsrs と Windows での実行は未検証）

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/型認識Lint|型認識Lint]]

### linter: `eslint/no-redeclare` に `ignoreDeclarationMerge` オプション（[#28816](https://github.com/oxc-project/oxc/pull/28816)）

> [!tip] 何ができるようになったか
> typescript-eslint の `no-redeclare` にある `ignoreDeclarationMerge` オプションを追加した。有効なとき（既定で `true`）は、宣言のマージ（interface と interface、class と interface、interface と namespace など）を再宣言として報告しない。設定スキーマ（`configuration_schema.json`）と `config.generated.ts` にも追加された。
>
> - **使い方**: `"no-redeclare": ["error", { "ignoreDeclarationMerge": true }]`
> - **嬉しい場面**: TypeScript の宣言のマージを使うコードで誤検知を避けたいとき（#28782）

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/Linterルール個別修正|Linterルール個別修正]]

## 変更・修正

### transformer: 静的プライベートフィールドへの複合代入を 1 回だけ適用（[#28606](https://github.com/oxc-project/oxc/pull/28606)）

> [!quote] Before
> ターゲットが `es2021` 以下のとき、`this.#count += k` のように左辺がクラス名でない静的プライベートフィールドへの複合代入で、`+=` を残したまま右辺にも古い値を足していたため、演算子が 2 回適用されていた（`11` になるはずが `21`）。

> [!success] After
> この分岐でも演算子を `=` にし、`_count._ = ...(_count)._ + k` の形に変換する。

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/ES2022クラス変換|ES2022クラス変換]]

### transformer: 代入・更新でプライベートメソッドの値を保つ（[#28788](https://github.com/oxc-project/oxc/pull/28788)）

> [!quote] Before
> プライベートメソッドへの複合代入・更新（`this.#method ||= rhs()` など）で、値を読むときにメソッド本体を呼び出していた。メソッドが `undefined` を返すと `rhs()` を評価し、メソッドの関数を返す代わりに例外を投げていた。

> [!success] After
> メソッドの読み取りとアクセサーのゲッター呼び出しを区別し、メソッドの読み取りはブランドチェックを通して関数そのものを返す。

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/ES2022クラス変換|ES2022クラス変換]]

### transformer: プライベートアクセサーへの論理代入でレシーバーを保つ（[#28790](https://github.com/oxc-project/oxc/pull/28790)）

> [!quote] Before
> ES2021 以下がターゲットのとき、`receiver.#value &&= rhs()` でゲッターとセッターがそれぞれ `receiver` を読んでいたため、ゲッターが左辺の変数を書き換えると、セッターの準備で `TypeError` になっていた。

> [!success] After
> レシーバーを一時変数（`_receiver = receiver`）に保存し、ゲッターとセッターで同じものを使う。

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/ES2022クラス変換|ES2022クラス変換]]

### Oxfmt: Tailwind のクラス文字列を空白を詰めた後の形でレイアウトを決める（[#28744](https://github.com/oxc-project/oxc/pull/28744)、[#28745](https://github.com/oxc-project/oxc/pull/28745)、[#28791](https://github.com/oxc-project/oxc/pull/28791)）

> [!quote] Before
> `sortTailwindcss` が有効（`preserveWhitespace` は無効）のとき、出力ではクラス文字列の空白・改行を 1 つの空白に詰めるのに、レイアウトの判定は元のソースの文字列で行っていた。そのため、複数行の `className` を持つ JSX の開始タグ、Tailwind 関数の呼び出しを右辺にもつ代入（短い引数の判定）、Tailwind 関数の唯一のテンプレート引数・タグ付きテンプレートのアローの本体・短いオブジェクトのキーなどで、整形が 2 回目でようやく安定していた。

> [!success] After
> 空白を詰めた後の文字列・幅をもとにレイアウトを決め、1 回で Prettier + prettier-plugin-tailwindcss と同じ出力になる。

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/Oxfmt|Oxfmt]]

### codegen: 無限大の数値リテラルを `Infinity` ではなく `1e400` で出力（[#28812](https://github.com/oxc-project/oxc/pull/28812)）

> [!quote] Before
> `minify` なしでは、無限大の `NumericLiteral` を識別子 `Infinity` として出力していた。`Infinity` はグローバルのプロパティなので、`function f(Infinity) { return 1e400; }` のようにローカルの束縛に隠されると値が変わっていた。

> [!success] After
> `minify` なしでは `1e400`（`-1e400`）と出力する。`minify` ありは従来どおり `1/0`。`UnaryExpression` の `delete (0, Infinity)` の回避策は削除された。Minifier のテストの期待値 37 件が `1e400` に変わった。JS の codegen（`packages/codegen`）も同じ。

### Minifier: 空文字列の検索での `replaceAll` の畳み込みで UTF-16 の境界を保つ（[#28807](https://github.com/oxc-project/oxc/pull/28807)）

> [!quote] Before

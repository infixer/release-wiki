## 新機能

### `react/only-export-components` に `allowCompoundComponents` オプションを追加（[#27117](https://github.com/oxc-project/oxc/pull/27117)）

> [!tip] 何ができるようになったか
> 有効にすると、すべてのプロパティが React コンポーネントである空でないオブジェクトのエクスポート（コンパウンドコンポーネント）を許可する。default export やエクスポートされたローカル束縛もチェックする。入れ子のオブジェクト・スプレッド・アクセサ・定数の混在・静的なコンポーネント名の無い無名関数は引き続き違反になる。[eslint-plugin-react-refresh#117](https://github.com/ArnaudBarre/eslint-plugin-react-refresh/pull/117) の挙動に合わせたもの。
>
> - **使い方**: `"react/only-export-components": ["error", { "allowCompoundComponents": true }]`（既定は `false`）
> - **嬉しい場面**: `export const Card = { Header, Body }` のようにコンポーネントをまとめてエクスポートしたいとき

📦 oxlint_v1.86.0 に収録 · トピック: [[repos/oxc-project-oxc/topics/Linterルール個別修正|Linterルール個別修正]]

### Minifier が同じ内容の隣接する `if` 文をまとめるように（[#26445](https://github.com/oxc-project/oxc/pull/26445)）

> [!tip] 何ができるようになったか
> 同じ内容で終わる（return などで抜ける）隣接した `if` 文を 1 つにまとめる。
>
> - **例**: `if (a) { b; return d } if (c) { b; return d }` → `if (a || c) return b, d;`

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/Minifier|Minifier]]

### Minifier が抜ける `if` ブロックの後ろの文を else 側へまとめるように（[#26667](https://github.com/oxc-project/oxc/pull/26667)）

> [!tip] 何ができるようになったか
> `if` の consequent が終端文（`return` など）で終わるブロック文の場合にも、後続の文を else 側へ移して終端文を取り除く最適化を行うようになった。その結果、条件式へ畳み込めるようになる（[#25489](https://github.com/oxc-project/oxc/issues/25489) の修正）。
>
> - **例**: `if (a()) { b(); return; } c();` → `if (a()) b(); else c();` → `a() ? b() : c();`

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/Minifier|Minifier]]

### `react/jsx-no-target-blank` にサジェスチョンを実装（[#27181](https://github.com/oxc-project/oxc/pull/27181)）

> [!tip] 何ができるようになったか

### `eslint/require-await` が `await using` を await として数えるように（[#27080](https://github.com/oxc-project/oxc/pull/27080)）

> [!quote] Before
> `await using x = ...` や `for (await using x of xs)` しか await を含まない async 関数も報告され、危険な自動修正（`--fix-dangerously`）で `async` を外すと、パースできないコードになっていた。

> [!success] After
> `await using` 宣言を await として数える（ESLint の eslint/eslint#19828 と同じ）。入れ子の関数・アロー関数の中は従来どおり数えない。

### 型リテラル内の式の演算子を見て型引数ではないと判定するように（[#27122](https://github.com/oxc-project/oxc/pull/27122)）

> [!quote] Before
> 波かっこ内の二項演算子や `extends` の無い三項演算子などがあっても型引数リストとして読み続けていたため、`x = f<{a: b + c}>` の次の行の `/re/g` を正規表現として扱えなかった。

> [!success] After
> tsc と同じく、これらが現れた時点で型引数の推測を打ち切り、次の行の `/re/g` を正規表現と読む。mapped type の修飾子・計算キー・改行区切りのメンバーは従来どおり動く。

### `eslint/one-var` の分割時に `declare` を保持するように（[#27081](https://github.com/oxc-project/oxc/pull/27081)）

> [!quote] Before

## 新機能

### パーサー: 重複した import 属性のキーに分かりやすいエラーを出す（[#28262](https://github.com/oxc-project/oxc/pull/28262)）

> [!tip] 何ができるようになったか
> `with { type: "json", type: "html" }` のように import 属性のキーが重複したとき、これまでは「Identifier `type` has already been declared」と変数の再宣言と同じ文面だった。今後は「Duplicate import attribute key `type`」と表示し、最初の指定箇所と繰り返した箇所を示して「Each import attribute key must be unique」というヘルプを付ける。
>
> - **使い方**: 特別な設定は不要（パーサーのエラーメッセージが変わる）
> - **嬉しい場面**: import 属性の書き間違いの原因をすぐに把握したいとき

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/パーサー|パーサー]]

### レキサー: `cpu_versions!` マクロが const 関数に対応（[#28426](https://github.com/oxc-project/oxc/pull/28426)）

> [!tip] 何ができるようになったか
> `cpu_select!` マクロを const の文脈で使え、`#[apply(cpu_versions)]` を const 関数・メソッドに付けられるようになった。
>
> - **使い方**: const 関数に `#[apply(cpu_versions)]` を付ける（`oxc_lexer` の内部）
> - **嬉しい場面**: CPU ごとに特殊化したい const 関数が出てきたとき（現時点で必要かは未定だが、コストなしで機能を広げた）

⏳ 未リリース · トピック: [[repos/oxc-project-oxc/topics/レキサー基盤|レキサー基盤]]

### JS プラグイン: AST ノードを `Object.create` で作って高速化（[#27816](https://github.com/oxc-project/oxc/pull/27816)）

> [!quote] Before

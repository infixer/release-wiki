## 概要

`no-unused-vars` 以外の個別 lint ルールについての細かい不具合修正をまとめたトピック。vitest/unicorn 系ルールの自動修正の適用範囲、`prefer-const`・`preserve-caught-error`・`import/no-duplicates`・`node/no-exports-assign` などのルールについて、判定基準や自動修正の適用条件を上流（ESLint・Unicorn・import-js・typescript-eslint）や実際の意味論に揃える変更が中心。自動修正が不正なコードや意味の変わるコードを生む問題（`require-await` と `await using`、`one-var` の `declare` 落ち、`prefer-exponentiation-operator` の優先順位、`unicorn/no-zero-fractions` の区切り文字付き整数）の修正も続いている。オプション追加としては `react/only-export-components` の `allowCompoundComponents`（oxlint_v1.86.0）、`react/jsx-no-target-blank`・`unicorn/no-useless-switch-case`・`react/no-unescaped-entities` のサジェスチョン実装がある。jsx-a11y 系（`lang`・`mouse-events-have-key-events`・`label-has-associated-control`）では、式の文字列・nullish な値・空の属性値の判定を直す修正が入った。`unicorn/prefer-query-selector` には `allowWithVariables` オプションが追加された（oxlint_v1.88.0 で公開）。`typescript/no-import-type-side-effects` と `import/no-duplicates` の自動修正が同じパスで衝突して不正な構文を生む問題も修正された（oxlint_v1.88.0 で公開）。`unicorn/prefer-bigint-literals` は `BigInt(123n)` を `123n` に簡約し、実行時の値が変わる（精度が落ちる）自動修正は行わないようになった。精度の判定は `utils/number.rs` に共通化され、`no-loss-of-precision` の 2・8・16 進数の判定も直った（oxlint_v1.88.0 で公開）。`sort-keys` の `natural: true` の比較は ESLint の `natural-compare` の移植になり、全順序でない比較による自動修正の panic も解消した。`oxc/bad-array-method-on-arguments` は `arguments` の参照をファイルごとに 1 回だけ調べるようになり、`var arguments;` に束縛された参照もチェックする（いずれも oxlint_v1.88.0）。2026-10-16 の回では、#27710・#27746 の報告をもとに ESLint・Unicorn との差異を埋める修正が多数入った（`no-setter-return` のディスクリプタのセッター、`no-useless-assignment` の引数への代入、`max-params` の rest 引数、`id-length` の分割代入、`no-magic-numbers`・`no-div-regex`、`unicorn/consistent-function-scoping`・`no-array-callback-reference`・`prefer-type-error`・`catch-error-name` など）。`no-var` と `unicorn/catch-error-name` の自動修正が不正なコードを生む問題も直った（いずれも未リリース）。2026-10-19 の回では `eslint/prefer-template` が入れ子の連結を ESLint と同じく別々に報告するようになった（未リリース）。これらは oxlint_v1.89.0（2026-10-19）で公開された。同じリリースで、孤立サロゲートを含む文字列でも各ルールがチェックを行うようになった（UTF-8 が必要な自動修正は診断だけ残す。ユーザー設定の正規表現・glob はそうした値に一致しない）。その後、`eslint/arrow-body-style` の自動修正が型アサーションを保ち、`react/jsx-key` の `warnOnDuplicates` が置換を含むテンプレートの `key` の後の重複を再び報告するようになった（いずれも未リリース）。2026-10-23 の回では、`eslint/prefer-const` が再代入される宣言子を含む宣言を自動修正しない、`jest/no-conditional-expect`（Vitest も）が関数式のコールバックをたどる、`eslint/no-useless-concat` がかっこを見通す、孤立サロゲートを含む名前でも `jest/no-jasmine-globals`・`import/no-commonjs`・`import/namespace`・`react/rules-of-hooks` などが報告する、という修正が入った（いずれも未リリース）。2026-10-26 の回では、`eslint/array-callback-return` が初期値付きの `reduce` / `reduceRight` や `thisArg` 付きの `map`・`Array.from` のように追加の引数があるコールバックも ESLint と同じくチェックするようになった（未リリース）。2026-10-30 の回では、`import/no-cycle` が確認済みのパスを複製しなくなり（vscode で割り当て 42.4% 減）、`unicorn/no-await-expression-member` が `await` の無いファイルをスキップするようになった（いずれも未リリース）。2026-11-04 の回では、`eslint/no-misleading-character-class` がアラビア語・ヘブライ語・タイ語などの結合文字も検出し、`unicorn/no-zero-fractions` が指数部をそのまま残し（`1.0E+10` → `1E+10`）、`eslint/prefer-spread` が `(c ? a : b).apply(null, args)` なども報告し、`eslint/no-fallthrough` が無限ループで終わる case を報告しなくなった。`unicorn/prefer-single-call` の修正の状態は `conditional_fix` に整理された（いずれも未リリース）。oxlint_v1.91.0（2026-11-03）では、`eslint/no-control-regex`・`unicorn/prefer-global-this`・`unicorn/no-invalid-fetch-options` の修正、2 つのルールの suspicious カテゴリへの移動、多数のルールの割り当て削減が公開された。2026-11-06 の回（未リリース）では、`eslint/no-redeclare` に typescript-eslint 由来の `ignoreDeclarationMerge` オプション（既定 `true`。interface 同士・class と interface などの宣言のマージを報告しない）が加わった。修正は、`unicorn/prefer-type-error` が波かっこなしの `if` の throw も報告、`eslint/no-restricted-imports` が空のパターンで `allowTypeImports` を正しく扱う、`jsx-a11y/aria-role` が `role={undefined}` を許可、`vitest/prefer-called-exactly-once-with` が非 ASCII のテキストで panic せず自動修正で隣のコードを消さない、`eslint/no-misleading-character-class` が `\p{M}` の lazy な正規表現で結合文字を判定、`react/only-export-components` が JSX の値をコンポーネントでないものとして扱う、`jsdoc/require-param` が外側の関数の JSDoc を使わない、というもの。2026-11-06 の回の修正は oxlint_v1.92.0（2026-11-06）で公開された。2026-11-09 の回（未リリース）では、`promise/prefer-catch` に `then(undefined, fn)` / `then(null, fn)` 向けのサジェスチョンが加わり、照合の対象を `CallExpression` に広げた。CFG のラベル付きジャンプの修正（ラベルなしの `break` がラベル付きブロックを飛び先にしない、積み重なったループのラベルへの `continue`）で `no-unreachable`・`no-unreachable-loop` の誤検知が直った。`react/exhaustive-deps` の依存の削除は `--fix-dangerously` が必要な危険なサジェスチョンになり、`eslint/no-restricted-imports` は再 export された import を 1 回だけ報告し、`eslint/prefer-destructuring` はコメントを消す修正をせず、`import/no-anonymous-default-export` はかっこで囲んだ export も報告し、`eslint/id-length` は TypeScript の修飾名の参照を無視する。`oxc_jsdoc` がすべての行終端子で改行するようになり、単独の CR の改行のファイルでの jsdoc ルールの誤報告も直った。2026-11-13 の回（未リリース）では、通常の lint 実行中（`--fix` なしでも）に panic していた多数のルールが直った。Unicode の空白・マルチバイト文字の位置の扱い（jest・vitest の `no-large-snapshots`・`prefer-to-be`、`unicorn/prefer-set-has`・`no-useless-spread`・`consistent-template-literal-escape`、`vitest/prefer-called-once`、`eslint/no-empty` の `finally` のサジェスチョン）、かっこで囲んだ呼び出し先・オプショナルチェーン（`unicorn/no-length-as-slice-end`・`prefer-dom-node-remove`・`prefer-object-from-entries`・`prefer-includes`、`oxc/no-accumulating-spread`）、モジュール文字列やクォートした import 名の中の波かっこ（`import/no-duplicates`・`typescript/consistent-type-imports`）、rest 引数（`unicorn/prefer-array-flat`）、並べ替えのオーバーフロー（`vitest/require-test-timeout`）、循環する別名の無限再帰（`unicorn/no-document-cookie`）が対象。`react/jsx-key` は配列の直接の JSX 要素だけを調べるようになり、`vue/no-shared-component-data` に自動修正が実装された。

## 概要

oxlint・oxfmt の設定ファイルの読み込みまわり。TypeScript の設定ファイルを読み込めないときのエラーでは、Node.js の対応範囲として Node 20 を案内しないようになった（Node 20 は TypeScript ファイルをネイティブに読めないため。パッケージの `engines` の要件は変わらない。未リリース）。設定ファイルの探索については [[repos/oxc-project-oxc/topics/Vite+連携|Vite+連携]] も参照。Oxfmt では BOM 付きの設定 JSON を読み込めるようになり、`.editorconfig` も `.oxfmtrc` と同じように検証する（未リリース）。設定ファイルの型 `Oxlintrc`（`$schema`・JSON 形式の `extends` を含む）が `oxlint` パッケージからエクスポートされ、`eslint-plugin-oxlint` などが型を手で組み立て直さずに import できるようになった（未リリース）。

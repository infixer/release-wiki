## 概要

`tasks/coverage` の TypeScript フィクスチャ取り込みが、TypeScript 本体の新しい `tsc/testdata` 統合レイアウト（コンパイラ用とコンフォーマンス用のベースラインディレクトリが分離された形式）に対応した。strict/checkJs のバリアントを扱い、参照ベースラインの無いフィクスチャは除外している。runtime スイートがスキップする V8 の `test262.status` は、V8 の `main` ではなく Node の V8 のバージョン（`process.versions.v8`）のタグから取得するようになった（未リリース）。

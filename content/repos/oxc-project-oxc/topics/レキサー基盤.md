## 概要

`oxc_lexer` の内部実装（`carve` / `disambiguate` パイプラインと SIMD 実装）まわりの改善が続いている。SIMD 実装には `popcnt` CPU 機能が必須化された。JSX の字句解析では、HTML 風コメント（`<!--` / `-->`）の扱いを JS 用実装と共通化し、コメントや Unicode 空白（NBSP など）を含む JSX タグ（閉じタグ・自己閉じタグ・メンバータグ名・`.tsx` の型パラメータ判別など）の誤動作を修正している。これらは大きな親 PR（#26919）から複数の小さな PR に分割して進められている。

## 概要

`oxc_parser` と関連クレート（AST・コメント、`oxc_regular_expression`）。HTML コメントの値からコメント記号を完全に取り除きつつ範囲を保持するよう修正された。正規表現パーサーは、regjsparser から移植したバッファ境界アサーションに対応し、グループ名の Unicode エスケープもデコードするようになった。TypeScript の診断（TS1242・TS1243 の追加、TS1071 の重複解消、型メンバーの区切りの検証）を tsc に合わせる修正も続いている。一方、パーサーでは正しく判定できない型依存の診断（TS1265・TS1266）は削除された。スクリプトでのモジュール構文は semantic ではなくパーサーで報告する。JavaScript のファイルでの TypeScript 専用のクラス修飾子は TS8009 として拒否し、TS1222・TS18019 の報告位置も TypeScript に揃えた。semantic では、`TSMethodSignature` の計算されたキーを外側のスコープで解決するよう修正した（未リリース）。また semantic で、`delete a?.b` や `delete (a.b)` もメンバーへの書き込み（`MemberWriteTarget`）として扱うようになった（Rolldown が利用。未リリース）。パーサーは解析中にノード ID を割り当てるようになり（`Program` が 0、欠番あり。semantic は引き続き詰めた ID に置き換える）、`Comment` には所有ノードと `Leading` / `Trailing` / `Dangling` の位置を表す任意の `attachment` が加わった（`Comment` は 24 バイトになり `Copy` ではなくなった。いずれも破壊的変更）。`export` の直後の `/*@__NO_SIDE_EFFECTS__*/` も関数の `pure` フラグに反映するよう修正された（いずれも未リリース）。AST では、孤立サロゲートを含む静的なメンバー名・プロパティ名（`obj["\uD800"]`、`{ "\uD800": 1 }`）を動的扱いにせず、`static_property_name()` などが `JSStr` を、`PropertyKey::static_name()` などが新しい `StaticPropertyName` を返すようになった（破壊的変更。未リリース）。

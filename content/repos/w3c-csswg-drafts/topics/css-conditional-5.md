## 概要

CSS Conditional Rules Module Level 5。コンテナクエリなどの条件付きルールを定義する仕様。
2026-10-28 の取り込みで、issue #6205 に沿って `matchContainer()` と `ContainerQueryList` の API の本文が加わった。
2026-11-04 の取り込みで、named feature の綴りが `gamut mapping` から他の named feature と揃う `gamut-mapping` に変わった（#14545、未リリース）。

## 主な API・オプション

- `matchContainer()` — 2026-10-27 に API の本文を追加（#6205）
- `ContainerQueryList` — 同上
- named feature `gamut-mapping` — 2026-11-02 に `gamut mapping` から綴りを変更（#14545）

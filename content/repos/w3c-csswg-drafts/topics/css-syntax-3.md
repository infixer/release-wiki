## 概要

CSS Syntax Level 3。CSS のトークン化とパースのアルゴリズムを定義する仕様。2026-10-12 の取り込みで、`style` 属性を正しくパースするための「parse a style attribute」「consume a style attribute」が追加された（#11113）。既存の「block's contents」とは統合できず、別の手順になっている。

## 主な API・オプション

- parse a style attribute / consume a style attribute — `style` 属性のパース手順（[`64e5504`](https://github.com/w3c/csswg-drafts/commit/64e5504c81d5292a6df2c27391f2afa75cd076d7)）

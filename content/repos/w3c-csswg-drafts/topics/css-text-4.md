## 概要

CSS Text Module Level 4。文字間の空き（`text-spacing`・`text-spacing-trim`）などのテキスト処理を定義する仕様。
2026-10-28 の取り込みで、`text-spacing` の `insert` / `replace` の記述が明確になり（#13774）、`text-spacing-trim` の値の全範囲が戻された（#13789）。

## 主な API・オプション

- `text-spacing` — `insert` / `replace` の記述を明確化（#13774）
- `text-spacing-trim` — 値の全範囲を戻した（#13789）

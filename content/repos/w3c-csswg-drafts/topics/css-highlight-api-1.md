## 概要

CSS Custom Highlight API を定義する仕様。登録したハイライトを `::highlight()` 擬似要素でスタイル付けする。Issue #9091 に基づき、引数に `*` を指定する `::highlight(*)` セレクターが追加された（`css-pseudo-4` 側の記述もあわせて更新）。

## 主な API・オプション

- `::highlight(*)` — 2026-09-30 の取り込みで追加されたセレクター（`css-highlight-api-1` / `css-pseudo-4`）

## 変更・修正

### Rust 版コンパイラ: 非 ASCII 文字を含む行の診断の下線位置を修正（[#37898](https://github.com/react/react/pull/37898)）

> [!quote] Before
> 実験的な Rust の Babel アダプターは、Babel の UTF-16 の列位置を UTF-8 のバイトオフセットとして扱っていたため、非 ASCII 文字（`"café"` など）の後ろで診断の下線（`^^^^^`）がずれ、複数行の範囲では下線が長すぎることがあった（#37897）。

> [!success] After
> 下線の位置と複数行の長さを UTF-16 のコードユニットで数え、Babel と一致させる。タブと ASCII の扱いは変わらない（アクセント付き文字・CJK・絵文字・結合文字・タブ・複数行のテストを追加）。

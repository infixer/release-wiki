## 新機能

### react-devtools-fusebox に Suspense タブの入口 `initializeSuspense` を追加（[#38167](https://github.com/react/react/pull/38167)）

> [!tip] 何ができるようになったか
> React Native DevTools は React DevTools の各タブを `initializeComponents`・`initializeProfiler` で個別のパネルとしてマウントしているが、Suspense タブには同等の入口が無く表示できなかった。`initializeSuspense` を追加し、`suspense` タブを同じ方法で描画できるようにした。
>
> - **使い方**: `react-devtools-fusebox` の `initializeSuspense` を呼んで Suspense パネルを描画する
> - **嬉しい場面**: React Native DevTools で Suspense 境界のマップ・表示のタイムライン・境界が何でサスペンドしたかを見たいとき

⏳ 未リリース · トピック: [[repos/react-react/topics/DevTools|DevTools]]

## 変更・修正

### DevTools: Hermes でスタックフレームのファイル名が空になる問題を修正（[#38168](https://github.com/react/react/pull/38168)）

> [!quote] Before
> Hermes の call site は `getFileName()` は実装しているが `getScriptNameOrSourceURL()` を実装していないため、React Native ではバックエンドがすべてのフレームのファイル名を空で記録していた。Components や Suspense のインスペクターから「View source」をしても開く URL が無く、フロントエンドが `Could not find resource for` を投げていた。

> [!success] After
> `getScriptNameOrSourceURL()` が無いときは `getFileName()` にフォールバックする。ソースマップ経由で境界の JSX の位置のファイルが開く。

⏳ 未リリース · トピック: [[repos/react-react/topics/DevTools|DevTools]]

### React Native: 旧イベントディスパッチのパイプラインを削除（[#38172](https://github.com/react/react/pull/38172)）

> [!quote] Before
> `react-native-renderer` に旧イベントのパイプライン（`LegacySyntheticEvent`・`ReactNativeBridgeEventPlugin`・`ReactFabricGlobalResponderHandler` など）が残っていたが、React Native リポジトリ側にある新しいパイプラインがすべての環境で既定で有効になってからは使われていなかった。

> [!success] After
> 使われていない旧パイプラインのコードを削除した（`ReactNativeFeatureFlags.js` も削除）。React Native で e2e テスト済み。

⏳ 未リリース · トピック: [[repos/react-react/topics/React-Native-レンダラー|React Native レンダラー]]

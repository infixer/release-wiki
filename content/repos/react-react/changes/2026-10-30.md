## 変更・修正

### React Compiler（Rust 版）: 非 ASCII の名前で `is_ref_like_name` が panic する問題を修正（[#38025](https://github.com/react/react/pull/38025)）

> [!quote] Before
> `is_ref_like_name` は最初の文字を `object_name[..1]` で調べており、1 バイトだけを切り出していた。`한글Ref` のようにマルチバイト文字で始まる `*Ref` の名前では文字の途中で切れ、`.current` にアクセスするとコンパイラが panic していた。

> [!success] After
> 最初の文字を `.chars().next()` で読むようにし、こうした名前は TS 版の正規表現と同じく `false` を返す。再現用のフィクスチャ `repro-ref-like-name-non-ascii.js` を追加（#38023 を修正）。

⏳ 未リリース · トピック: [[repos/react-react/topics/React-Compiler|React Compiler]]

### View Transitions: Chrome 153 のエラーメッセージに合わせて分類を更新（[#38034](https://github.com/react/react/pull/38034)）

> [!quote] Before
> Chrome 153 で view transition の `InvalidStateError` のメッセージが変わり（例: `Transition was aborted because of invalid state. Document hidden`）、これまでメッセージの完全一致で抑えていたエラーが `onRecoverableError` に出るようになっていた。

> [!success] After
> すべての理由を隠してしまう `.startsWith()` にはせず、対処しようのないもの（`Document hidden`、`Viewport size changed`、理由の無いメッセージ）だけに一致させる。Firefox の同様のメッセージも追加。実際には `Snapshot capture failed` や `Animation start failed` として現れる重複した `view-transition-name` には、`__DEV__` でより分かりやすいメッセージを出す（#37669 を修正）。

⏳ 未リリース · トピック: [[repos/react-react/topics/React-DOM|React DOM]]

## 概要

`@vue/reactivity` の `reactive` / `shallowReactive` / `watch` など。
v3.5.44 では、`once` のウォッチャーがコールバックの例外でも止まるように、他の effect の中で動くウォッチャーのコールバック・クリーンアップで依存を追跡しないように、
`Map` / `Set` の `shallowReactive()` / `shallowReadonly()` で `isShallow()` が正しく `true` を返すように、
リアクティブな配列の反復でネイティブのイテレーターを書き換えないように修正された。

## 主な API・オプション

- `watch(source, cb, { once: true })` — コールバックが例外を投げても停止する
- `watch(..., { flush: 'sync' })` / `immediate` — コールバックとクリーンアップの読み取りは外側の effect に追跡されない
- `isShallow()` / `shallowReactive()` / `shallowReadonly()` — コレクションでも shallow の意味を保つ

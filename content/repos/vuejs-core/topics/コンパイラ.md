## 概要

テンプレート・SFC のコンパイラ（`@vue/compiler-core` / `@vue/compiler-dom` / `@vue/compiler-sfc`）。
v3.5.44 では、`defineModel()` まわりのエラーの改善（`v-model` をプロップに使ったときのヒント、オプションが分割代入したプロップを参照したときのコンパイルエラー）、
静的な文字列化での `v-html` の偽値、`v-memo` + `v-for` のキャッシュ判定の括弧、
本番ビルドで Transition の `persisted` が注入されない退行が修正された。
`compiler-dom` の静的な内容の文字列化（`stringifyStatic`）では、定数の真偽値のバインディングのうち偽に当たる値を省き、カスタム要素にバインドした真偽値の属性は文字列化せず実行時の挙動を保つ（未リリース）。
`@vue/compiler-ssr` では、素の要素の静的な `style` 属性をコンパイル時に開始タグへ書き出すようになった（未リリース）。
v3.5.45 では、props の分割代入で `catch` / `switch` / クラスの static ブロックのスコープを正しく扱うように、`v-if` のノードの `loc` を他のテンプレート基準で計算しないように修正され、`defineProps<T>()` の型解決で tsconfig の `include` を列挙しなくなった（大きなモノレポで高速化）。

## 主な API・オプション

- `defineModel()` — 戻り値の ref に `v-model` を使う。オプション（`default` など）はモジュールスコープに巻き上げられるため、分割代入したプロップは参照できない（`default: props => ...` を使う）
- `X_V_MODEL_ON_PROPS` — プロップに `v-model` を使ったときのコンパイラエラー
- `v-html` / `v-memo` / `v-show`

## 要点

Release 本文には個別の変更点は記載されておらず、安定版の詳細は [CHANGELOG.md](https://github.com/vuejs/core/blob/main/CHANGELOG.md) を参照するよう案内されている。この回に取り込んだ PR 25 件（すべて修正）が 📦 v3.5.44 に収録されている。

- リアクティビティ: `once` のウォッチャーが例外でも止まる（[#15755](https://github.com/vuejs/core/pull/15755)）、sync / immediate のウォッチャーのコールバックで外側の effect に依存を追跡させない（[#15782](https://github.com/vuejs/core/pull/15782)）、`Map` / `Set` の `shallowReactive()` で `isShallow()` が正しく動く（[#15793](https://github.com/vuejs/core/pull/15793)）
- レンダラー: ルートの `mount()` が他のアプリの保留中のウォッチャーを同期実行しない（[#15757](https://github.com/vuejs/core/pull/15757)）、不正な `v-for` の範囲を本番でも空にする（[#15742](https://github.com/vuejs/core/pull/15742)）
- コンパイラ: 本番ビルドで `v-show` の子に Transition の `persisted` が付かない退行を修正（[#15783](https://github.com/vuejs/core/pull/15783)）、`defineModel()` のエラーの改善（[#15781](https://github.com/vuejs/core/pull/15781)、[#15604](https://github.com/vuejs/core/pull/15604)）
- 組み込みコンポーネント: `<Suspense>` 下の SVG の名前空間（[#15640](https://github.com/vuejs/core/pull/15640)）、`KeepAlive` の `max`（[#15711](https://github.com/vuejs/core/pull/15711)）、`Teleport` の `to` の変更（[#15818](https://github.com/vuejs/core/pull/15818)）
- トランジション: 入れ子の `TransitionGroup`（[#15848](https://github.com/vuejs/core/pull/15848)）、コメントで包まれたルートの切り替え（[#15853](https://github.com/vuejs/core/pull/15853)）
- SSR・ハイドレーション: 非同期 setup のエラーの伝播（[#15857](https://github.com/vuejs/core/pull/15857)）、`hydrateOnVisible()` と `display: contents`（[#15773](https://github.com/vuejs/core/pull/15773)）
- その他: `playsinline` を真偽値の属性に（[#15627](https://github.com/vuejs/core/pull/15627)）、非同期のカスタム要素（[#15777](https://github.com/vuejs/core/pull/15777)）、compat の `_setupProxy`（[#15618](https://github.com/vuejs/core/pull/15618)）

## 新機能

### TUI の数式表示にアクセント・記号・名前付きデリミタを追加（[#46266](https://github.com/openai/codex/pull/46266)）

> [!tip] 何ができるようになったか
> TUI の Markdown レンダラーが表示できる Unicode 数式の種類が増えた。
>
> - **アクセント**: `\hat`・`\bar`・`\tilde`・`\vec`・`\dot`・`\ddot` を単一の書記素の上に表示（後続の上付き・下付き文字も維持）
> - **記号**: 物理・関係・集合・論理・矢印・積分などの記号を追加（`\hbar` を含む）
> - **デリミタ**: `\left`・`\right` を使った名前付きデリミタ、`\left<`・`\right>` による山括弧に対応
> - アクセントの引数が空・不可視・複数の書記素や行にまたがる場合は、元の記法のまま表示する

📦 rust-v0.156.1 に収録 · トピック: [[repos/openai-codex/topics/TUI|TUI]]

### Windows サンドボックスの設定で MXC バックエンドを選択可能に（[#46271](https://github.com/openai/codex/pull/46271)）

> [!tip] 何ができるようになったか
> 設定で `windows.sandbox = "mxc"` を指定できるようになり、選択したバックエンドが環境構成・コマンド実行・パッチ書き込み・サンドボックスのメタデータまで一貫して使われるようになった。
>
> - TUI は MXC を有効なものとして扱い、Windows サンドボックスの準備状態を `ready` と報告し、旧来のセットアッププロンプトを表示しない
> - `allowed_sandbox_implementations` は従来どおり昇格/非昇格の旧バックエンドのみを対象とし、MXC は制限しない
> - `windows.sandbox_private_desktop` は MXC では既定 `false`（旧サンドボックスでは引き続き `true`）

### Code Mode のレスポンスにオプトインのオーバーヘッド計測を追加（[#46288](https://github.com/openai/codex/pull/46288)）

> [!tip] 何ができるようになったか
> 新しい設定 `features.code_mode.experimental_show_cell_overhead`（既定は無効）を有効にすると、`exec`・`wait` のレスポンスヘッダーに、ハンドラー処理時間・ホスト処理時間・その差分が表示されるようになった。
>
> - **嬉しい場面**: app-server の待ち時間など、ホスト外で消費している時間を把握したいとき
> - 無効時や计測不能時は従来どおりの表示形式を維持する

### モデルカタログによるツール説明の上書きが全マルチエージェント V2 ツールに対応（[#46297](https://github.com/openai/codex/pull/46297)）

> [!tip] 何ができるようになったか

### フィードバックレポートに設定・機能フラグの診断情報を追加（[#46501](https://github.com/openai/codex/pull/46501)）

> [!tip] 何ができるようになったか

### 互換性のある機能上書きを指定していても共有デーモンを使えるように（[#46529](https://github.com/openai/codex/pull/46529)）

> [!tip] 何ができるようになったか
> これまで機能フラグの上書きを指定すると常に embedded モードに強制されていたが、共有デーモンと両立できる上書きであれば共有デーモンを使えるようになった。

> - 選択された Boolean 機能上書きと `suppress_unstable_features_warning` はデーモンモードでも許可（共有サービスを無効化する明示的な上書きのみ embedded モードのまま）

> - worktree セッションもデーモンを自動起動できるようになった

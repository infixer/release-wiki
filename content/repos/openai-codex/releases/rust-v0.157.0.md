## 要点

- GPT-6 Sol・Luna を追加。Amazon Bedrock でも利用でき、古いモデルからの移行プロンプトも用意（#47332, #47347）
- フルスクリーンのトランスクリプトが既定で有効に。Shift+クリックでテキスト選択を広げられるように（#47178, #47414）
- 条件を満たす対話セッションでバックグラウンドサーバーを自動起動。サーバー設定に互換性が無い場合の回復手段も用意（#47179, #47318）
- 別のアプリで開いている会話を `f` ショートカットでフォーク。下書きとキュー済みのプロンプトは保持（#47185）
- `/import` がリモートセッションとローカルのバックグラウンドサーバーのセッションで使えるように（#47317）
- ターミナル描画の改善（Unicode の箇条書き記号・チェックボックス・揃えた数式・最適化の記法）（#47191, #47322）
- 主な修正: スレッド切り替え時に音声会話を維持（#47381）、ターン終了時に未送信の質問への回答をコンポーザーに復元（#47422, #47423）、tmux のマウス設定の尊重と SSH 越しの Terminal.app でのネイティブスクロールバックの復元（#47399, #47417）、リアルタイム接続と単体の Web 検索での設定済みプロキシのルーティング修正（#47101, #47142, #47204）、ファイルアップロードの一時的な失敗のリトライとタイムアウトの 5 分への延長（#47122, #47393）、リダイレクトや継続中の HTTP・WebSocket 通信へのネットワーク制限の適用（#47389, #47407）

## 要点

- オプトインの `instant_interrupt` で、モデルの応答中や長時間の Code Mode の呼び出し中でも新しい入力で Codex の向きを変えられるように（#48135, #48141）
- 新しいセッションにコンパクトなウェルカム画面と統一されたヘッダーを表示し、ターンの途中や後に時々 tip を表示（#48513, #48562, #48352）
- 警告ビューアを閉じると確認済みの警告を消す（`k` で後に残せる）。プランを実装するか決める間もトランスクリプトをスクロール可能に（#48205, #48206, #48805）
- ネイティブの Mermaid 描画がフローチャートの辺・ラベル・ノードグループをより多く扱えるように。app-server のクライアントは特定の項目からスレッド履歴をページングできる（#48814, #48895, #48151）
- 主な修正: Windows で MCP サーバー・Code Mode のホスト・パイプしたコマンドの起動時に余計なコンソールウィンドウを出さない（#48138, #48238, #48483, #48491）、トランスクリプトの選択のコピーで Markdown の表・書式・意味のある空白を保持（#48548, #48549, #48469）、空のセッションでタスク切り替え時に下書きを保持し、最初のターン前のスレッドをアーカイブ・一覧表示可能に（#48628, #48828, #48199）、ローカルの ChatGPT サインインで確実にブラウザを開く（#48502, #48544）、承認済みコマンドでも明示的なファイルシステムの拒否を維持し、書き込み可能ルート配下の `.aws` を既定で保護（#48155, #48176）、ネットワーク有効のサンドボックスでの macOS の TLS アクセスとプロキシが必要なリモート環境を修正（#48565, #48198）
- 削除: 自動のフォローアッププロンプト候補と `tui.prompt_suggestions` 設定（#48621）、同梱の `plugin-creator` スキル（#48604）

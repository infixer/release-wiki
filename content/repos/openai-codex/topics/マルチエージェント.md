## 概要

`spawn_agent` などのマルチエージェント V2 ツール群による、サブエージェントへのタスク委任機能。この期間は `spawn_agent` の既定の説明文から「具体的で範囲の決まったサブタスクにのみ使うべき」という制約的な指示が取り除かれ、委任のガイダンスが緩和された。また、モデルカタログによるツール説明の上書きが、これまで `spawn_agent` 限定だったところから `send_message`・`followup_task`・`wait_agent`・`interrupt_agent`・`list_agents` を含む全 6 ツールに拡張された。2026-09-30 の回では、メッセージボードの通知がターンのメールボックス（`InterAgentCommunication`）経由になり、完了済みの回答を再開しなくなった（rust-v0.159.2 に収録）。また、準備中の環境もサブエージェントに引き継がれ、準備完了・失敗が子孫まで伝わるようになった。2026-10-02 の回では、`model_catalog_in_context`（既定は無効）でモデルの一覧をツールの説明から developer メッセージの `<model_catalog>` に移し、ツール定義を変えずに選択肢を最新に保てるようになった。2026-10-05 の回では、TUI のサブエージェントのピッカーがスレッドのアーカイブ状態と一致するようになり、アーカイブ済みのスレッドは隠され、アーカイブ解除で戻る。2026-10-07 の回では、すでに取り消された委任は、ランタイムの受け付けや起動の前に `TurnAborted` を返すようになった。2026-10-09 の回では、クライアントの切断後に作られた永続化済みの v2 の子にもライフサイクルのリスナーを付けてアイドル時に解放するようにし、`thread_unload_delay_secs` の既定を 60 秒から 1800 秒（30 分）に引き上げた。ephemeral の子は読み込んだままにする。2026-10-12 の回では、フル fork で親の履歴のプレフィックスを保つ `preserve_fork_prefix` と、サブエージェントでモデルの既定のコンテキストウィンドウ・自動コンパクションのしきい値を使う機能 `subagent_default_context_limits`（いずれも既定は無効）が入った。エージェントのメッセージボードは `get_channels` で権限を公開し、403 の拒否を構造化されたエラーで返すようになり、ローカルのボードはテンプレート（`configure_local_board`）で初期のチャンネルを準備できる。2026-10-14 の回では、`LocalBoard`・`LocalBoardConnection` により、別々に作ったランタイムが読み取り専用・読み書きの異なる権限でローカルのメッセージボードを共有できるようになった。`features.multi_agent_v2.disable_native_tools` でネイティブのツールを隠しつつ V2 のランタイムと指示を残せるようになり、`multi_agent_v2.disable_direct_message` の有効時にボードが使えなくてもターンが拒否されないよう修正された。

## 主な API・オプション

- `spawn_agent` — v2 の既定の説明文から委任範囲についての指示を削除
- `send_message` / `followup_task` / `wait_agent` / `interrupt_agent` / `list_agents` — モデルカタログによる説明文の上書きに対応（null/未指定は既定のテキスト、空文字列で静的テキストを消せる）
- メッセージボードの通知 — 現在のターンのメールボックスに `InterAgentCommunication` として届く。受け付けが閉じていれば送らない
- `model_catalog_in_context` — モデル一覧を `<model_catalog>` メッセージで提供（V1・V2、既定は無効、1,000 バイトまで）
- `thread_unload_delay_secs` — アイドルのスレッドをアンロードするまでの秒数。既定は 1800（以前は 60）
- `preserve_fork_prefix`（マルチエージェント v2、既定は `false`）— フル fork で親のモデルから見える履歴を保ち、子の指示を後ろに追加
- `subagent_default_context_limits`（既定は無効）— サブエージェントの起動・再開で `model_context_window`・`model_auto_compact_token_limit` の引き継ぎをクリア
- `get_channels` の `board_permissions` / チャンネルの `permissions` — メッセージボードの実際の権限。403 の `permission_denied` は `action`・`resource` 付きの構造化エラー
- `LocalBoardSetup` / `configure_local_board` — ローカルのボードにテンプレートで初期のチャンネルと説明を読み込む（SQLite にアトミックに保存）
- `LocalBoard` / `LocalBoardConnection` — `thread_extension_init` でホストが読み取り専用・読み書きのアクセスを渡し、独立したランタイム間でローカルのボードを共有
- `features.multi_agent_v2.disable_native_tools`（既定は `false`）— ネイティブのマルチエージェントのツールを隠し、V2 のランタイムと指示は有効なままにする

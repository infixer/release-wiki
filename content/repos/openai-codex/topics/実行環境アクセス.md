## 概要

ファイルシステムなどの実行環境（Environment）へのアクセスを、サンドボックス設定を伴った形で統一的に公開する内部基盤。この期間に `EnvironmentAccess`・`FileSystemEnvironmentAccessor` が追加され、スキルの発見・読み込み・プラグイン名前空間の解決が、これまでの `ExecutorFileSystem` への直接呼び出しからこの新しいアクセサ経由に切り替えられた。2026-09-30 の回では、パスの URI 変換で、スラッシュで始まる opaque な Windows パスを POSIX パスと誤認しないよう修正された。2026-10-02 の回では、`//server/share/project` のように区切り文字 2 つで始まるパスを、ホストに関係なく Windows の UNC パスと推定するようになった。

## 主な API・オプション

- `EnvironmentAccess` / `FileSystemEnvironmentAccessor` — 捕捉したサンドボックス設定を伴うファイルシステムアクセス。テキスト読み取りヘルパーと明示的な無制限コンストラクタ（`unrestricted`）を提供
- `Environment::filesystem_ref()` — 共有ファイルシステムを借用するための API
- `codex-exec-server` からも新しい API を公開

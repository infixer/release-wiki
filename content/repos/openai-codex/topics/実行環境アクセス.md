## 概要

ファイルシステムなどの実行環境（Environment）へのアクセスを、サンドボックス設定を伴った形で統一的に公開する内部基盤。この期間に `EnvironmentAccess`・`FileSystemEnvironmentAccessor` が追加され、スキルの発見・読み込み・プラグイン名前空間の解決が、これまでの `ExecutorFileSystem` への直接呼び出しからこの新しいアクセサ経由に切り替えられた。

## 主な API・オプション

- `EnvironmentAccess` / `FileSystemEnvironmentAccessor` — 捕捉したサンドボックス設定を伴うファイルシステムアクセス。テキスト読み取りヘルパーと明示的な無制限コンストラクタ（`unrestricted`）を提供
- `Environment::filesystem_ref()` — 共有ファイルシステムを借用するための API
- `codex-exec-server` からも新しい API を公開

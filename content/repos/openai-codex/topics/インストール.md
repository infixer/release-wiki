## 概要

Codex のインストールスクリプト（`scripts/install/` など）まわり。2026-10-07 の回では、Windows PowerShell 向けのインストーラ `scripts/install/install.ps1` で、`Get-FileHash` を使わずに .NET の API で SHA-256 を直接計算するようになり、ネイティブのランチャーが PowerShell 7 のモジュールパスを渡した場合でもアーカイブのチェックサムを検証できるようになった。2026-10-21 の回では、スタンドアロンのインストールが、検証後にロックを持ったまま使われていない古いリリースを片付けるようになった（現在・以前に選んだリリースと実行中のプロセスが使うものは残す）。2026-10-28 の回では、macOS で `lsof` の終了コード 1 や ASCII でないインストール先のパスのせいで古いリリースの片付けが飛ばされる問題が修正された（未リリース）。

## 主な API・オプション

- `scripts/install/install.ps1` — Windows PowerShell 向けのインストーラ。アーカイブのチェックサム（SHA-256）を .NET の API で検証し、不一致ならエラー

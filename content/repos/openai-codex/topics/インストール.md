## 概要

Codex のインストールスクリプト（`scripts/install/` など）まわり。2026-10-07 の回では、Windows PowerShell 向けのインストーラ `scripts/install/install.ps1` で、`Get-FileHash` を使わずに .NET の API で SHA-256 を直接計算するようになり、ネイティブのランチャーが PowerShell 7 のモジュールパスを渡した場合でもアーカイブのチェックサムを検証できるようになった。

## 主な API・オプション

- `scripts/install/install.ps1` — Windows PowerShell 向けのインストーラ。アーカイブのチェックサム（SHA-256）を .NET の API で検証し、不一致ならエラー
